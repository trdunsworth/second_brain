# Positron

Source: <https://positron.posit.co> — captured 2026-11-01 (docs version 2026.10.1; IDE release
2026.10.2-3).

## Positioning

Positron is a **free IDE purpose-built for data science**, from Posit Software, PBC (formerly
RStudio, PBC) — *"transparent AI assistance, interactive data exploration, and everything you need
to go from question to insight to application."* It is Posit's next-generation IDE for R and Python —
the same project workflows you know from RStudio, with first-class support for both languages.

## License

Positron is licensed under the **Elastic License 2.0** — source-available, rather than
OSI-approved open source. See the [licensing page](https://positron.posit.co/licensing.html) for what
the license permits and Posit's reasoning.

## Components

### Posit Assistant

The AI assistant built for data science; it connects to your live Python or R sessions, sees your
data, and helps you explore, visualize, build, and debug. Available via the Posit AI / Posit AI Pass
subscription in [[RStudio IDE]], [[Positron]], and the terminal; zero data retention.

### Data Explorer

Interactive data frame exploration — fast, interactive data frames for large datasets, per-column
summary profiles, and a data grid.

### Data Apps

Build and preview data applications directly from the IDE; deploy via Posit Publisher to Posit
Connect / Posit Connect Cloud.

### Quarto

Create dynamic reports with Quarto from within the IDE.

### Positron Notebook Editor

Bridges Jupyter notebook functionality with IDE capabilities built for data science.

## Feature areas

| Area | Covers |
|---|---|
| Bridge exploration → production | Data Apps, Quarto reports, Jupyter notebooks |
| Explore and analyze at speed | First-class Python / R / SQL support, Data Explorer, Variables pane, Plots pane |
| Develop with confidence | Remote SSH / Workbench, folder templates, multi-session console, Posit Publisher |
| Enterprise-ready | Positron Pro via Posit Workbench: SSO security, scalable compute, centralized management, dedicated support |

## Enterprise tier

**Positron Pro** — a secure, governed, scalable data science editor delivered *through*
[[Posit Company and Platform]], not as a separate desktop license.
