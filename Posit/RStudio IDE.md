# RStudio IDE

Sources: <https://posit.co/products/open-source/rstudio/> and <https://docs.posit.co/ide/user/> —
captured 2026-10-30 and 2026-11-01.

## Positioning

The premier free, open-source development environment for R. Posit's framing: *"Open source since
2009. We build RStudio, the tidyverse, Shiny, Quarto, and 350+ packages used by millions of people
every week. RStudio will remain free. Using RStudio without AI will cost nothing."*

Tagline: *"The trusted IDE for R data scientists, now with AI that knows your data."*

## Editions

### Open source edition (free)

- **AGPL v3** license.
- Desktop (Windows 11, macOS 15+, Linux) or browser via RStudio Server / Posit Workbench.
- Features: syntax highlighting, code completion, smart indentation; execute R from source editor;
  Python via reticulate; Visual Markdown Editor for Quarto and R Markdown; Data Viewer; Git
  integration and project management; interactive debugger; package development tools; publish to
  Posit Connect, shinyapps.io, or RPubs; community forum support.

### RStudio Server (open source)

- The browser/server variant of the open-source IDE, also AGPL v3-licensed; deployed via Posit
  Workbench or self-hosted.

### Desktop Pro (commercial)

- A commercial license and priority support; the commercial license removes the restrictions of the
  AGPL license, and Posit Professional Drivers are available for database connectivity.
- Priority email support with an 8-hour response during business hours ET; pricing is quote-gated.

### Enterprise

- **RStudio within Posit Workbench** — managed RStudio sessions with enterprise auth, centrally
  managed from one console.

## AI

- **Posit Assistant** — an AI agent embedded in RStudio that reads the live session (loaded packages,
  variables, data frames) and answers from real data rather than generic assumptions; zero data
  retention.
- **Next Edit Suggestions** — background code completions for joins, parameter updates, and
  patterns; unlimited with a Posit AI subscription.
