# London System - Complete Guide

> **Aggression**: 10/100 (Solid)  
> **ECO**: A45-A48  
> **Study Priority**: #1 (White)  
> **Estimated Hours**: 8  
> **Best Against**: Everything, especially higher rated & tactical players

---

## Why London for You?

1. **System-based** - Same setup vs almost everything
2. **Minimal theory** - Learn plans, not moves
3. **Solid structure** - No weaknesses, hard to crack
4. **Scales to GM level** - Carlsen, Kramnik, MVL play it
5. **Teaches maneuvering** - Pure chess understanding

---

## Core Setup

```chess
1.d4 d5 2.Bf4
```

**Standard development:**
```
3.e3 Nf6 4.Nf3 e6 5.Bd3 Bd6 6.Bxd6 Qxd6 7.Nbd2 0-0 8.0-0 c5 9.c3 Nc6 10.Ne5
```

**Key pieces:**
- **Bf4** - Outside pawn chain, eyes kingside
- **e3** - Solid, supports d4, frees Bf1
- **c3** - Supports d4, prepares Qb3, frees Nc3
- **Nbd2** - Keeps c3 free, goes to e4/c4
- **Ne5** - **The dream outpost** - dominates

## Main Lines

### 1. Classical Main Line
```
1.d4 d5 2.Bf4 Nf6 3.e3 e6 4.Nf3 Bd6 5.Bxd6 Qxd6 6.Nbd2 0-0 7.Bd3 c5 8.c3 Nc6 9.Ne5
```
**Plan**: Ne5, f3, Qf2, Rac1, control c5/e5, minority attack (b3, a4, Rb1, Na3-c4)

### 2. Jobava London (More Active, Agg 25)
```
1.d4 d5 2.Nc3 Nf6 3.Bf4
```
Avoids some anti-London prep. Same ideas, Nc3 instead of e3.

### 3. vs ...g6 (King's Indian Setup)
```
1.d4 Nf6 2.Bf4 g6 3.Nf3 Bg7 4.e3 d6 5.Be2 0-0 6.0-0 c5 7.c3 Nc6 8.Nbd2
```
Solid. Prevent ...e5 with Qb3 ideas.

### 4. vs ...c5 (Early Break)
```
1.d4 d5 2.Bf4 c5 3.e3 Nc6 4.c3 Nf6 5.Nf3 cxd4 6.exd4 Qb6 7.Qb3
```
Qb3 hits b7/d5. Solid.

## Key Strategic Ideas

### 1. The Ne5 Outpost
**Maneuver**: Nf3-h4-f3-e5 OR Nf3-d2-e4 OR Nbd2-f1-e3
- Controls c6, d7, f7, g6
- Trade bad pieces (especially Black's dark-squared bishop)
- Often worth a pawn in positional value

### 2. Minority Attack (Queenside)
```
b3 -> a4 -> Rb1 -> Na3 -> Nc4 -> b5! -> axb5 -> Nxb5
```
- Creates weak pawn on c6 or a7
- Long-term structural advantage
- Converts to endgame win

### 3. Dark-Squared Bishop Trade
**Bxd6** (after ...Bd6) or **Bh6** (after ...Bf5) - **ALWAYS trade dark bishops**
- Your light bishop (on d3) becomes good
- Black's dark squares weakened
- Simplifies to favorable endgame

### 4. Preventing ...c5 and ...e5
- **...c5**: Meet with c3, dxc5, or hold tension
- **...e5**: dxe5, Ne5 - you welcome it!

## Common Mistakes (Yours to Avoid)

| Mistake | Why Bad | Fix |
|---------|---------|-----|
| Premature Ne5 | Can be kicked by ...f6 | Prepare with f3/h3 first |
| Ignoring ...c5 | Opens position for Black | Always have c3 ready |
| Trading light bishop | Your only good bishop! | Keep Bd3, trade dark one |
| Rushing attack | No weaknesses to attack | Patience! Squeeze slowly |
| Auto-pilot moves | Miss tactical shots | Check checks/captures/threats |

| **61-80 (Aggressive)** | 2.Nc3 (Jobava), g3/Bg2 setup, kingside pawn storm. |

## Practice Positions

Set up and solve (5 min each):

1. **Ne5 Maneuver**: `r2q1rk1/pp2bppp/2np1n2/3Pp3/2P1P3/2N2N2/PP1Q1PPP/R4RK1 w - - 0 1` → Find Ne5 path
2. **Minority Attack**: `r1bq1rk1/pp2ppbp/2np1np1/8/2PPP3/2N2N2/PP3PPP/R1BQ1RK1 w - - 0 1` → Plan b3-a4-Rb1
3. **...c5 Break**: `rnbq1rk1/pp2ppbp/3p1np1/2pP4/2P1P3/2N2N2/PP3PPP/R1BQ1RK1 w - - 0 1` → Handle ...c5
4. **Conversion**: `8/5k2/3p4/3P4/3K4/8/8/8 w - - 0 1` → Basic K+P opposition win
