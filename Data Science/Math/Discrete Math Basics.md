# Discrete Math Basics

Discrete mathematics deals with countable, distinct structures. It is the foundation of computer science and algorithm design.

## 1. Set Theory
- **Set**: A collection of distinct objects.
- **Union ($\cup$)**: All elements in either set.
- **Intersection ($\cap$)**: Elements common to both sets.
- **Complement**: Elements not in the set.
- **Power Set**: The set of all subsets.

## 2. Logic and Boolean Algebra
- **Propositions**: Statements that are either True or False.
- **Logical Operators**:
    - **AND ($\wedge$)**: True only if both are true.
    - **OR ($\vee$)**: True if at least one is true.
    - **NOT ($\neg$)**: Flips the truth value.
    - **IF-THEN ($\rightarrow$)**: Implication.
- **Truth Tables**: Used to determine the validity of complex logical expressions.

## 3. Combinatorics
The study of counting.
- **Permutations**: Order matters. $P(n, r) = \frac{n!}{(n-r)!}$.
- **Combinations**: Order does not matter. $C(n, r) = \binom{n}{r} = \frac{n!}{r!(n-r)!}$.
- **Pigeonhole Principle**: If $n$ items are put into $m$ containers and $n > m$, at least one container must contain more than one item.

## 4. Graph Theory Basics
- **Graph**: A set of vertices (nodes) connected by edges.
- **Directed vs. Undirected**: Whether edges have a specific direction.
- **Weighted Graphs**: When edges have values (e.g., distance between cities).
- **Path**: A sequence of edges connecting a sequence of vertices.
