## Study Strategy

### Week 1-2: Core 100
- [ ] Pronouns + Question words
- [ ] 30 Basic verbs (recognize + conjugate)
- [ ] 20 い-adj + 15 な-adj
- [ ] Numbers 1-10,000 + 5 basic counters
- [ ] 30 Adverbs + 15 Conjunctions
- [ ] Survival phrases

### Week 3-4: Expand to 300
- [ ] Next 100 nouns by category
- [ ] All counters (irregular readings)
- [ ] Verb compounds (〜始める, 〜終わる, 〜すぎる)
- [ ] Compound nouns (学校 + 先生 = 先生...)

### Ongoing: Anki Deck Structure
```
Card Type 1: Recognition (JP → EN)
Card Type 2: Production (EN → JP) 
Card Type 3: Audio → Meaning
Card Type 4: Cloze (sentence context)
```
