# Basic Sentence Structure

## Core Principle: SOV + Topic-Comment

### English: SVO
> I **eat** an apple.
> S  V   O

### Japanese: SOV (with Topic-Comment overlay)
> 私は りんごを **食べます**。
> Topic  Object  **Verb**
> (As for me) (apple)    **eat**

**The verb ALWAYS comes at the end.** Everything else is flexible.

---

## Sentence Types

### 1. A は B です (Noun = Noun)
**Topic は Noun です**

| Japanese | Structure | English |
|----------|-----------|---------|
| 私は学生です。 | Topic は Noun です | I am a student. |
| これは本です。 | Topic は Noun です | This is a book. |
| 田中さんは先生です。 | Topic は Noun です | Tanaka-san is a teacher. |

**Negation**: ではありません (dewa arimasen) / じゃありません (ja arimasen)
- 私は学生**ではありません**。→ I am **not** a student.

**Past**: でした / ではありませんでした
- 私は学生**でした**。→ I **was** a student.

---

### 2. A は [い-adj] です (Topic + い-adjective)
**Topic は い-adj です**

| Japanese | Structure | English |
|----------|-----------|---------|
| このりんごは甘いです。 | Topic は い-adj です | This apple is sweet. |
| 今日は寒いです。 | Topic は い-adj です | Today is cold. |

**Negation**: 〜くありません / 〜くないです
- 甘くありません / 甘くないです → Not sweet

**Past**: 〜かったです / 〜くなかったです
- 甘かったです → Was sweet
- 甘くなかったです → Was not sweet

> **Note**: い-adjectives conjugate! です is just politeness marker here.

---

### 3. A は [な-adj] です (Topic + な-adjective)
**Topic は な-adj です**

| Japanese | Structure | English |
|----------|-----------|---------|
| この部屋は静かです。 | Topic は な-adj です | This room is quiet. |
| 彼は元気です。 | Topic は な-adj です | He is healthy/energetic. |

**Negation**: ではありません / じゃありません
- 静かではありません → Not quiet

**Past**: でした / ではありませんでした
- 静かでした → Was quiet

> **Note**: な-adjectives act like nouns! They need です for predication.

---

### 4. A は [Verb] (Topic + Verb)
**Topic は Object/Location/etc. Verb**

| Japanese | Structure | English |
|----------|-----------|---------|
| 私はりんごを食べます。 | Topic は Object を Verb | I eat an apple. |
| 田中さんは図書館で勉強します。 | Topic は Location で Verb | Tanaka-san studies at the library. |
| 電車が来ます。 | Subject が Verb | The train comes. |

**Verb Position**: ALWAYS FINAL. No exceptions in main clauses.

---

## Topic vs Subject: The Critical Distinction

### Topic (は) = "As for X..."
- Known information
- Sets the "stage"
- Can be any noun phrase

### Subject (が) = The grammatical subject of the predicate
- New information
- Required for statives, adjectives, intransitives, potentials

### Double-Subject Construction (Common!)
> **Topic は Subject が Predicate**

| Japanese | Literal | Natural English |
|----------|---------|-----------------|
| **私は** **日本語が** わかります。 | As for me, Japanese is understandable. | I understand Japanese. |
| **象は** **鼻が** 長い。 | As for elephant, nose is long. | Elephants have long trunks. |
| **この店は** **コーヒーが** おいしい。 | As for this shop, coffee is delicious. | This shop has delicious coffee. |

## Word Order Flexibility (Scrambling)

**Before the verb**, constituents can reorder for emphasis/focus:

| Order | Example | Nuance |
|-------|---------|--------|
| **SOV** (neutral) | 私が りんごを 食べた。 | I ate an apple. |
| **OSV** (object focus) | りんごを 私が 食べた。 | **The apple** (not something else), I ate. |
| **Topic-OSV** | 私は りんごを 昨日 食べた。 | As for me, the apple, yesterday ate. |

**Rule**: Particles tell you the role. Word order tells you emphasis.

## The Copula System: だ / です / である / であります

| Form | Politeness | Usage |
|------|------------|-------|
| **だ** (da) | Plain/Casual | Nouns, な-adj: 学生だ, 静かだ |
| **です** (desu) | Polite | Nouns, な-adj, い-adj: 学生です, 静かです, 甘いです |
| **である** (de aru) | Formal/Written | Essays, papers, news: 学生である |
| **であります** (de arimasu) | Formal polite | Military, very formal speech |

**Conjugation of だ/です**:

| Tense | Plain (だ) | Polite (です) |
|-------|------------|---------------|
| Present | だ / (none for な-adj) | です |
| Negative | ではない / じゃない | ではありません / じゃありません |
| Past | だった | でした |
| Past Negative | ではなかった / じゃなかった | ではありませんでした / じゃありませんでした |

> **い-adjectives don't use だ!** 甘いだ ✗ → 甘い ○ / 甘いです ○

## Question Formation

### 1. か (ka) - Formal Question Marker
- 学生ですか。 → Are you a student?
- おいしいですか。 → Is it delicious?

### 2. Rising Intonation (Casual)
- 学生？ → Student?
- おいしい？ → Delicious?

### 3. の (no) / ん (n) - Explanatory Question
- どうして来なかった**の**？ → Why didn't you come? (seeking explanation)
- 忙しい**ん**ですか。 → Is it that you're busy?

### 4. Wh-Questions (Question Word Stays In Place!)
| Question Word | Example | Note |
|---------------|---------|------|
| **何** (なに/なん) | これは**何**ですか？ | What is this? |
| **誰** (だれ) | **誰**が来ますか？ | Who comes? (subject → が) |
| **どこ** | **どこ**へ行きますか？ | Where to? |
| **いつ** | **いつ**来ますか？ | When? (no に for relative time) |
| **なぜ / どうして** | **なぜ**来ませんか？ | Why? |
| **どう** | **どう**でしたか？ | How was it? |
| **どれ / どの / どっち** | **どれ**がいいですか？ | Which one? |

> **Critical**: Japanese wh-words do NOT move to front! They stay in their grammatical position.

## Negation Summary

| Predicate Type | Plain Negative | Polite Negative |
|----------------|----------------|-----------------|
| **Verb (ます)** | 〜ない (dictionary→ない) | 〜ません |
| **い-adjective** | 〜くない | 〜くありません / 〜くないです |
| **な-adjective** | 〜ではない / 〜じゃない | 〜ではありません / 〜じゃありません |
| **Noun + です** | 〜ではない / 〜じゃない | 〜ではありません / 〜じゃありません |

---

## Tense Summary (Polite Forms)

| Type | Present/Future | Past |
|------|----------------|------|
| **Verb (ます)** | 食べます | 食べました |
| **Verb (ます) Neg** | 食べません | 食べませんでした |
| **い-adj** | 甘いです | 甘かったです |
| **い-adj Neg** | 甘くありません | 甘くありませんでした |
| **な-adj** | 静かです | 静かでした |
| **な-adj Neg** | 静かではありません | 静かではありませんでした |
| **Noun** | 学生です | 学生でした |
| **Noun Neg** | 学生ではありません | 学生ではありませんでした |

## Existence: ある vs いる

| | Animate (People, Animals) | Inanimate (Objects, Plants, Places) |
|---|---|---|
| **Exists** | いる (iru) | ある (aru) |
| **Polite** | います (imasu) | あります (arimasu) |
| **Location marker** | **に** | **に** |

| Example | Translation |
|---------|-------------|
| ここに猫が**います**。 | There is a cat here. |
| 机の上に本が**あります**。 | There is a book on the desk. |
| 誰か**いますか**？ | Is anyone there? |
| 何**かありますか**？ | Is there anything? |

> **Note**: ある also used for "have" with に: 私は車が**あります** (I have a car - lit. "At me, car exists")

## Basic Sentence Templates (Memorize These)

### 1. Introduction
> **私は [Name] です。** → I am [Name].
> **私は [Country] 人です。** → I am from [Country].

### 2. Likes/Dislikes (Stative → が)
> **私は [Noun] が好きです。** → I like [Noun].
> **私は [Noun] が嫌いです。** → I dislike [Noun].
> **私は [Verb-stem] ことが好きです。** → I like doing [Verb].

### 3. Want (Adjective → が)
> **私は [Noun] が欲しいです。** → I want [Noun].
> **私は [Verb-stem] たいです。** → I want to [Verb].

### 4. Ability (Potential → が)
> **私は [Noun] ができます。** → I can [Noun].
> **私は [Verb-possible] ことができます。** → I can [Verb].

### 5. Existence
> **[Place] に [Thing] があります/います。** → There is [Thing] at [Place].

### 6. Motion
> **[Place] に/へ 行きます/来ます/帰ります。** → Go/Come/Return to [Place].

### 7. Action with Object
> **[Topic] は [Object] を [Verb]ます。** → [Topic] [Verb]s [Object].

### 8. Action at Location
> **[Topic] は [Place] で [Verb]ます。** → [Topic] [Verb]s at [Place].

### 9. Means/Instrument
> **[Topic] は [Means] で [Verb]ます。** → [Topic] [Verb]s by [Means].

### 10. Time
> **[Topic] は [Time] に [Verb]ます。** → [Topic] [Verb]s at [Time].
