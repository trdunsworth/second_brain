# Counters & Classifiers (助数詞 - じょすうし)

## Overview
Japanese **requires counters** for counting. You cannot say "three books" as "三本" - you must use the correct classifier for the object type.

**Structure**: Number + Counter (+ Particle)

---

## Asking "How Many?"

| Counter | Question Form |
|---------|---------------|
| General (つ) | **いくつ**ですか？ |
| People | **何人** (なんにん) ですか？ |
| Small objects | **何個** (なんこ) ですか？ |
| Long objects | **何本** (なんぼん) ですか？ |
| Flat objects | **何枚** (なんまい) ですか？ |

| Books | **何冊** (なんさつ) ですか？ |
| Age | **何歳** (なんさい) ですか？ |

## Counters with で (Means/Group) vs を (Object)

| Structure | Meaning | Example |
|-----------|---------|---------|
| **Counter + で** | In groups of / By means of | **三人で**行く (Go in a group of 3) |
| **Counter + を** | Count as object | **三人を**招待した (Invited 3 people) |
