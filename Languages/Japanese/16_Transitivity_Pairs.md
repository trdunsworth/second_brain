# Transitivity Pairs (自動詞 vs 他動詞) - Complete Guide

## Core Concept

| Type | Japanese | English | Subject | Object | Particle |
|------|----------|---------|---------|--------|----------|
| **Intransitive** (自動詞 - じどうし) | **動作が自分で完結** | Action completes within subject | **が** | — | **が** |
| **Transitive** (他動詞 - たどうし) | **動作が他に及ぶ** | Action extends to object | **が/は** | **を** | **を** |

> **Key**: Same action, different perspective. "The door opens" vs "I open the door."

## Major Transitivity Patterns

### Pattern 1: -aru (Intrans) ↔ -eru (Trans) **Most Common!**
| Intransitive | Transitive | Meaning |
|--------------|------------|---------|
| 開く (aku) | 開ける (akeru) | Open |
| 閉まる (shimaru) | 閉める (shimeru) | Close |
| 付く (tsuku) | 付ける (tsukeru) | Attach / Turn on |
| 消える (kieru) | 消す (kesu) | Disappear / Erase |
| 始まる (hajimaru) | 始める (hajimeru) | Begin |
| 終わる (owaru) | 終わらせる (owarasaseru) | End |
| 集まる (atsumaru) | 集める (atsumeru) | Gather |
| 決まる (kimaru) | 決める (kimeru) | Decide |
| 変わる (kawaru) | 変える (kaeru) | Change |
| 入る (hairu) | 入れる (ireru) | Enter / Insert |
| 溢れる (afureru) | 溢れさせる (afuresaseru) | Overflow |

### Pattern 2: -ru (Intrans) ↔ -su (Trans)
| Intransitive | Transitive | Meaning |
|--------------|------------|---------|
| 落ちる (ochiru) | 落とす (otosu) | Fall / Drop |
| 割れる (wareru) | 割る (waru) | Break (intrans) / Break (trans) |
| 切れる (kireru) | 切る (kiru) | Cut (be cut) / Cut |
| 止まる (tomaru) | 止める (tomeru) | Stop |
| 曲がる (magaru) | 曲げる (mageru) | Bend |
| 伸びる (nobiru) | 伸ばす (nobasu) | Stretch/Extend |
| 縮む (chijimu) | 縮める (chijimeru) | Shrink |
| 潰れる (tsubureru) | 潰す (tsubusu) | Crush |

### Pattern 3: -eru (Intrans) ↔ -asu (Trans) [Causative-like]
| Intransitive | Transitive | Meaning |
|--------------|------------|---------|
| 出る (deru) | 出す (dasu) | Exit / Take out |
| 起きる (okiru) | 起こす (okosu) | Wake up / Wake someone |
| 増える (fueru) | 増やす (fuyasu) | Increase |
| 減る (heru) | 減らす (herasu) | Decrease |
| 直る (naoru) | 直す (naosu) | Heal / Fix |
| 治る (naoru) | 治す (naosu) | Recover / Cure |

### Pattern 4: Same Form (Context Determines)
| Verb | Intransitive Use | Transitive Use |
|------|------------------|----------------|
| 開く (hiraku) | ドアが開く | ドアを開く (rare, usually 開ける) |
| 回る (mawaru) | 地球が回る | 部屋を回る (tour) |
| 渡る (wataru) | 橋を渡る | 川を渡す (ferry across) |

## Particle Rules (Ironclad)

### Intransitive → **が** (Subject)
> ドア**が**開いた。 (The door opened.)
> 電車**が**来た。 (The train came.)
> 花**が**咲いた。 (Flowers bloomed.)

### Transitive → **を** (Object)
> 私がドア**を**開けた。 (I opened the door.)
> 田中さんが本**を**読んだ。 (Tanaka read a book.)

### With Potential Form (Transitive)
> **Original**: 本**を**読む → **Potential**: 本**が/を**読める
> **Modern usage**: Both が and を accepted, が more traditional

### With Causative (Transitive)
> 先生が学生**に**本**を**読ませた。 (Teacher made student read book.)
> **Agent = に**, **Object = を**

### With Passive (Transitive)
> 本**が**田中さん**に**読まれた。 (Book was read by Tanaka.)
> **Subject = が**, **Agent = に**

## Stative Transitives (Special Class)

These are **transitive in form** but **stative in meaning** - they take **が** for the "object":

| Verb | Meaning | Particle | Example |
|------|---------|----------|---------|
| **分かる** (wakaru) | Understand | **が** | 日本語**が**分かる。 |
| **できる** (dekiru) | Can do | **が** | ピアノ**が**できる。 |
| **要る** (iru) | Need | **が** | お金**が**要る。 |
| **ある** (aru) - existence | Exist (inanimate) | **が** | 本**が**ある。 |
| **いる** (iru) - existence | Exist (animate) | **が** | 猫**が**いる。 |

> **Why が?**: These describe a **state of the subject**, not an action on an object. "Japanese is understandable (to me)" not "I understand Japanese."

## Transitivity in Compound Verbs

### V1 + V2: Transitivity follows V2 (usually)

| Compound | Transitivity | Reason |
|----------|--------------|--------|
| **持ち帰る** (mochikaeru) | Transitive | 帰る is intrans but 持つ is trans + object |
| **歩き回る** (arukimawaru) | Intransitive | 回る is intrans |
| **読み終わる** (yomiowaru) | Transitive | 終わる can be trans (終わらせる) but here intrans |
| **書き始める** (kakihajimeru) | Transitive | 始める is transitive |

> **Rule**: The **final verb (V2)** determines transitivity of the compound.

## Transitivity & Aspect: ている vs てある vs ておく

| Form | Transitivity | Meaning | Example |
|------|--------------|---------|---------|
| **ている** | Both | Progressive / Result state | ドアが開いている (Door is open) / ドアを開けている (Opening door) |
| **てある** | **Transitive only** | Intentional result state | ドアが開けてある (Door has been opened intentionally) |
| **ておく** | **Transitive only** | Preparation for future | ドアを開けておく (Open door in advance) |

> **Critical**: てある・ておく **require transitive verbs**!
> - 窓が開いてある ✗ (Intransitive)
> - 窓が開けてある ○ (Transitive: someone opened it)

## Causative & Passive: Transitivity Shifts

### Causative: Intrans → Trans, Trans → Ditransitive
| Base | Type | Causative | New Structure |
|------|------|-----------|---------------|
| 泣く (naku) | Intrans | 泣かせる (nakaseru) | 赤ちゃん**を**泣かせる (Make baby cry) |
| 食べる (taberu) | Trans | 食べさせる (tabesaseru) | 子供**に**ケーキ**を**食べさせる |

### Passive: Trans → Intrans
| Base | Type | Passive | New Structure |
|------|------|---------|---------------|
| 褒める (homeru) | Trans | 褒められる (homerareru) | 田中さん**が**先生**に**褒められた |

### Adversative Passive (Intrans → Passive = "Suffer")
| Base | Type | Passive | Meaning |
|------|------|---------|---------|
| 死ぬ (shinu) | Intrans | 死なれる (shinareru) | Someone died (on me / to my detriment) |
| 雨が降る | Intrans | 雨が降られた | It rained (on me / unfortunate) |

## Transitivity Diagnostic Tests

### Test 1: Can you say "XをY"?
- **Yes** → Transitive (or stative transitive)
- **No** → Intransitive

### Test 2: Does it have a direct object?
- **Yes** → Transitive
- **No** → Intransitive

### Test 3: Can you make it passive?
- **Yes** → Transitive
- **No** → Intransitive (unless adversative)

### Test 4: ている = State or Action?
- **State** (door is open) → Often intransitive origin
- **Action** (opening door) → Transitive

## Common Mistake Pairs

| Mistake | Correct | Reason |
|---------|---------|--------|
| ドアを**開いた** | ドアを**開けた** | Transitive needed |
| 私が**開ける** | 私が**開ける** | (Actually OK - transitive) |
| 電車を**着いた** | 電車が**着いた** / 電車に**着いた** | 着く is intransitive |
| 窓が**開けてある** | 窓が**開けてある** | OK (transitive base) |
| 窓が**開いてある** | 窓が**開いている** | てある needs transitive |
| 本が**読める** | 本が**読める** | OK (stative transitive) |
| 本を**読める** | 本を**読める** | Also OK (modern) |

## Practice: Choose Intransitive/Transitive

1. 氷が___。 (溶ける/溶かす) → **溶ける** (Intrans: ice melts)
2. 氷を___。 (溶ける/溶かす) → **溶かす** (Trans: melt the ice)
3. ドアが___。 (開く/開ける) → **開く**
4. ドアを___。 (開く/開ける) → **開ける**
5. 会議が___。 (始まる/始める) → **始まる**
6. 会議を___。 (始まる/始める) → **始める**
7. 電気が___。 (付く/付ける) → **付く**
8. 電気を___。 (付く/付ける) → **付ける**
9. 宿題が___。 (終わる/終わらせる) → **終わる**
10. 宿題を___。 (終わる/終わらせる) → **終わらせる**

*Transitivity is binary but the pairs are systematic. Learn the 4 major patterns (-aru/-eru, -ru/-su, -eru/-asu, same-form). Once you know the pattern, you can predict the pair.*
