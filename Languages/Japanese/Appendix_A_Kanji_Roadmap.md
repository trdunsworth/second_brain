# Kanji Learning Roadmap (漢字学習ロードマップ)

## Philosophy: Kanji in Context, Not Isolation

**Core Principle**: Learn kanji **through vocabulary**, not as abstract symbols. The brain acquires orthography **incidentally** through massive reading. Explicit study accelerates but cannot replace exposure.

---

| Level | Kanji Count | Vocabulary | Use Case |

## Learning Sequence Options

### Option 1: Frequency-Based (Recommended)
**Order**: By **corpus frequency** (newspapers, novels, web)
- **Pros**: Highest ROI, matches real usage
- **Cons**: Non-linear, mixes simple/complex shapes
- **Resources**: **Kanji Garden**, **WaniKani** (modified), **Anki "2.136 Joyo by Frequency"**

### Option 2: RTK (Remembering the Kanji) - Heisig
**Order**: By **component logic** (primitives → complex)
- **Pros**: Systematic, memorable stories, separates meaning/reading
- **Cons**: No readings/vocab initially, abstract keywords
- **Best for**: Visual learners, those wanting writing ability fast
- **Follow with**: **Kanji in Context** or **Kodansha Kanji Learner's Course**

### Option 3: Grade Level (Japanese School Order)
**Order**: 1st grade (80) → 2nd (160) → ... → 6th (1,026) → Secondary (1,110)
- **Pros**: Matches native materials, graded readers
- **Cons**: Low-frequency kanji early (e.g., 曜 in 2nd grade)
- **Best for**: Those using Japanese school materials

### Option 4: JLPT Level Order
**Order**: N5 → N4 → N3 → N2 → N1
- **Pros**: Test-aligned, clear milestones
- **Cons**: Test-specific, not pure frequency

---

## Recommended Hybrid Approach

### Phase 1: RTK Lite (First 500-1,000)
- **Goal**: Recognize shape/meaning, write from memory
- **Method**: Heisig's component stories (skip writing if not needed)
- **Time**: 2-3 months @ 15-20/day
- **Output**: "Kanji goggles" - see structure, not noise

### Phase 2: Vocabulary-Driven (Next 1,500+)
- **Goal**: Readings + vocabulary in context
- **Method**: **Sentence mining** + **Anki** (targeted cards)
- **Source**: **Core 2000/6000**, **Tango N5-N1**, **Novel sentences**
- **Card type**: **Recognition** (Kanji→Reading/Meaning) + **Production** (Keyword→Kanji) optional

### Phase 3: Maintenance + Expansion (Ongoing)
- **Method**: **Extensive reading** (graded → native)
- **Tool**: **Yomichan** + **Anki** auto-mining
- **Target**: 3,000+ recognition, 2,000+ production

## Kanji Card Templates (Anki)

### Type 1: Recognition (Primary)
```
Front:  **漢字** (single kanji or word)
Back:   **Reading** (kana) | **Meaning** (English) | **Example word** + sentence
```
**Use for**: 90% of cards. Builds reading fluency.

### Type 2: Production (Optional)
```
Front:  **Keyword** (Heisig meaning) or **English meaning**
Back:   **漢字** | **Reading** | **Component breakdown**
```
**Use for**: Writing practice, if handwriting needed.

### Type 3: Vocabulary Context (Essential)
```
Front:  **Sentence with target word bolded** (kanji + kana)
Back:   **Reading** | **Translation** | **Target word breakdown**
```
**Use for**: Real acquisition. Kanji learned **in context**.

### Type 4: Similar Kanji Discrimination
```
Front:  **Target kanji** + **2-3 confusing kanji**
Back:   **Differences highlighted** (component, reading, meaning)
```
**Use for**: Problem pairs (e.g., 土/士, 末/未, 入/人, 方/万).

## Reading vs Writing: The Great Debate

| Skill | Necessity | Method |
|-------|-----------|--------|
| **Recognition (Reading)** | **ESSENTIAL** | Massive input + Anki recognition cards |
| **Production (Writing)** | **OPTIONAL** | Only if: living in Japan, exams, calligraphy interest |
| **Handwriting** | **RARELY NEEDED** | Phones/PCs handle 99% of writing |

> **Recommendation**: **Skip handwriting** unless specifically required. Invest time in **reading volume** instead.

## Weekly Kanji Routine (30 min/day)

| Day | Activity | Time |
|-----|----------|------|
| **Mon** | Anki reviews (recognition) + 10 new cards | 20 min |
| **Tue** | Anki reviews + 10 new + **writing practice** (optional) | 25 min |
| **Wed** | Anki reviews + **sentence mining** (5 sentences) | 25 min |
| **Thu** | Anki reviews + 10 new + **component review** | 20 min |
| **Fri** | Anki reviews + **similar kanji drill** | 20 min |
| **Sat** | **Extensive reading** (30 min) - no SRS | 30 min |
| **Sun** | **Rest** or **light review** | 10 min |

---

*Kanji is a **marathon**, not a sprint. Consistency > intensity. 15 min daily > 3 hours weekly. The goal is **reading fluency**, not calligraphy. Trust the process: massive input + targeted SRS = acquisition.*
