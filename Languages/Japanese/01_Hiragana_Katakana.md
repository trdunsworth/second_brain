### Sokuon (促音) - Small つ (Geminate Consonants)
- **っ** before k, s, t, p → doubles the following consonant
- きっと (kitto), さって (satte), かった (katta), ざっし (zasshi)
- **Not used before**: n, m, y, r, w, vowels, h (except in loanwords: バッハ Bahha)

## Pronunciation Notes

### Vowel Devoicing
- **i** and **u** become whispered/devoiced between voiceless consonants (k, s, t, p, h) or at utterance end
- すき (suki) → [sɯ̥ki], です (desu) → [desɯ̥]
- Not devoiced: after voiced consonants, in isolation, or when emphasized

### Pitch Accent Basics
- Japanese has **pitch accent** (not stress accent)
- Each mora has high or low pitch
- **Accent nucleus**: the last high-pitched mora before a drop
- Dictionary form: usually **heiban** (flat) or **atamadaka** (head-high) or **nakadaka** (middle-high)
- Example: はし (hashi) - "chopsticks" [HL] vs "bridge" [LH] vs "edge" [LHL]

### Mora Timing
- Each kana = 1 mora (beat)
- ん, っ, long vowel marker = 1 mora each
- とうきょう (toukyou) = 4 morae: to-u-kyo-u

## Stroke Order Principles
1. **Top to bottom**
2. **Left to right**
3. **Horizontal before vertical** (when crossing)
4. **Center before wings** (symmetrical characters)
5. **Enclosing before contents**
6. **Dots and minor strokes last**

## Common Pitfalls
| Pitfall | Solution |
|---------|----------|
| し vs つ | し = "she" curve; つ = "tsu" two strokes |
| ん vs そ | ん = one stroke; そ = two strokes (zigzag) |
| シ vs ツ | シ = horizontal alignment; ツ = vertical alignment |
| ン vs ソ | ン = horizontal; ソ = vertical |
| ロ vs る | ロ = square; る = loop |
| わ vs れ | わ = open bottom; れ = loop |
| ね vs れ | ね = extra loop at bottom |
| め vs ぬ | め = cross in middle; ぬ = loop at bottom |
