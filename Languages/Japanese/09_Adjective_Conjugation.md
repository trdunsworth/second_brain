# Adjective Conjugation - Complete Tables

## い-Adjectives (形容詞) - Full Paradigm

### Base: 高い (takai - expensive/high)

| Form | Suffix/Change | Result | Example Sentence |
|------|---------------|--------|------------------|
| **Plain Present** | (base) | 高い | この本は高い。 |
| **Polite Present** | + です | 高いです | この本は高いです。 |
| **Plain Negative** | い → く + ない | 高くない | この本は高くない。 |
| **Polite Negative** | い → く + ありません / ないです | 高くありません / 高くないです | この本は高くありません。 |
| **Plain Past** | い → かっ + た | 高かった | この本は高かった。 |
| **Polite Past** | い → かっ + た + です | 高かったです | この本は高かったです。 |
| **Plain Past Negative** | い → く + なかっ + た | 高くなかった | この本は高くなかった。 |
| **Polite Past Negative** | い → く + ありませんでした / なったです | 高くありませんでした / 高くなかったです | この本は高くありませんでした。 |
| **て-form** | い → く + て | 高くて | 高くて買えない。 |
| **Adverbial** | い → く | 高く | 高く売る。 |
| **Conditional (ば)** | い → けれ + ば | 高ければ | 高ければ買わない。 |
| **Conditional (なら)** | (base) + なら | 高いなら | 高いなら買わない。 |
| **Stem (Nominal)** | い → さ | 高さ | 高さが違う。 |
| **Seems (そう)** | い → そう | 高そう | 高そうだ。 |
| **Too (すぎる)** | い → すぎる | 高すぎる | 高すぎる。 |
| **Easy/Hard** | い → やすい/にくい | 高やすい/高にくい | (rare for this adj) |
| **Noun modifier** | (base) | 高い | 高い本 |

## Special Cases

### 同じ (onaji - same) - な-adj but no な
| Form | Result |

| Plain Present | 同じだ |
| Polite Present | 同じです |
| Negative | 同じではない / 同じじゃない |

| て-form | 同じで |
| Adverb | 同じに |
| なら | 同じなら |
| Noun mod | 同じ (no な!) |

### 大きい/小さい - Can be both
| Usage | 大きい | 小さい |
|-------|--------|--------|
| **い-adj (standard)** | 大きくない, 大きかった | 小さくない, 小さかった |
| **な-adj (formal/written)** | 大きな (attributive only) | 小さな (attributive only) |
| **Noun mod (な-form)** | 大きな家 | 小さな家 |
| **Predicate** | 大きいだ ✗ → 大きいだ/大きいです | 小さいだ ✗ → 小さいです |

> **大きな/小さな** ONLY used before nouns, NEVER as predicate!

## Adjective + する / なる (Change of State)

| Pattern | Meaning | Example |
|---------|---------|---------|
| **い-adj く + する** | Make [adj] (transitive) | 部屋を**きれいにする** (make room clean) |
| **な-adj に + する** | Make [adj] (transitive) | 音を**静かにする** (make sound quiet) |
| **い-adj く + なる** | Become [adj] (intransitive) | 暗く**なる** (becomes dark) |
| **な-adj に + なる** | Become [adj] (intransitive) | 便利**になる** (becomes convenient) |

**Note**: きれい (kirei) and 嫌い (kirai) are な-adjectives despite ending in い!
- きれい**に**する / きれい**に**なる
- 嫌い**に**する / 嫌い**に**なる (rare)

## Comparison Structures with Adjectives

### Comparative: A より B のほうが [Adj]
- **この本より、あの本のほうが高い。** (That book is more expensive than this one.)

### Superlative: [Group] で 一番 [Adj]
- **クラスで一番背が高い。** (Tallest in class.)

### "More": もっと / さらに + [Adj]
- **もっと高い** (more expensive)
- **さらに難しい** (even more difficult)

### "Less": あまり / 全然 + [Neg Adj]
- **あまり高くない** (not very expensive)
- **全然面白くない** (not interesting at all)

### "As...as": A と 同程度 / A ほど [Adj] ない
- **彼ほど背が高くない。** (Not as tall as him.)

### "The more..., the more...": 〜ば〜ほど
- **早ければ早いほどいい。** (The earlier, the better.)
- **高ければ高いほど売れる。** (The more expensive, the better it sells.)

| Adjective Type | Suffix | Example | Meaning |
|----------------|--------|---------|---------|
| **い-adj** | い → さ | 高さ, 深さ, 重さ, 暑さ, 寒さ, 速さ, 遅さ, 長さ, 短さ, 厚さ, 薄さ | Height, depth, weight, heat, cold, speed, slowness, length, shortness, thickness, thinness |

| **Color い-adj** | い → さ | 白さ, 黒さ, 赤さ, 青さ, 黄色さ | Whiteness, blackness, redness, blueness, yellowness |
