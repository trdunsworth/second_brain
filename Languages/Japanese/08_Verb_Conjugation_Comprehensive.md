# Verb Conjugation - Complete Reference

## Overview: The 6 Stem Forms (六つの活用形)

Every Japanese verb has **6 stem forms** (活用形 - katsuyoukei). All conjugations attach to these stems.

| Stem Form | Japanese | Function | Attaches to... |
|-----------|----------|----------|----------------|
| **未然形** (Mizenkei) | Imperfective | Negative, causative, passive, volitional | ない, せる/させる, れる/られる, う/よう |
| **連用形** (Ren'youkei) | Continuative | Polite, past, te-form, noun modification, compound verbs | ます, た/だ, て/で, たい, にいく, 〜始める |
| **終止形** (Shuushikei) | Terminal | Sentence-end (plain present) | (nothing) - dictionary form |
| **連体形** (Rentaikei) | Attributive | Modifies nouns | (nothing) - same as terminal in modern Japanese |
| **已然形/仮定形** (Izenkei/Kateikei) | Hypothetical | Conditional ば | ば |
| **命令形** (Meireikei) | Imperative | Commands | (nothing) / ろ/よ |

## Godan (五段) - Complete Stem Table

**Verb: 書く (kaku - write)** - ends in **く** (k-row)

| Stem | Form | Suffix | Result | Used For |
|------|------|--------|--------|----------|
| **Mizen (a)** | Imperfective | -a | **書か** (kaka) | 書か**ない**, 書か**せる**, 書か**れる**, 書か**う** |
| **Ren'you (i)** | Continuative | -i | **書き** (kaki) | 書き**ます**, 書き**た**, 書き**て**, 書き**たい**, 書き**に行く** |
| **Shuushi (u)** | Terminal | -u | **書く** (kaku) | Plain present, dictionary |
| **Rentai (u)** | Attributive | -u | **書く** (kaku) | Modifies nouns: 書く**人** |
| **Katei (e)** | Hypothetical | -e | **書け** (kake) | 書け**ば** |
| **Meirei (e)** | Imperative | -e | **書け** (kake) | Command: 書け! |

### All Godan Rows (5 rows = 5 vowel grades)

| Row | Verb | Mizen (a) | Ren'you (i) | Shuushi (u) | Rentai (u) | Katei (e) | Meirei (e) |
|-----|------|-----------|-------------|-------------|------------|-----------|------------|
| **k** | 書く | 書か | 書き | 書く | 書く | 書け | 書け |
| **g** | 泳ぐ | 泳が | 泳ぎ | 泳ぐ | 泳ぐ | 泳げ | 泳げ |
| **s** | 話す | 話さ | 話し | 話す | 話す | 話せ | 話せ |
| **t** | 待つ | 待た | 待ち | 待つ | 待つ | 待て | 待て |
| **d** | 呼ぶ | 呼ば | 呼び | 呼ぶ | 呼ぶ | 呼べ | 呼べ |
| **n** | 死ぬ | 死な | 死に | 死ぬ | 死ぬ | 死ね | 死ね |
| **b** | 読む | 読ま | 読み | 読む | 読む | 読め | 読め |
| **m** | 買う | 買わ | 買い | 買う | 買う | 買え | 買え |
| **r** | 走る | 走ら | 走り | 走る | 走る | 走れ | 走れ |
| **w** | 会う | 会わ | 会い | 会う | 会う | 会え | 会え |

> **Special**: う-verbs (買う, 会う, 言う, 払う...) use **わ** in mizenkei (not あ)!
> 買わない, 会わない, 言わない, 払わない

## Ichidan (一段) - Complete Stem Table

**Verb: 食べる (taberu - eat)** - stem = **食べ** (tabe)

| Stem | Form | Result | Used For |
|------|------|--------|----------|
| **Mizen** | Imperfective | **食べ** (tabe) | 食べ**ない**, 食べ**させる**, 食べ**られる**, 食べ**よう** |
| **Ren'you** | Continuative | **食べ** (tabe) | 食べ**ます**, 食べ**た**, 食べ**て**, 食べ**たい**, 食べ**に行く** |
| **Shuushi** | Terminal | **食べる** (taberu) | Plain present |
| **Rentai** | Attributive | **食べる** (taberu) | Modifies nouns: 食べる**人** |
| **Katei** | Hypothetical | **食べれ** (tabere) | 食べれ**ば** |
| **Meirei** | Imperative | **食べろ** (tabero) / **食べよ** (tabe yo) | Command |

> **Key**: Ichidan has **ONE stem** (dictionary minus る). Mizen = Ren'you = Stem!

### Common Ichidan Verbs by Vowel

| **〜える** (e-ru) | **〜いる** (i-ru) |
|-------------------|-------------------|
| 開ける (akeru) | 見る (miru) |
| 閉める (shimeru) | 着る (kiru - wear) |
| 降りる (oriru) | 寝る (neru) |
| 入れる (ireru) | 起きる (okiru) |
| 変える (kaeru) | 似る (niru) |
| 選ぶ (erabu) - **GODAN!** | いる (iru - exist) - **IRREGULAR!** |
| 帰る (kaeru) - **GODAN!** | 知る (shiru) - **GODAN!** |

## Irregular Verbs - Complete Stems

### する (suru - do)

| Stem | Form | Result | Used For |
|------|------|--------|----------|
| **Mizen** | Imperfective | **し** (shi) / **せ** (se) | し**ない**, **せ**る (causative), **さ**せる, **さ**れる (passive), し**よう** |
| **Ren'you** | Continuative | **し** (shi) | し**ます**, し**た**, し**て**, し**たい** |
| **Shuushi** | Terminal | **する** (suru) | Plain present |
| **Rentai** | Attributive | **する** (suru) | Modifies nouns |
| **Katei** | Hypothetical | **すれ** (sure) | すれ**ば** |
| **Meirei** | Imperative | **しろ** (shiro) / **せよ** (seyo) | Command |

> **Note**: Two mizenkei stems: **し** (for ない, よう, させる) and **せ** (for せる/される)!

### 来る (kuru - come)

| Stem | Form | Result | Used For |
|------|------|--------|----------|
| **Mizen** | Imperfective | **こ** (ko) / **く** (ku) | こ**ない**, **こ**させる, **こ**られる, こ**よう** |
| **Ren'you** | Continuative | **き** (ki) | き**ます**, き**た**, き**て**, き**たい** |
| **Shuushi** | Terminal | **来る** (kuru) | Plain present |
| **Rentai** | Attributive | **来る** (kuru) | Modifies nouns |
| **Katei** | Hypothetical | **くれ** (kure) | くれ**ば** |
| **Meirei** | Imperative | **来い** (koi) / **来よ** (koyo) | Command |

## Derived Forms - Complete Conjugation Tables

### 1. Negative (〜ない) - Plain Negative
**Stem: Mizenkei + ない**

| Verb Type | Rule | Examples |
|-----------|------|----------|
| **Godan** | Mizen (a) + ない | 書かない, 行かない, 話さない, 待たない, 死なない, 呼ばない, 読まない, 買わない, 走らない, 会わない |
| **Ichidan** | Stem + ない | 食べない, 見ない, 寝ない, 起きない, 開けない, 閉めない |
| **する** | し + ない | しない |
| **来る** | こ + ない | こない |

### 2. Polite (〜ます) - ます-form
**Stem: Ren'youkei + ます**

| Verb Type | Rule | Examples |
|-----------|------|----------|
| **Godan** | Ren'you (i) + ます | 書きます, 行きます, 話します, 待ちます, 死にます, 呼びます, 読みます, 買います, 走ります, 会います |
| **Ichidan** | Stem + ます | 食べます, 見ます, 寝ます, 起きます, 開けます, 閉めます |
| **する** | し + ます | します |
| **来る** | き + ます | 来ます |

### 3. Past (〜た/だ) - Plain Past
**Stem: Ren'youkei + た/だ (euphonic change)**

| Verb Type | Rule | Examples |
|-----------|------|----------|
| **Godan** | Ren'you + た/だ | 書いた, 行った, 話した, 待った, 死んだ, 呼んだ, 読んだ, 買った, 走った, 会った |
| **Ichidan** | Stem + た | 食べた, 見た, 寝た, 起きた, 開けた, 閉めた |
| **する** | し + た | した |
| **来る** | き + た | 来た |

**Godan Euphonic Changes (音便 - onbin):**
| Ren'you Ending | + た → | Example |
|----------------|--------|---------|
| -i (き, し, ち, り, い) | **った** | 書き→書いた, 話し→話した, 待ち→待った, 走り→走った, 会い→会った |
| -ni (に) | **んだ** | 死に→死んだ, 呼び→呼んだ, 読み→読んだ |
| -ki (き) | **いた** | 書き→書いた (but 行く→行った) |
| -gi (ぎ) | **いだ** | 泳ぎ→泳いだ |
| -bi (び) | **んだ** | 呼び→呼んだ |

### 4. て-form (〜て/で) - Connective
**Stem: Ren'youkei + て/で (same euphonic changes as た)**

| Verb Type | Rule | Examples |
|-----------|------|----------|
| **Godan** | Ren'you + て/で | 書いて, 行って, 話して, 待って, 死んで, 呼んで, 読んで, 買って, 走って, 会って |
| **Ichidan** | Stem + て | 食べて, 見て, 寝て, 起きて, 開けて, 閉めて |
| **する** | し + て | して |
| **来る** | き + て | 来て |

### 5. Potential (〜える/られる) - "Can Do"
**Stem: Mizenkei (Godan) / Stem (Ichidan) + る/られる**

| Verb Type | Rule | Examples |
|-----------|------|----------|
| **Godan** | Mizen (e) + る | 書ける, 行ける, 話せる, 待てる, 死ねる, 呼べる, 読める, 買える, 走れる, 会える |
| **Ichidan** | Stem + られる | 食べられる, 見られる, 寝られる, 起きられる, 開けられる, 閉められる |
| **Short Potential** (colloquial) | Stem + れる | 食べれる, 見れる, 寝れる (ら抜き言葉) |
| **する** | (irregular) | **できる** |
| **来る** | こ + られる | 来られる |

> **Godan potential = becomes Ichidan!** (書ける conjugates like 食べる)

### 6. Volitional (〜う/よう) - "Let's / I'll"
**Stem: Mizenkei + う (Godan) / Stem + よう (Ichidan)**

| Verb Type | Rule | Examples |
|-----------|------|----------|
| **Godan** | Mizen (o) + う | 書こう, 行こう, 話そう, 待とう, 死のう, 呼ぼう, 読もう, 買おう, 走ろう, 会おう |
| **Ichidan** | Stem + よう | 食べよう, 見よう, 寝よう, 起きよう, 開けよう, 閉めよう |
| **する** | し + よう | しよう |
| **来る** | こ + よう | 来よう |

### 7. Passive (〜れる/られる) - "Is Done"
**Stem: Mizenkei + れる (Godan) / Stem + られる (Ichidan)**

| Verb Type | Rule | Examples |
|-----------|------|----------|
| **Godan** | Mizen (a) + れる | 書かれる, 行かれる, 話される, 待たれる, 死なれる, 呼ばれる, 読まれる, 買われる, 走られる, 会われる |
| **Ichidan** | Stem + られる | 食べられる, 見られる, 寝られる, 起きられる, 開けられる, 閉められる |
| **する** | (irregular) | **される** |
| **来る** | こ + られる | 来られる |

> **Ichidan passive = potential!** Context distinguishes: ケーキが食べられた (passive: cake was eaten) vs ケーキが食べられる (potential: can eat cake)

### 8. Causative (〜せる/させる) - "Make/Let Do"
**Stem: Mizenkei + せる (Godan) / Stem + させる (Ichidan)**

| Verb Type | Rule | Examples |
|-----------|------|----------|
| **Godan** | Mizen (a) + せる | 書かせる, 行かせる, 話させる, 待たせる, 死なせる, 呼ばせる, 読ませる, 買わせる, 走らせる, 会わせる |
| **Ichidan** | Stem + させる | 食べさせる, 見させる, 寝させる, 起きさせる, 開けさせる, 閉めさせる |
| **する** | さ + せる | **させる** |
| **来る** | こ + させる | 来させる |

### 9. Causative-Passive (〜せられる/させられる) - "Is Made to Do"
**Causative stem + られる (all become Ichidan)**

| Verb Type | Rule | Examples |
|-----------|------|----------|
| **Godan** | Mizen (a) + せられる | 書かせられる, 行かせられる, 話させられる... |
| **Ichidan** | Stem + させられる | 食べさせられる, 見させられる... |
| **する** | させられる | させられる |
| **来る** | こさせられる | 来させられる |

> **Short causative-passive** (colloquial): 書かされる, 行かされる (Godan: mizen + さる)

### 10. Conditional ば (〜えば/れば) - "If/When"
**Stem: Kateikei + ば**

| Verb Type | Rule | Examples |
|-----------|------|----------|
| **Godan** | Katei (e) + ば | 書けば, 行けば, 話せば,待てば, 死ねば, 呼べば, 読めば, 買えば, 走れば, 会えば |
| **Ichidan** | Stem + れ + ば | 食べれば, 見れば, 寝れば, 起きれば, 開ければ, 閉めれば |
| **する** | すれ + ば | すれば |
| **来る** | くれ + ば | 来れば |

> **For adjectives/nouns**: い-adj → くあれば / な-adj・noun → なら(ば)

### 11. Imperative (命令形) - Commands
**Stem: Meireikei**

| Verb Type | Rule | Examples |
|-----------|------|----------|
| **Godan** | Katei (e) | 書け, 行け, 話せ, 待て, 死ね, 呼べ, 読め, 買え, 走れ, 会え |
| **Ichidan** | Stem + ろ / よ | 食べろ/食べよ, 見ろ/見よ, 寝ろ/寝よ |
| **する** | しろ / せよ | しろ/せよ |
| **来る** | 来い / 来よ | 来い/来よ |

> **Polite command**: て-form + ください (書いてください)

## て-form Constructions (Essential!)

| Construction | Structure | Meaning | Example |
|--------------|-----------|---------|---------|
| **Request** | て + ください | Please do | 待ってください |
| **Permission** | て + もいい | May do | 入ってもいいです |
| **Prohibition** | て + はいけない | Must not | 入ってはいけません |
| **Progressive** | て + いる | Doing / State | 読んでいる, 知っている |
| **Experience** | て + ある | Done (result state) | 書いてある |
| **Preparation** | て + おく | Do in advance | 予約しておく |
| **Trial** | て + みる | Try doing | 食べてみる |
| **Regret** | て + しまう | Do completely (regret) | 食べてしまった |
| **Sequence** | て + て + Verb | Do X, then Y | 起きて、食べて、行った |
| **Reason** | て + から / ので | Because | 病気で休んで、... |

## Conditional Forms Comparison

| Form | Structure | Nuance | Example |
|------|-----------|--------|---------|
| **と** | Verb (plain) + と | Natural consequence, always | 春になると暖かくなる |
| **ば** | Verb (kateikei) + ば | General conditional | 時間があれば行く |
| **たら** | Verb (ta-form) + ら | Completed action, specific | 行ったら電話する |
| **なら** | Noun/な-adj + なら / Verb (plain) + なら | Topic-conditional, "if so" | 学生なら安い / 行くなら連絡して |
