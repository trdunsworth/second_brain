# Adjective Fundamentals - い-adjectives & な-adjectives

## Two Classes, Two Behaviors

| Feature | **い-adjectives** (形容詞) | **な-adjectives** (形容動詞) |
|---------|---------------------------|----------------------------|
| **Ending** | Always end in **い** | End in various sounds, take **な** before nouns |
| **Conjugation** | **Yes** - conjugate like verbs | **No** - act like nouns, use です/だ |
| **Origin** | Native Japanese | Mostly Chinese-derived (kango) |
| **Examples** | 大きい, 小さい, いい, 悪い, 高い, 安い, 早い, 遅い | 静か, 元気, 好き, 嫌い, 上手, 下手, 便利, 不便 |

---

## い-Adjectives (イ形容詞) - Full Conjugation

### Base: 高い (takai - expensive/high)

| Form | Conjugation | Example | Use |
|------|-------------|---------|-----|
| **Dictionary / Plain Present** | 高い | この本は**高い** | Casual statement, modifies nouns |
| **Polite Present** | 高い**です** | この本は**高いです** | Polite statement |
| **Plain Negative** | 高**くない** | この本は**高くない** | Casual negative |
| **Polite Negative** | 高**くありません** / 高**くないです** | この本は**高くありません** | Polite negative |
| **Plain Past** | 高**かった** | この本は**高かった** | Casual past |
| **Polite Past** | 高**かったです** | この本は**高かったです** | Polite past |
| **Plain Past Negative** | 高**くなかった** | この本は**高くなかった** | Casual past negative |
| **Polite Past Negative** | 高**くありませんでした** / 高**くなかったです** | この本は**高くありませんでした** | Polite past negative |
| **て-form** | 高**くて** | 高**くて**買えない | Linking, cause/reason |
| **Adverbial (く-form)** | 高**く** | 高**く**売る | Modify verbs, make adverbs |
| **Conditional (ば)** | 高**ければ** | 高**ければ**買わない | If/when |
| **Stem (い → さ)** | 高**さ** | 高**さ**が違う | Nominalization (noun) |
| **〜そう** (seems) | 高**そう** | 高**そう**だ | Appearance |
| **〜すぎる** (too) | 高**すぎる** | 高**すぎる** | Excessive |

### Key Patterns
- **Negative**: い → く + ない
- **Past**: い → かっ + た
- **Past Negative**: い → く + なかっ + た
- **て-form**: い → く + て
- **Adverb**: い → く
- **Noun**: い → さ (高さ, 深さ, 重さ, 暑さ, 寒さ...)

## な-Adjectives (ナ形容詞) - Noun-Like Behavior

### Base: 静か (shizuka - quiet)

| Form | Conjugation | Example | Use |
|------|-------------|---------|-----|
| **Dictionary / Plain Present** | 静か**だ** | この部屋は**静かだ** | Casual (requires だ) |
| **Polite Present** | 静か**です** | この部屋は**静かです** | Polite |
| **Plain Negative** | 静か**ではない** / 静か**じゃない** | この部屋は**静かではない** | Casual negative |
| **Polite Negative** | 静か**ではありません** / 静か**じゃありません** | この部屋は**静かではありません** | Polite negative |
| **Plain Past** | 静か**だった** | この部屋は**静かだった** | Casual past |
| **Polite Past** | 静か**でした** | この部屋は**静かでした** | Polite past |
| **Plain Past Negative** | 静か**ではなかった** / 静か**じゃなかった** | この部屋は**静かじゃなかった** | Casual past negative |
| **Polite Past Negative** | 静か**ではありませんでした** / 静か**じゃありませんでした** | この部屋は**静かじゃありませんでした** | Polite past negative |
| **て-form** | 静か**で** | 静か**で**いい | Linking, cause |
| **Adverbial (に-form)** | 静か**に** | 静か**に**する | Modify verbs |
| **Conditional (なら)** | 静か**なら** | 静か**なら**いい | If (topic-conditional) |
| **Noun** | 静か**さ** | 静か**さ**を保つ | Nominalization |

### Key Patterns
- **Present**: + だ / です
- **Negative**: + ではない / じゃない
- **Past**: + だった
- **Past Negative**: + ではなかった / じゃなかった
- **て-form**: + で
- **Adverb**: + に
- **Conditional**: + なら
- **Noun**: + さ

> **Critical**: な-adjectives **cannot stand alone as predicates without だ/です**!
> - 静か ✗ → 静かだ ○ / 静かです ○
> - But い-adjectives CAN: 高い ○

## Modifying Nouns (Attributive Form)

### い-adjectives: **Dictionary form directly modifies**
| Adjective | + Noun | Example |
|-----------|--------|---------|
| 高い | 本 | **高い本** (expensive book) |
| 古い | 家 | **古い家** (old house) |
| おいしい | りんご | **おいしいりんご** (delicious apple) |

### な-adjectives: **Add な**
| Adjective | + な + Noun | Example |
|-----------|-------------|---------|
| 静か | な + 部屋 | **静かな部屋** (quiet room) |
| 便利 | な + 場所 | **便利な場所** (convenient place) |
| 好き | な + 食べ物 | **好きな食べ物** (favorite food) |
| 元気 | な + 子 | **元気な子** (energetic child) |

## Special / Irregular Adjectives

### いい (ii - good) - **IRREGULAR!**
| Form | Conjugation | Note |
|------|-------------|------|
| Present | いい | Only dictionary form is irregular |
| Negative | **よくない** | Not いくない |
| Past | **よかった** | Not いかった |
| Past Neg | **よくなかった** | |
| て-form | **よくて** | |
| Adverb | **よく** | |
| Conditional | **よければ** | |
| Noun | **よさ** | |

> **All other forms follow よ- stem!** Good news: only present tense is weird.

### かっこいい (kakkoii - cool) / わるい (warui - bad)
- Compounds with いい follow いい pattern: かっこよくない, かっこよかった
- わるい is regular: わるくない, わるかった

### 同じ (onaji - same) - **NA-ADJECTIVE BUT NO な**
- 同じ本 (same book) - no な!
- 同じだ / 同じです
- 同じではない / 同じじゃない

### 大きい (ookii) / 小さい (chiisai) - **Can be both!**
| Usage | Example |
|-------|---------|
| い-adj | 大きい家, 小さい家 |
| な-adj (formal/written) | 大きな家, 小さな家 |
- **大きな/小さな** only used attributively (before nouns), never as predicate

## Adjective + です Nuance

| Adjective Type | です Role |
|----------------|-----------|
| **い-adjective** | Politeness marker only (already predicates) |
| **な-adjective** | **Required** copula (cannot predicate without it) |
| **Noun** | **Required** copula |

## Adverbial Forms Comparison

| Adjective | Adverb Form | Example |
|-----------|-------------|---------|
| **高い** (い) | **高く** | 高く飛ぶ (fly high) |
| **速い** (い) | **速く** | 速く走る (run fast) |
| **静か** (な) | **静かに** | 静かに話す (speak quietly) |
| **上手** (な) | **上手に** | 上手に書く (write well) |
| **早い** (い) | **早く** | 早く来る (come early) |

> **Rule**: い-adj → く | な-adj → に

## Comparative & Superlative

### Comparative: A より B のほうが [Adj]
- **この本よりあの本のほうが高い。** → That book is more expensive than this one.
- **A より B が [Adj]** (shorter, B is subject): この本よりあの本が高い。

### Superlative: [Group] で 一番 [Adj]
- **クラスで一番背が高い。** → Tallest in the class.
- **世界で一番美しい。** → Most beautiful in the world.

### "More" / "Less" with degree adverbs
- **もっと** 高い (more expensive)
- **さらに** 高い (even more expensive)
- **あまり** 高くない (not very expensive)
- **全然** 高くない (not expensive at all)

## Stative Adjectives (Desire/Like/Ability) - Take が!

These are **い-adjectives** but the "object" takes **が**, not を:

| Adjective | Meaning | Example |
|-----------|---------|---------|
| **好き** (suki) | like | **猫が**好きです |
| **嫌い** (kirai) | dislike | **虫が**嫌いです |
| **欲しい** (hoshii) | want (noun) | **車が**欲しいです |
| **要る** (iru) | need | **お金が**要ります |
| **分かる** (wakaru) | understand | **日本語が**分かります |
| **できる** (dekiru) | can do | **ピアノが**できます |

> **Why が?**: These describe a **state of the subject**, not an action on an object. "Cats are likeable (to me)" not "I like cats."

## Compound Adjectives

### Noun + い-adjective stem
- **忙しい** (isogashii) + **そう** → 忙しそう (looks busy)
- **楽しい** (tanoshii) + **さ** → 楽しさ (fun-ness)

### Noun + な-adjective
- **色** (iro) + **白い** → 色白 (fair-skinned) - becomes な-adj: 色白な人
- **気** (ki) + **長い** → 気長 (patient) - 気長な人

### Reduplication (emphasis)
- **黒々** (kurokuro) - pitch black
- **真っ白** (masshiro) - pure white
- **真っ赤** (makka) - bright red
- **真っ青** (massao) - pale/blue with fear

## Practice: Conjugate Fully

**い-adjectives**: 新しい, 古い, 難しい, 易しい, 面白い, つまらない, 忙しい, 暇
**な-adjectives**: 便利, 不便, 静か, 賑やか, 元気, 病気, 上手, 下手, 好き, 嫌い, 必要, 有名

**For each, produce**: Plain/Polite × Present/Negative/Past/PastNeg, て-form, adverb, conditional, noun form
