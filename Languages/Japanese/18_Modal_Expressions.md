# Modal Expressions - Obligation, Permission, Possibility, Probability

## Overview
Japanese expresses modality through **verb endings**, **auxiliary verbs**, **adjectives**, and **sentence-final particles**. No single "modal verb" like English can/must/should.

---

## Obligation / Necessity (Must / Have to)

### 1. なければならない (nakereba naranai) - Standard "Must"
**Structure**: Verb ない-form → なければ + ならない
- **行かなければならない。** (Must go.)
- **宿題をしなければならない。** (Must do homework.)

**Variants**:
- **なければいけない** (nakereba ikenai) - Slightly softer, more common in speech
- **なくてはならない** (nakute wa naranai) - て-form version, same meaning
- **なくてはいけない** (nakute wa ikenai) - Most common spoken form

### 2. べき (beki) - "Should / Ought to" (Moral/Logical Obligation)
**Structure**: Verb Dictionary + べき / べきだ
- **学生は勉強すべきだ。** (Students should study.)
- **謝るべきだった。** (Should have apologized.)

**Negative**: べきではない / べきじゃない
- **嘘をつくべきではない。** (Should not lie.)

> **Nuance**: べき = objective correctness, moral duty | なければならない = circumstantial necessity

### 3. ことになっている (koto ni natte iru) - "It's Decided/Rule"
**Structure**: Verb Dict/Neg + ことになっている
- **ここではタバコを吸わないことになっている。** (Smoking is prohibited here - rule.)
- **九時に始まることになっている。** (It's scheduled to start at 9.)

### 4. わけにはいかない (wake ni wa ikanai) - "Cannot Afford to / Not Allowed"
**Structure**: Verb Dict + わけにはいかない
- **試験前だから、遊ぶわけにはいかない。** (Can't go out - exam's coming.)
- **上司の命令だから、断るわけにはいかない。** (Can't refuse - boss's order.)

### 5. ざるを得ない (zaru o enai) - "Have No Choice But" (Formal/Written)
**Structure**: Verb Mizenkei (ない-stem without ない) + ざるを得ない
- **行かざるを得ない。** (Have no choice but to go.)
- **認めざるを得なかった。** (Had to admit.)

## Prohibition (Must Not / Cannot)

### 1. てはならない / てはいけない / てはだめ
**Structure**: Verb て-form + は + ならない/いけない/だめ
- **ここに入ってはならない。** (Must not enter.)
- **遅れてはいけない。** (Must not be late.)
- **嘘をついてはだめ。** (No lying.)

> **Register**: ならない (formal) > いけない (standard) > だめ (casual)

### 2. べきではない - "Should Not"
- **人を傷つけるべきではない。** (Should not hurt others.)

### 3. ことはない - "No Need To" (Not Prohibition!)
- **心配することはない。** (No need to worry.)
- **来ることはない。** (Don't have to come.)

---

## Permission (May / Can)

### 1. てもいい (temo ii) - "May / It's OK to"
**Structure**: Verb て-form + も + いい
- **入ってもいいですか？** (May I enter?)
- **これを使ってもいい。** (You may use this.)

**Casual**: てもいい → **てもええ** (Kansai) / **ていい** (very casual)

### 2. てもかまわない (temo kamawanai) - "Don't Mind If"
- **タバコを吸ってもかまいません。** (I don't mind if you smoke.)

### 3. ことができる / できる - "Can / Be Able To" (Ability)
- **日本語ができます。** (Can speak Japanese.)
- **漢字が読める。** (Can read kanji.)

## Possibility / Capability

### 1. Potential Form (可能動詞) - "Can Do"
| Verb Type | Form | Example |
|-----------|------|---------|
| **Godan** | Mizenkei (e) + る | 書ける, 行ける, 話せる, 買える |
| **Ichidan** | Stem + られる | 食べられる, 見られる |
| **Short Potential** | Stem + れる | 食べれる, 見れる (colloquial) |
| **する** | できる | できる |
| **来る** | 来られる | 来られる |

### 2. ことができる (koto ga dekiru) - "Can Do" (All Verbs)
- **難しい漢字を書くことができる。** (Can write difficult kanji.)
- **Used for**: Compound verbs, emphasis, formality

### 3. 可能性がある (kanousei ga aru) - "Possibility Exists"
- **雨が降る可能性がある。** (There's a possibility of rain.)

### 4. 〜得る (uru / eru) - "Can Possibly" (Formal/Written)
**Structure**: Verb Stem + 得る
- **あり得ることだ。** (It's a possible thing.)
- **考え得る限り。** (As far as one can think.)

## Probability / Conjecture (Epistemic Modality)

### Certainty Scale (High → Low)

| Level | Expression | Structure | Example | Certainty |
|-------|------------|-----------|---------|-----------|
| **100%** | **だ / です** | Fact | 彼は学生だ。 | Fact |
| **90%** | **はずだ** | Expectation | もう着くはずだ。 | Should be |
| **80%** | **にちがいない** | Strong conviction | 犯人は彼にちがいない。 | No doubt |
| **70%** | **だろう / でしょう** | Conjecture | 雨だろう。 | Probably |
| **60%** | **かもしれない** | Possibility | 雨かもしれない。 | Might |
| **50%** | **かもしれない / 可能性がある** | 50/50 | 来るかもしれない。 | Maybe |
| **30%** | **〜そう / ようだ** | Appearance | 雨が降りそうだ。 | Looks like |
| **Low** | **〜らしい** | Hearsay/Inference | 彼は来るらしい。 | I hear/Seems |

---

### 1. はずだ (hazu da) - "Should / Supposed To" (Logical Expectation)
**Structure**: [Plain] + はずだ
- **九時には着くはずだ。** (Should arrive by 9.)
- **そんなはずはない。** (That can't be right.)

> **Negative**: はずがない (impossible) / はずではない (not necessarily)

### 2. だろう / でしょう (darou / deshou) - "Probably / Right?"
**Structure**: [Plain] + だろう / でしょう
- **明日、雨だろう。** (Probably rain tomorrow.)
- **高いでしょう？** (It's expensive, right?)

> **Past**: だったろう / でしたろう
> **Polite**: でしょう (standard polite conjecture)

### 3. にちがいない (ni chigai nai) - "No Doubt / Must Be"
**Structure**: [Plain] + にちがいない
- **彼が犯人にちがいない。** (He must be the culprit.)
- **成功するにちがいない。** (Will surely succeed.)

### 4. かもしれない (kamoshirenai) - "Might / May"
**Structure**: [Plain] + かもしれない
- **忘れているかもしれない。** (Might have forgotten.)
- **Polite**: かもしれません
> **Short**: かも (casual) - **雨かも。**

### 5. そう / ようだ (sou / you da) - "Seems Like / Looks Like"

| Form | Structure | Basis | Example |
|------|-----------|-------|---------|
| **〜そう** | Verb Stem / い-adj(い→そう) / な-adj/名詞+そう | **Visual evidence** | 雨が降りそうだ。 / 美味しそう。 / 元気そうだ。 |
| **〜ようだ** | Verb Plain / い-adj / な-adj+な / 名詞+の | **Inference/Overall impression** | 雨が降るようだ。 / 美味しいようだ。 / 学生のようだ。 |

> **そう** = Direct observation | **ようだ** = Indirect inference

### 5. らしい (rashii) - "Seems / I Hear / Apparently"
**Structure**: [Plain] + らしい
- **彼は医者らしい。** (He's apparently a doctor / I hear he's a doctor.)
- **雨が降るらしい。** (I hear it'll rain / Seems like rain.)

> **Sources**: Hearsay, inference from evidence, typicality
> **彼らしい決断だ。** (A decision typical of him.)

## Volition / Intention (Desire, Willingness)

### 1. たい (tai) - "Want to" (First Person / Questions)
**Structure**: Verb Stem + たい
- **行きたい。** (Want to go.)
- **何が食べたい？** (What want to eat?)

**Negative**: たくない
**Past**: たかった / たくなかった

> **Third person**: たがる (shows signs of wanting)
> - **子供がアイスクリームを食べたがっている。** (Child wants ice cream.)

### 2. ほしい (hoshii) - "Want (Noun)" (First Person)
**Structure**: Noun + が + ほしい
- **車がほしい。** (Want a car.)

> **Third person**: ほしがる

### 3. よう / う (Volitional) - "Let's / I'll"
**Structure**: Verb Volitional Form
- **行こう！** (Let's go! / I'll go!)
- **食べよう。** (Let's eat.)

### 4. つもり (tsumori) - "Intend to"
**Structure**: Verb Dict/Neg + つもりだ
- **行くつもりだ。** (Intend to go.)
- **行かないつもりだ。** (Intend not to go.)

### 5. ことにする / ことになる - "Decide / It's Decided"
| Form | Subject | Example |
|------|---------|---------|
| **ことにする** | **Self** decides | **タバコをやめることにした。** (Decided to quit.) |
| **ことになる** | **External/Circumstance** decides | **転勤することになった。** (It's been decided I'll transfer.) |

---

## Advice / Recommendation (Should)

### 1. ほうがいい (hou ga ii) - "Better To" (Advice)
**Structure**: Verb た-form / ない-form + ほうがいい
- **行ったほうがいい。** (Better go.)
- **行かないほうがいい。** (Better not go.)

> **Past**: ほうがよかった (Should have / Should not have)
> - **行ったほうがよかった。** (Should have gone.)
> - **行かないほうがよかった。** (Shouldn't have gone.)

### 2. べき (beki) - "Should" (Moral/Logical)
- **謝るべきだ。** (Should apologize.)

### 3. 〜たらどうですか / 〜たら？ - "Why Don't You...?"
- **医者に行ったらどうですか？** (Why don't you see a doctor?)
- **これ、食べたら？** (Why not eat this?)

## Evidentiality (Information Source)

| Marker | Source | Example |
|--------|--------|---------|
| **(Plain)** | Direct knowledge | 雨が降っている。 |
| **〜そうだ** | Visual evidence | 雨が降りそうだ。 (Looks like rain.) |
| **〜ようだ** | Inference | 雨が降るようだ。 (Seems it'll rain.) |
| **〜らしい** | Hearsay / Indirect | 雨が降るらしい。 (I hear it'll rain.) |
| **〜ということだ** | Reported | 雨が降るということだ。 (They say it'll rain.) |
| **〜んだって** | Casual hearsay | 雨が降るんだって。 (Heard it'll rain.) |

## Modality Summary Table

| Function | Key Forms | Register |
|----------|-----------|----------|
| **Obligation** | なければならない, べき, ことになっている | Standard → Formal |
| **Prohibition** | てはならない, てはいけない, べきではない | Formal → Casual |
| **Permission** | てもいい, てもかまわない | Standard |
| **Ability** | Potential, ことができる | Standard |
| **Possibility** | かもしれない, 可能性がある, 得る | Standard → Formal |
| **Probability** | だろう, はずだ, にちがいない, かもしれない, そう, ようだ, らしい | Standard |
| **Volition** | たい, つもり, ことにする, Volitional | Standard |
| **Advice** | ほうがいい, べき, たらどう | Standard |
| **Evidentiality** | そう, ようだ, らしい, ということだ | Standard |

## Practice: Choose the Modal

1. Students _____ study. (moral duty) → **べきだ**
2. I _____ go to work tomorrow. (schedule) → **ことになっている / 予定だ**
3. You _____ smoke here. (rule) → **てはいけない / ことはできません**
4. It _____ rain later. (90% sure) → **はずだ / にちがいない**
5. It _____ rain later. (50% chance) → **かもしれない**
6. It _____ be raining. (looks like it) → **降りそうだ / 降るようだ**
7. I _____ eat sushi. (desire) → **食べたい**
8. You _____ see a doctor. (advice) → **行ったほうがいい**
9. He _____ be a doctor. (I hear) → **らしい**
10. We _____ decide by tomorrow. (no choice) → **決めざるを得ない / 決めなければならない**

---

*Modality is the speaker's stance toward the proposition. Japanese encodes it in the predicate complex. Master the certainty scale first - it's the backbone of nuanced expression.*
