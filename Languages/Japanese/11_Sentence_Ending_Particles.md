# Sentence-Ending Particles (終助詞 - しゅうじょし)

## Overview
These particles attach to sentence ends to convey **speaker attitude, emotion, politeness, gender, regional dialect**, and **discourse function**. They're essential for natural speech.

---

## Core Particles (Standard Japanese)

### よ (yo) - Assertion / New Information
**Function**: "I'm telling you," "You should know," emphasis on information transfer
- **知っていますよ。** (I know it, you see.)
- **明日、雨ですよ。** (It'll rain tomorrow, FYI.)
- **これは私のですよ。** (This is mine, just so you know.)

> **Nuance**: Can sound pushy if overused. Women often use **よね** instead.

---

### ね (ne) - Seeking Agreement / Shared Knowledge
**Function**: "Right?" "Isn't it?" "You know?" - builds rapport
- **いい天気ですね。** (Nice weather, isn't it?)
- **疲れましたね。** (You're tired, right?)
- **そうですね。** (That's right, isn't it.)

> **Variants**: ねー (casual/elongated), な (masculine casual)

---

### よね (yone) - Assertion + Confirmation
**Function**: "I think X, right?" - softer than よ, more confident than ね
- **美味しいよね。** (It's delicious, right?)
- **明日、休みよね。** (Tomorrow's off, right?)

> **Common female pattern**: よね > よ

---

### か (ka) - Question Marker
**Function**: Formal question marker (polite)
- **学生ですか。** → **学生ですか？** (Are you a student?)
- **何時ですか。**（What time is it?）

> **Casual**: Rising intonation only (no か)
> **Rhetorical**: **そんなこと、できるか！** (Like I could do that!)

---

### の (no) / ん (n) - Explanation / Emphasis / Soft Question
**Function**: Explanatory, emotional emphasis, soft question (mainly feminine/casual)

| Use | Example | Nuance |
|-----|---------|--------|
| **Explanation** | **遅れたんです。** | "The thing is, I was late." |
| **Emphasis** | **本当なんですよ。** | "It's TRUE, I tell you." |
| **Soft Question (F)** | **どこ行くの？** | "Where are you going?" (gentle) |
| **Realization** | **ああ、そうなんですか。** | "Oh, I see." |

> **Male casual**: んだ / んだよ / のだ
> **Female casual**: の / のよ / わよ

---

### な (na) - Monologue / Emotion / Prohibition
**Function**: 
1. **Talking to self** (masculine): **うまいな、これ。** (This is good.)
2. **Prohibition** (dictionary form + な): **入るな！** (Don't enter!)
3. **Emphatic desire** (volitional + な): **行きたいな。** (I wanna go...)
4. **Tag question** (masculine): **行くな。** (You're going, right?)

> **Feminine**: なあ / なぁ (softer)

---

### わ (wa) - Feminine Emphasis / Emotion
**Function**: Soft assertion, emotional coloring (traditionally feminine)
- **疲れたわ。** (I'm so tired.)
- **綺麗だわ。** (It's beautiful.)
- **もう知らないわ。** (I don't care anymore.)

> **Kansai dialect**: Used by both genders: **知らんわ。**

---

### ぜ (ze) / ぞ (zo) - Masculine Emphasis
**Function**: Strong assertion, male casual speech
- **ぜ**: Softer, persuasive: **行くぜ！** (Let's go!)
- **ぞ**: Stronger, declarative: **俺がやるぞ！** (I'LL do it!)

> **Rare in modern Tokyo speech**; more anime/manga/drama

---

### さ (sa) - Casual Filler / "You Know"
**Function**: Light assertion, filler, "y'know" (masculine casual)
- **どうせ無理さ。** (It's hopeless anyway.)
- **そんなもんさ。** (That's just how it is.)
- **まあ、いいやさ。** (Well, whatever.)

---

### っけ (kke) - Memory Recall
**Function**: "Did...?" "Was it...?" - trying to remember
- **彼の名前、何だったっけ？** (What was his name again?)
- **ここだったっけ？** (Was it here?)

> **Past tense**: だったっけ / たっけ

---

### かしら (kashira) - Feminine "I Wonder"
**Function**: "I wonder if..." (soft, feminine)
- **雨が降るかしら。**(I wonder if it'll rain.)
- **来るかしら。**(I wonder if he'll come.)

> **Male equivalent**: かな (kana)

---

### かな (kana) - "I Wonder" (Gender-Neutral Casual)
**Function**: Uncertainty, soliloquy
- **うまくいくかな。**(Wonder if it'll work out.)
- **どこかな。**(Wonder where it is.)

---

### わよ (wayo) / わね (wane) - Feminine Combinations
| Combo | Nuance | Example |
|-------|--------|---------|
| **わよ** | Assertion + emotion | **疲れたわよ。** |
| **わね** | Seeking agreement + emotion | **綺麗だわね。** |

## Politeness & Gender Matrix

| Particle | Politeness | Gender | Context |
|----------|------------|--------|---------|
| **よ** | Neutral | Both | Standard info-giving |
| **ね** | Neutral | Both | Standard rapport-building |
| **よね** | Neutral | F > M | Soft assertion |
| **か** | Formal | Both | Polite questions |
| **の/ん** | Casual | F > M | Explanation, soft Q |
| **んだ/のだ** | Casual | M > F | Explanation, emphasis |
| **な** | Casual | M | Monologue, prohibition |
| **なあ** | Casual | Both | Emotion, monologue |
| **わ** | Casual | F | Emotion, soft assertion |
| **ぜ/ぞ** | Very Casual | M | Strong assertion |
| **さ** | Very Casual | M | Filler, resignation |
| **っけ** | Casual | Both | Memory check |
| **かしら** | Casual | F | Uncertainty |
| **かな** | Casual | Both | Uncertainty |

---

## Intonation Matters!

| Particle | Rising ↗ | Falling ↘ | Flat → |
|----------|----------|-----------|--------|
| **よ** | Surprise/Insistence | Normal assertion | - |
| **ね** | Strong agreement seek | Light confirmation | Monologue |
| **よね** | Confirmation seek | Shared assumption | - |
| **か** | Standard question | Rhetorical/angry | - |
| **の** | Soft question | Explanation/emphasis | - |
| **な** | Emotion/monologue | Prohibition (sharp) | - |

---

## Regional Variations (Major)

### Kansai (Osaka/Kyoto)
| Standard | Kansai | Notes |
|----------|--------|-------|
| よ | **で** / **や** | **ええで** (Good, ya know) |
| ね | **や** / **な** | **寒いやん** (Cold, huh) |
| か | **か** / **かい** | **何してんねん** (What're you doing?) |
| の/んだ | **ん** / **ねん** | **知らんねん** (I don't know) |
| よね | **やろ** / **やん** | **美味しいやろ** (Delicious, right?) |
| わ | **わ** (both genders) | **知らんわ** |

### Tohoku / Northern
- **べ** / **だべ** = だろう / でしょう (probably)
- **け** = か (question)
- **さ** = よ/ね (assertion/agreement)

## Discourse Functions Summary

| Function | Particles | Example |
|----------|-----------|---------|
| **New info** | よ, よね | **明日休みだよ** |
| **Shared info** | ね, よね | **寒いね** |
| **Question** | か, の, かい, だい | **何してるの？** |
| **Explanation** | の/んだ, んです | **風邪なんです** |
| **Emotion** | なあ, わ, ぜ, ぞ, さ | **悔しいなあ** |
| **Prohibition** | な (dict form) | **触るな！** |
| **Memory** | っけ | **何時だっけ？** |
| **Uncertainty** | かな, かしら | **来るかな** |
| **Self-talk** | な, なあ, かな | **どうしようかな** |

## Practice: Add Appropriate Particle

1. ここ____静かだ。 → **ね** (shared observation)
2. これ____私のです。 → **よ** (informing)
3. 明日、雨____。 → **よね** (confirm forecast)
4. 何時____？ → **か** (polite) / **(rising intonation)** (casual)
5. 疲れた____。 → **わ** (F) / **なあ** (M) / **よ** (neutral)
6. 行く____？ → **の** (F soft) / **か** (polite) / **(rise)** (casual)
7. 触る____！ → **な** (prohibition)
8. 彼の名前、何____？ → **だったっけ** (memory)
9. 間に合う____。 → **かな** (uncertainty)
10. 美味しい____。 → **ね** / **よね** / **わね**

*Sentence-ending particles are the "soul" of Japanese speech. They convey the speaker's heart. Listen for them in native content constantly.*
