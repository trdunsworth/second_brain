# Literary & Written Japanese (文語・文語調・書き言葉)

## Register Spectrum

| Register | Japanese | Use Case | Example Copula |
|----------|----------|----------|----------------|
| **Casual Speech** | 話し言葉 / 口語 | Friends, family, casual net | だ / だね |
| **Polite Speech** | 丁寧語 | Strangers, service, standard | です / ます |
| **Standard Written** | 書き言葉 / 常用文 | Essays, articles, emails, reports | である / だ |
| **Formal Written** | 公用文 / 論文 | Academic papers, contracts, laws | である / であります |
| **Literary/Artistic** | 文語調 / 小説文 | Novels, haiku, lyrics, poetry | だ / である / 文語形 |
| **Classical** | 文語 / 古文 | Pre-1946 texts, legal codes | なり / たり / けり |

## 書き言葉 (Kakikotoba) - Standard Written Style

### Key Features vs Speech

| Feature | Speech (口語) | Writing (書き言葉) |
|---------|---------------|-------------------|
| **Sentence End** | です/ます, だ, だよ | である, だ, ない |
| **Conjunctions** | て-form, から, ので | Stem-linking, したがって, よって |
| **Pronouns** | わたし, あなた, これ | 私, 筆者, 本稿, この |
| **Fillers** | えー, あのー, なんか | (None) |
| **Sentence Length** | Short, fragmented | Long, complex embedding |
| **Vocabulary** | Native (和語) heavy | Sino-Japanese (漢語) heavy |

### Stem-Linking (連用形接続) - Hallmark of Written Style
**Replace て-form with 連用形 (stem)**

| Speech | Writing |
|--------|---------|
| **読んで、書く** | **読み、書く** |
| **行って、見る** | **行き、見る** |
| **買って、食べる** | **買い、食べる** |
| **高くて、大きい** | **高く、大きい** (い-adj: く-form) |
| **静かで、広い** | **静かで、広い** (な-adj: で remains) |

> **Rule**: Verb 連用形, い-adj く-form, な-adj で - all can link clauses in writing.

### Conjunctive Adverbs (接続副詞) - Written Connectors

| Function | Speech | Writing |
|----------|--------|---------|
| **Addition** | そして, それに | **さらに, かつ, また, ならびに** |
| **Contrast** | でも, でもね | **しかし, 一方, 逆に, それに対して** |
| **Cause** | だから, ので | **したがって, それゆえに, よって, このため** |
| **Condition** | もし〜なら | **もし〜ならば, 〜の場合** |
| **Example** | 例えば | **たとえば, 具体的には** |
| **Summary** | つまり, 要するに | **すなわち, 要するに, 結論として** |
| **Shift** | ところで | **なお, ところで, ちなみに** |

## である Style (De Aru Style) - Academic/Formal Standard

### When to Use
- **Academic papers** (論文)
- **Technical reports** (技術報告)
- **Wikipedia** (ウィキペディア)
- **News articles** (ニュース記事 - mixed with です/ます)
- **Contracts/Legal** (契約書, 法令)
- **Official documents** (公文書)

### Conjugation of である

| Form | Plain | Polite (であります) |
|------|-------|---------------------|
| **Present** | である | であります |
| **Negative** | でない / ではない | でありません / ではありません |
| **Past** | であった | でありました |
| **Past Neg** | ではなかった | ではありませんでした |
| **て-form** | であり | でありまして |
| **Conditional** | であれば | でありましたら |
| **Volitional** | であろう | でしょう / であろうか |

### Noun/な-adj + である
- **学生である** (Is a student)
- **静かである** (Is quiet)
- **必要である** (Is necessary)

### Verb/い-adj + の + である (Nominalization)
- **行くのである** (The fact is that [he] goes)
- **高いのである** (The fact is that [it] is expensive)

## 論文スタイル (Ronbun Style) - Academic Paper Conventions

### Structure Markers

| Section | Standard Phrases |
|---------|------------------|
| **Abstract** | **本稿では、〜について論じる。** / **本研究の目的は〜である。** |
| **Introduction** | **近年、〜が注目されている。** / **これまで〜について研究されてきた。** |
| **Problem** | **しかし、〜という問題がある。** / **未解決の課題は〜である。** |
| **Method** | **本研究では、〜を用いた。** / **〜という手法を採用する。** |
| **Results** | **結果、〜が明らかになった。** / **〜という傾向が見られた。** |
| **Discussion** | **この結果から、〜と考えられる。** / **〜という解釈が可能である。** |
| **Conclusion** | **以上のことから、〜と結論づけられる。** / **今後の課題は〜である。** |

### Hedging (Academic Caution)
| Strength | Expression | Example |
|----------|------------|---------|
| **Strong** | **〜はずだ / にちがいない** | **正しいはずだ。** |
| **Standard** | **〜と考えられる / と推測される** | **効果があると考えられる。** |
| **Moderate** | **〜可能性がある / 〜傾向がある** | **改善の可能性がある。** |
| **Weak** | **〜かもしれない / 〜と思われる** | **関係しているかもしれない。** |

### Passive Preference
- **Active (Speech)**: **私たちは実験した。** → **Passive (Paper)**: **実験が行われた。**
- **Active**: **筆者は分析した。** → **Passive**: **分析がなされた。**

## 文語調 (Bungochō) - Literary Style for Fiction

### Narrative Modes

#### 1. Third-Person Past (Standard Novel)
**Features**: だ/である, た-form, literary vocabulary, stem-linking

> **彼は窓の外を眺めた。雨が降り続いている。** (He gazed out the window. The rain continued to fall.)

#### 2. Third-Person Present (Dramatic/Immediate)
**Features**: Dictionary form, いま・ここ focus

> **彼は窓の外を眺める。雨が降っている。** (He gazes out the window. Rain is falling.)

#### 3. First-Person (Diary/Confessional)
**Features**: 私/僕/俺, subjective, emotional, sentence-end particles

> **僕は窓の外を見た。雨だ。嫌になる。** (I looked out. Rain. Depressing.)

#### 4. Historical/Classical Flavor (時代小説)
**Features**: 文語 copula (なり/たり), classical vocab, classical auxiliaries (ぬ, つ, けり)

> **彼は窓の外を眺めたり。雨降り続くなり。** (Literary classical)

### Literary Vocabulary (文語語彙)

| Spoken | Literary | Nuance |
|--------|----------|--------|
| 見る | **眺める / 見やる / 目をやる** | Gaze, glance |
| 行く | **赴く (おもむく) / 向かう** | Proceed, head toward |
| 来る | **現れる / 訪れる** | Appear, visit |
| 言う | **語る / 囁く (ささやく) / 叫ぶ** | Tell, whisper, shout |
| 思う | **想う (おもう) / 思案する** | Feel deeply, deliberate |
| 知る | **悟る (さとる) / 承知する** | Realize, acknowledge |
| 悲しい | **哀しい (かなしい) / 悲しげ** | Sorrowful, looking sad |
| 嬉しい | **喜ばしい / 嬉しげ** | Joyful, looking happy |
| 早い | **速やか / 早々** | Prompt, early |
| 遅い | **遅々とした / 緩やか** | Slow, gradual |

### Sentence-End Particles in Fiction

| Particle | Speech | Fiction | Example |
|----------|--------|---------|---------|
| **よ** | Info-giving | Narrator assertion | **雨だよ。** |
| **ね** | Agreement | Narrator empathy | **寂しいね。** |
| **な** | Monologue | Character thought | **どうしようかな。** |
| **ことよ** | — | Exclamatory past | **待ったことよ！** |
| **ものを** | — | Regret (classical) | **知らなかったものを。** |

## 俳句・短歌 (Haiku/Tanka) - Ultra-Compressed Style

### Grammar Compression Techniques

| Technique | Example | Expansion |
|-----------|---------|-----------|
| **Cutting Word (切れ字 - kireji)** | **古池や**蛙飛び込む水の音 | **古池や** = 古池**だ** (copula) + **や** (exclamation) |
| **Noun Phrase Only** | **夏草や**兵どもが夢の跡 | **夏草や** = 夏草**があって** |
| **Verb Stem as Noun** | **散りぬべき**時知りてこそ | **散りぬべき** = 散るべき (should fall) |
| **Classical Auxiliaries** | **見渡せば**花も紅葉もなかりけり | **なかりけり** = なかった (past negative + exclamatory) |

### Kireji (Cutting Words)
| Kireji | Function | Example |
|--------|----------|---------|
| **や** (ya) | Exclamation, pause | **古池や** |
| **かな** (kana) | Wonder, emotion | **花さそふ**嵐の庭の雪かな |
| **けり** (keri) | Exclamatory past | **行きけり** |

## 書き言葉 vs 話し言葉 - Quick Conversion

| Speech | Writing | Rule |
|--------|---------|------|
| **だ / です** | **である** | Copula |
| **〜て、〜て** | **〜、〜** (stem) | Conjunction |
| **から / ので** | **したがって / よって** | Reason |
| **でも / けど** | **しかし / 一方** | Contrast |
| **私 / あなた** | **筆者 / 読者 / 本稿** | Pronouns |
| **〜と思う** | **〜と考えられる** | Opinion |
| **〜できない** | **〜不可能である** | Ability |
| **〜しない** | **〜不行う / 〜しない** | Negative |
| **たくさん** | **多数 / 多量** | Quantity |
| **ちょっと** | **やや / わずかに** | Degree |

## Genre-Specific Conventions

### News (ニュース記事)
- **Headline**: Noun phrases, 体言止め (taigen-dome - noun ending)
- **Lead**: である style, 5W1H
- **Body**: である/です・ます mix, passive, stem-linking
- **Attribution**: 〜と発表した, 〜と明らかにした

### Business Email (ビジネスメール)
- **Opening**: いつもお世話になっております。
- **Body**: です/ます + 敬語, clear paragraphs
- **Closing**: よろしくお願いいたします。

### Technical Blog (技術ブログ)
- **Tone**: です/ます or である (consistent)
- **Code/Commands**: 体言止め, imperative for steps
- **Explanation**: Stem-linking, logical connectors

### Creative Writing (小説・エッセイ)
- **Essay**: です/ます or だ/である (author's choice)
- **Novel**: Literary style, narrative mode consistency
- **Dialogue**: 話し言葉 (speech style) with quotation marks

## Practice: Convert to Written Style

**Speech**: 私は昨日、図書館へ行って、本を借りて、家で読みました。面白かったです。

**Writing (Standard)**: **昨日、図書館へ行き、本を借り、家で読んだ。面白かった。**

**Writing (Academic)**: **筆者は昨日、図書館にて図書を借用し、自宅にて熟読した。興味深い内容であった。**

**Writing (Novel)**: **昨日は図書館へ赴き、一冊の本を借りて帰った。頁を繰る手が止まらなかった。**

---

*Style = register + genre + medium. Choose your tools deliberately. The stem-linking + である combo is the skeleton of formal written Japanese. Master it, then bend it for your genre.*
