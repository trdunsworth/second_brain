# Onomatopoeia & Mimetic Words (擬音語・擬態語・擬声語)

## Overview
Japanese has **thousands** of sound-symbolic words. They're not "childish" - they're **essential** for native-level expression, appearing in novels, news, daily speech, and manga.

| Category | Japanese | Covers |
|----------|----------|--------|
| **擬音語** (Giongo) | Phonomimes | Actual sounds (bang, splash, creak) |
| **擬声語** (Giseigo) | Phonetic mimes | Animal/human sounds (meow, laugh, cry) |
| **擬態語** (Gitaigo) | Phenomimes | States/conditions/manner (silent, visual, emotional) |

> **Key**: Gitaigo describe **states without sound** - "glittering," "silently," "nervously." This is unique to Japanese.

---

## Grammatical Patterns

### Adverbial (修飾)
| Pattern | Example |
|---------|---------|
| **Word + と + Verb** | **ザーザーと**雨が降る。 |
| **Word + に + Verb** | **ニヤニヤしながら**歩く。 |
| **Word + する** | **ドキドキする** (heart pounds). |
| **Word + だ / です** | **シーンと**静かだ。 |

### Reduplication Patterns
| Pattern | Examples | Nuance |
|---------|----------|--------|
| **ABAB** (Full) | ワクワク, キラキラ, ペラペラ | Standard |
| **Ari** (Vowel change) | キラキラ → キラリ (single flash) | Momentary |
| **Aru** (Vowel change) | ワクワク → ワクッ (sudden) | Sudden onset |
| **A-A** (Single) | シーン, ポツン, ドーン | State/impact |

## Grammatical Integration

### As Adverbs (Most Common)
| Pattern | Example |
|---------|---------|
| **Word + と + Verb** | **ニヤニヤと**笑う。 |
| **Word + に + Verb** | **ワクワクに**待つ。 (Less common) |
| **Word + して + Verb** | **ドキドキして**待つ。 |

### As Predicates (with する/だ)
| Pattern | Example |
|---------|---------|
| **Word + する** | **ドキドキする**。 (Heart pounds.) |
| **Word + だ/です** | **シーンだ**。 (It's silent.) |

### As Adjectives (with な)
| Pattern | Example |
|---------|---------|
| **Word + な + Noun** | **ドキドキな**瞬間。 |
| **Word + な + 状態** | **イライラな**気分。 |

### Reduplication for Intensity
| Base | Intensive | Meaning Shift |
|------|-----------|---------------|
| **キラ** | **キラキラ** | Single flash → Continuous sparkle |
| **ピカ** | **ピカピカ** | Single flash → Shiny |
| **ドキ** | **ドキドキ** | Single beat → Pounding |
| **ワク** | **ワクワク** | Single thrill → Excitement |
| **ニヤ** | **ニヤニヤ** | Single smirk → Continuous smirking |
| **チラ** | **チラチラ** | Single glance → Repeated glancing |

## Practice: Identify & Use

1. **Rain**: **シトシト**降る / **ザーザー**降る / **ポツポツ**降る
2. **Heart**: **ドキドキ**する / **バクバク**する / **キュン**とする
3. **Walk**: **テキパキ**歩く / **ノロノロ**歩く / **フラフラ**歩く
4. **Laugh**: **クスクス**笑う / **ゲラゲラ**笑う / **ニヤニヤ**笑う
5. **Texture**: **モチモチ** / **フワフワ** / **サクサク** / **ネバネバ**
6. **Light**: **キラキラ** / **ギラギラ** / **チカチカ** / **ピカピカ**

## Study Strategy

1. **Group by semantic field** (Rain, Heart, Movement, Texture)
2. **Learn in pairs** (Light/Heavy, Fast/Slow, Pleasant/Unpleasant)
3. **Manga/Anime** - Visual context cements meaning
4. **Native content** - News, novels, variety shows
5. **Don't translate** - Feel the sound-symbolism

---

*Onomatopoeia/mimetics are the "texture" of Japanese. They're not decoration - they're precision tools for sensory and emotional reality. Start with the Top 50 (ドキドキ, ワクワク, ニヤニヤ, イライラ, テキパキ, サクサク, キラキラ, ザーザー, シトシト, グーグー...). The rest follow semantic patterns.*
