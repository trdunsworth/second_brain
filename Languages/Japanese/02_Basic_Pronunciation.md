# Basic Japanese Pronunciation

## Vowel System (5 Pure Vowels)

| Vowel | IPA | Description | English Approximation |
|-------|-----|-------------|----------------------|
| **a** | [a] | Open central unrounded | "father" (but shorter) |
| **i** | [i] | Close front unrounded | "machine" (but shorter) |
| **u** | [ɯ] | Close back unrounded (compressed) | "food" (but unrounded lips) |
| **e** | [e] | Mid front unrounded | "bed" (but purer) |
| **o** | [o] | Mid back rounded | "more" (but shorter, no diphthong) |

**Key**: Japanese vowels are **monophthongs** - pure, steady, no glide. Shorter than English vowels.

## Consonant System

### Stops (Plosives)
| Voiceless | Voiced | Notes |
|-----------|--------|-------|
| **k** [k] | **g** [ɡ] | |
| **t** [t] | **d** [d] | Dental, not alveolar |
| **p** [p] | **b** [b] | |

### Affricates
| Voiceless | Voiced | Notes |
|-----------|--------|-------|
| **ts** [ts] | **dz** [dz] | つ, づ - single mora |
| **ch** [tɕ] | **j** [dʑ] | ち, ぢ - palatalized |

### Fricatives
| Voiceless | Voiced | Notes |
|-----------|--------|-------|
| **s** [s] | **z** [z] | さ/ざ series |
| **sh** [ɕ] | **j** [ʑ] | し/じ - palatalized |
| **h** [h/ç/ɸ] | — | Varies by vowel (see below) |
| **f** [ɸ] | — | ふ only - bilabial, not labiodental |

### Nasals
| Sound | IPA | Notes |
|-------|-----|-------|
| **m** | [m] | ま row |
| **n** | [n] | な row |
| **ɴ** | [ɴ] | ん - uvular before pause, assimilates before consonants |

### Liquids
| Sound | IPA | Notes |
|-------|-----|-------|
| **r** | [ɾ] | **Alveolar tap/flap** - not English 'r' or 'l' |
| **ry** | [ɾʲ] | りゃ/りゅ/りょ - palatalized |

### Glides
| Sound | IPA | Notes |
|-------|-----|-------|
| **y** | [j] | や/ゆ/よ, きゃ/きゅ/きょ etc. |
| **w** | [w] | わ, を (often just [o]) |

## The "H" Row Allophony (Important!)

**h** [h] → **ひ** [ç] (palatal) → **ふ** [ɸ] (bilabial) → **へ** [he] → **ほ** [ho]

| Kana | IPA | Description |
|------|-----|-------------|
| は | [ha] | Standard [h] |
| ひ | [çi] | Palatal fricative (like German "ich") |
| ふ | [ɸɯ] | Bilabial fricative (blow through nearly closed lips) |
| へ | [he] | Standard [h] |
| ほ | [ho] | Standard [h] |

**With dakuten**: ば [ba], び [bi], ぶ [bɯ], べ [be], ぼ [bo] - all voiced stops
**With handakuten**: ぱ [pa], ぴ [pi], ぷ [pɯ], ぺ [pe], ぽ [po] - all voiceless stops

## The "N" (ん) Allophony

| Context | Pronunciation | Example |
|---------|---------------|---------|
| Before **p, b, m** | [m] | しんぶん (shinbun) → [ɕimbuɴ] |
| Before **t, d, n, r, z, s** | [n] | さんた (santa) → [santa] |
| Before **k, g** | [ŋ] | さんか (sanka) → [saŋka] |
| Before **vowels, y, w, h** | [ɰ̃] (nasalized vowel) | せんえん (sennen) → [seɰ̃eɴ] |
| **Utterance-final** | [ɴ] (uvular nasal) | ほん (hon) → [hoɴ] |
| Before **ch, j, sh** | [ɲ] | しんちょう (shinchou) → [ɕiɲtɕoː] |

## Pitch Accent Fundamentals

### Four Basic Patterns

| Pattern | Name | Description | Example |
|---------|------|-------------|---------|
| **0 (Heiban)** | 平板 | Flat - no drop, or drop after word | はし (chopsticks) [LHH] |
| **1 (Atamadaka)** | 頭高 | Head-high - drop after 1st mora | はし (bridge) [HLL] |
| **2 (Nakadaka)** | 中高 | Middle-high - drop after 2nd mora | はし (edge) [LHL] |
| **3+ (Odaka)** | 尾高 | Tail-high - drop after last mora (on particle) | さくら (cherry blossom) [LHH] + particle → [LHHL] |

### Notation Conventions
- **Numbers** = mora position of accent nucleus (last high mora)
- **0** = no accent nucleus (heiban)
- **Bold** or **【】** = accent nucleus in text: `ha【shi】` = nakadaka

### Particle Interaction
- **Heiban (0)**: Particle stays high → `sakura-ga` [LHHH]
- **Atamadaka (1)**: Particle low → `hashi-ga` [HLLL]
- **Nakadaka (n)**: Particle low → `hashi-ga` [LHLL]
- **Odaka (final)**: Particle low → `sakura-ga` [LHHL]

## Intonation Patterns

### Declarative
- Falling intonation at end
- `Tabemasu.` [↘]

### Yes/No Question
- Rising intonation on final particle
- `Tabemasu ka?` [↗]

### Wh-Question
- Falling intonation (like declarative)
- `Nani o tabemasu ka?` [↘]

### Listing / Incomplete
- Slight rise on each item, fall on last
- `Ringo, mikan, banana...` [↗] [↗] [↘]

## Devoicing Rules (Vowel Devoicing)

### High Vowels (i, u) devoice when:
1. **Between voiceless consonants**: `kita` [kita] → `kishi` [kiɕi] (not devoiced - between voiced), `suki` [sɯ̥ki]
2. **Word-final after voiceless**: `desu` [desɯ̥], `masu` [masɯ̥]
3. **Fast/casual speech**: More extensive

### Do NOT devoice:
- After voiced consonants: `gizu` [gizu], `tabi` [tabi]
- When accented: `tsu【ku】` [tsɯku]
- In careful/formal speech
- Long vowels: `suuji` [sɯːdʑi]

## Common Pronunciation Errors for English Speakers

| Error | Correction | Practice |
|-------|------------|----------|
| **R** as English [ɹ] or [l] | Alveolar tap [ɾ] - like "tt" in "butter" (AmE) | `らりるれろ` drills |
| **F** as [f] (labiodental) | Bilabial [ɸ] - blow through lips | `ふ` isolation, `コーヒー` |
| **H** in ひ as [h] | Palatal [ç] - like German "ich" | `ひと` [çito] |
| **U** as [u] (rounded) | Compressed [ɯ] - spread lips | `すき` [sɯ̥ki] |
| **N** as [n] everywhere | Assimilate! [m], [ŋ], [ɲ], [ɴ] | `さんか`, `しんぶん`, `ほん` |
| **Vowel length** ignored | Distinguish: `obasan` vs `obaasan` | Minimal pair drills |
| **Pitch accent** ignored | Learn with each word | Use OJAD, Forvo, dictionaries |
| **Stress accent** applied | No stress! Equal mora weight | Metronome practice |

## Practice Routine (Daily 10 min)

1. **Vowel purity** (2 min): Sustain each vowel, check for diphthongization
2. **Consonant articulation** (3 min): 
   - `かが`, `ただ`, `ぱば` - voicing pairs
   - `ふ` bilabial fricative
   - `ひ` palatal fricative
   - `らりるれろ` tapping
3. **Mora timing** (2 min): Speak with metronome (60-80 BPM), 1 mora = 1 click
4. **Pitch accent** (3 min): 
   - Review 10 words with known patterns
   - Shadow native audio (NHK, podcasts)
   - Record and compare
