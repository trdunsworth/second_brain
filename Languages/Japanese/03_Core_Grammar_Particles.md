# Core Grammar Particles - Complete Reference

## Overview
Particles (助詞 - じょし) are postpositional markers that indicate grammatical function. They attach to nouns/noun phrases. **Memorize these first** - they're the skeleton of every sentence.

---

## The Big 10 (Essential Particles)

### 1. は (wa) - Topic Marker
**Function**: Marks the **topic** (what the sentence is about). "As for X..."
- **Not** the subject marker (that's が)
- Implies contrast or "speaking of X"
- **Pronunciation**: written は, read **わ**

| Usage | Example | Translation |
|-------|---------|-------------|
| Topic introduction | **私は**学生です。 | **I** am a student. |
| Contrast | **魚は**好きですが、**肉は**嫌いです。 | **Fish** I like, but **meat** I dislike. |
| Scene-setting | **今日は**いい天気です。 | **Today** is good weather. |

> **Key distinction**: は = "As for X" (topic/comment) | が = "It is X that..." (subject/focus)

---

### 2. が (ga) - Subject Marker / Focus
**Function**: Marks the **grammatical subject** or **focus** of the predicate.

| Usage | Example | Translation |
|-------|---------|-------------|
| New information / focus | **だれが**来ましたか？ **田中さんが**来ました。 | **Who** came? **Tanaka-san** came. |
| Subject of adjectives/statives | **猫が**好きです。 | **Cats** are liked (by me). / I like cats. |
| Subject of intransitive verbs | **雨が**降っています。 | **Rain** is falling. |
| Exhaustive listing | **私**が行きます。 | **I** (and no one else) will go. |
| Subordinate clause subject | **彼が**読んでいる本 | The book **that he is reading** |

> **は vs が test**: "Who ate the cake?" → ケーキを**食べたのはだれ？** (topic: cake) vs **だれがケーキを食べた？** (focus: who)

---

### 3. を (o) - Direct Object Marker
**Function**: Marks the **direct object** of a transitive verb.
- **Pronunciation**: written を, read **お**

| Usage | Example | Translation |
|-------|---------|-------------|
| Direct object | **リンゴを**食べます。 | I eat **an apple**. |
| Object of motion verbs (traversing) | **公園を**走ります。 | I run **through the park**. |
| Object of departure | **家を**出ます。 | I leave **home**. |
| Causative object | **弟を**勉強させます。 | I make **my brother** study. |

> **Note**: With potential form (できます), object often becomes が: 日本語ができます (not を)

---

### 4. に (ni) - Target / Location / Time / Agent
**Function**: Multiple uses - "to, at, in, on, by"

| Usage | Example | Translation |
|-------|---------|-------------|
| **Destination** (with motion verbs) | **東京に**行きます。 | I go **to Tokyo**. |
| **Location of existence** (にある/いる) | **本棚に**本があります。 | There are books **on the bookshelf**. |
| **Specific time point** | **三時に**会います。 | Meet **at 3:00**. |
| **Frequency** (per) | **週に**二回。 | **Twice a week**. |
| **Agent** (passive/causative) | **先生に**褒められました。 | I was praised **by the teacher**. |
| **Purpose** (with motion verbs) | **買い物に**行きます。 | Go **for shopping**. |
| **Result of change** | **医者に**なりました。 | Became **a doctor**. |
| **Contact/recipient** | **友達に**あげます。 | Give **to a friend**. |

> **Time exception**: Relative time (today, tomorrow, every day) → **NO に**: 今日行く (not 今日**に**行く)

---

### 5. で (de) - Location of Action / Means / Cause / Scope
**Function**: "At (action location), by (means), due to, in (scope)"

| Usage | Example | Translation |
|-------|---------|-------------|
| **Action location** | **図書館で**勉強します。 | Study **at the library**. |
| **Means/Instrument** | **バスで**行きます。 | Go **by bus**. |
| **Language/Tool** | **日本語で**話します。 | Speak **in Japanese**. |
| **Cause/Reason** | **病気で**休みました。 | Rested **due to illness**. |
| **Scope/Group** | **クラスで**一番です。 | **In the class**, #1. |
| **Material** (with 作る) | **木で**作りました。 | Made **from wood**. |
| **Cost/Time spent** | **千円で**買いました。 | Bought **for 1000 yen**. |
| **State during action** | **立ちで**食べます。 | Eat **standing up**. |

> **に vs で**: 存在 (ある/いる/住む) → **に** | 動作 (action verbs) → **で**

---

### 6. と (to) - And / With / Quotation / Conditional
**Function**: Exhaustive "and", accompaniment, quotation, "if"

| Usage | Example | Translation |
|-------|---------|-------------|
| **Noun conjunction (exhaustive)** | **りんごと**みかん | **Apples and oranges** (only these) |
| **Accompaniment** | **友達と**行きます。 | Go **with a friend**. |
| **Quotation (with 思う/言う/聞く)** | **「行きます」と**言いました。 | Said "**I'll go**." |
| **Conditional (natural consequence)** | **春と**桜が咲く。 | **When spring comes**, cherry blossoms bloom. |
| **Comparison** | **彼と**同じです。 | Same **as him**. |

> **と vs や**: と = exhaustive list | や = non-exhaustive (etc.)

---

### 7. の (no) - Possession / Attribution / Nominalization / Apposition
**Function**: The most versatile particle - " 's, of, 's, that which"

| Usage | Example | Translation |
|-------|---------|-------------|
| **Possession** | **私の**本 | **My** book |
| **Attribution (noun modifies noun)** | **日本の**車 | **Japanese** car / Car **of Japan** |
| **Apposition (A = B)** | **東京の**都市 | The city **of Tokyo** / **Tokyo** city |
| **Nominalization (verb/adjective → noun)** | **食べるの**が好き | **Eating** is liked / I like **to eat** |
| **Subject in relative clause** | **私が**買った**の** | The one **I bought** |
| **Explanatory の (んです)** | **忙しいの**です。 | It's **that I'm busy**. |
| **Question softener** | **何の**本？ | **What kind of** book? |

---

### 8. も (mo) - Also / Too / Even / Neither
**Function**: Replaces は, が, を - adds "also" meaning

| Usage | Example | Translation |
|-------|---------|-------------|
| **Also (topic)** | **私も**行きます。 | **I also** go. |
| **Also (subject)** | **猫も**好きです。 | **Cats too** are liked. |
| **Also (object)** | **リンゴも**食べました。 | Ate **apples too**. |
| **Even (with question word)** | **誰も**来ません。 | **Nobody** came. (誰 + も = no one) |
| **Even (emphasis)** | **一分も**待ちません。 | Won't wait **even a minute**. |
| **Both/All (with counter)** | **両方も**欲しい。 | Want **both**. |

> **も replaces**: は, が, を (never combines: 私はも ✗ → 私も ○)

---

### 9. から (kara) - From / Since / Because
**Function**: Source (spatial/temporal), reason

| Usage | Example | Translation |
|-------|---------|-------------|
| **Spatial source** | **東京から**来ました。 | Came **from Tokyo**. |
| **Temporal source** | **九時から**始まります。 | Starts **from 9:00**. |
| **Material source** | **木から**紙を作る。 | Make paper **from wood**. |
| **Reason (clause + から)** | **雨だから**行きません。 | **Because it's raining**, won't go. |
| **Agent (passive)** | **彼から**聞きました。 | Heard **from him**. |

> **Reason**: [Sentence] + から / だから (da-kara for na-adj/nouns)

---

### 10. まで (made) - Until / To (limit) / Even
**Function**: Endpoint (time, space, degree)

| Usage | Example | Translation |
|-------|---------|-------------|
| **Time endpoint** | **五時まで**働きます。 | Work **until 5:00**. |
| **Spatial endpoint** | **駅まで**歩きます。 | Walk **to the station**. |
| **Degree (even)** | **子供まで**知っている。 | **Even children** know. |
| **Range (から...まで)** | **一時から三時まで** | **From 1:00 to 3:00** |

---

## Particle Combination Quick Reference

| Combo | Meaning | Example |
|-------|---------|---------|
| **では** (dewa) | In/at (contrast/topic) | **東京では**寒い |
| **へは** (e wa) | To (topic) | **学校へは**行きます |
| **には** (ni wa) | At/to (topic) | **ここには**ない |
| **では** (de wa) | By means (topic) | **バスでは**行けない |
| **とは** (to wa) | With/and (topic) | **彼とは**会った |
| **からは** (kara wa) | From (topic) | **ここからは**見えない |
| **までは** (made wa) | Until (topic) | **ここまでは**大丈夫 |
| **とも** (to mo) | With/and (also) | **友達とも**行った |
| **にも** (ni mo) | At/to (also) | **ここにも**ある |
| **でも** (de mo) | At/by (also) | **ここでも**売ってる |

## Special Particles (Next Level)

### や (ya) - Non-exhaustive "and"
- りんご**や**みかん**など** - Apples, oranges, **etc.**

### など (nado) - Etc. / Such things
- Often pairs with や: 果物**や**野菜**など**

### しか (shika) - Only (with negative verb)
- お金**しか**ない - Have **only** money (nothing else)

### だけ (dake) - Only / Just
- これ**だけ**ください - **Just this** please.

### ばかり (bakari) - Only / Nothing but / Just did
- 甘いもの**ばかり**食べる - Eat **nothing but** sweets.
- 食べた**ばかり** - **Just finished** eating.

### ほど (hodo) - Degree / Extent / Comparison
- 死ぬ**ほど**痛い - Hurts **enough to die** / **so much that**...
- 彼**ほど**優しい人はいない - No one **as kind as** him.

### ぐらい / くらい (gurai/kurai) - Approximately / About
- 三十分**ぐらい** - **About** 30 minutes.

### さえ (sae) - Even (emphasis)
- 子供**さえ**できる - **Even a child** can do it.

### すら (sura) - Even (literary/formal)
- 専門家**すら**知らない - **Even experts** don't know.

### こそ (koso) - Precisely / For sure (emphasis on preceding)
- あなた**こそ**行くべきだ - **You** (precisely) should go.

## Particle Decision Flowchart

```
Is it the TOPIC (known info, contrast)?
  YES → は
  NO → Continue

Is it the SUBJECT of stative/adjective/potential?
  YES → が
  NO → Continue

Is it the FOCUS (new info, "who/what did X")?
  YES → が
  NO → Continue

Is it a DIRECT OBJECT of transitive verb?
  YES → を
  NO → Continue

Is it DESTINATION / TIME POINT / EXISTENCE LOCATION / AGENT?
  YES → に
  NO → Continue

Is it ACTION LOCATION / MEANS / CAUSE / SCOPE?
  YES → で
  NO → Continue

Is it "AND" (exhaustive) / WITH / QUOTATION?
  YES → と
  NO → Continue

Is it POSSESSION / ATTRIBUTION / NOMINALIZATION?
  YES → の
  NO → Continue

Is it "ALSO / TOO / EVEN"?
  YES → も (replaces は/が/を)
  NO → Continue

Is it "FROM" (source) / "BECAUSE"?
  YES → から
  NO → Continue

Is it "UNTIL / TO (limit)"?
  YES → まで
```

### は vs が Drills
- 私は医者です。 (Topic: me)
- 私が医者です。 (Focus: it's ME who is the doctor)
- 象は鼻が長い。 (Topic: elephant; Subject of adjective: nose)
- 雨が降っている。 (Subject of intransitive verb)
