# Advanced Keigo (敬語) - Complete Business & Formal System

## Keigo Architecture Review

| Category | Direction | Purpose | Core Question |
|----------|-----------|---------|---------------|
| **尊敬語** (Sonkeigo) | Others' actions ↑ | Elevate listener/superior | **Who does the action?** → Other (respected) |
| **謙譲語** (Kenjougo) | My actions ↓ | Humble self/in-group | **Who does the action?** → Me (humble) |
| **丁寧語** (Teineigo) | Neutral ↑ | General politeness | **Default polite register** |

> **Golden Rule**: **Action-doer determines keigo type**, not the sentence subject!

## Keigo Patterns (Productive Rules)

### 1. お/ご + Stem + になる (Sonkeigo)
**Rule**: **お** for 和語 (native), **ご** for 漢語 (Sino-Japanese)
| Verb | Stem | Sonkeigo |
|------|------|----------|
| 読む | 読み | **お読みになる** |
| 書く | 書き | **お書きになる** |
| 待つ | 待ち | **お待ちになる** |
| 連絡する | 連絡 | **ご連絡になる** |
| 報告する | 報告 | **ご報告になる** |
| 説明する | 説明 | **ご説明になる** |

> **Exception**: Verbs with special Sonkeigo (見る→ご覧になる, 食べる→召し上がる) don't use this pattern.

### 2. お/ご + Stem + する/いたす (Kenjougo)
| Verb | Stem | Kenjougo |
|------|------|----------|
| 待つ | 待ち | **お待ちする / お待ちいたす** |
| 連絡する | 連絡 | **ご連絡する / ご連絡いたす** |
| 報告する | 報告 | **ご報告する / ご報告いたす** |
| 説明する | 説明 | **ご説明する / ご説明いたす** |
| 連絡する | 連絡 | **ご連絡する / ご連絡いたす** |

> **いたす** > **する** in humility. **ご連絡いたします** is standard business.

### 3. Double Keigo (二重敬語) - **FORBIDDEN!**
| Wrong | Correct | Reason |
|-------|---------|--------|
| **お読みになられる** | お読みになる / 読まれる | Double Sonkeigo |
| **拝見させていただく** | 拝見する / 見せていただく | Double Kenjougo |
| **おっしゃられる** | おっしゃる | Double Sonkeigo |
| **いただかれる** | いただく / くださる | Double Kenjougo |
| **ご覧になられる** | ご覧になる | Double Sonkeigo |

## Business Email Keigo (実践ビジネスメール)

### Standard Template
```
件名：【御礼】〇〇の件について（株式会社〇〇　田中太郎）

株式会社〇〇
山田様

いつも大変お世話になっております。
株式会社〇〇の田中でございます。

先日は、貴重なお時間をいただき、誠にありがとうございました。
ご説明いただいた内容について、社内で検討させていただきたく存じます。

つきましては、来週の月曜日までにご連絡を差し上げたく存じますが、
ご都合のよいお時間帯などございましたら、ご教示いただけますと幸いです。

お忙しいところ恐縮ですが、何卒よろしくお願い申し上げます。

--------------------------------------------------
株式会社〇〇
営業部　田中太郎
TEL: 03-xxxx-xxxx
Email: tanaka@xxx.co.jp
```

### Key Email Phrases

| Situation | Phrase |
|-----------|--------|
| **Opening** | いつも大変お世話になっております。 / 平素より格別のご高配を賜り、厚く御礼申し上げます。 |
| **Reference** | 先日はありがとうございました。 / このたびはご連絡いただき、誠にありがとうございます。 |
| **Request** | ご検討いただけますと幸いです。 / ご確認いただけますでしょうか。 |
| **Scheduling** | ご都合のよい日程をご教示いただけますでしょうか。 / ご調整いただけますと幸いです。 |
| **Sending** | 資料をお送りいたします。 / 別途メールにて送付させていただきます。 |
| **Apology** | ご迷惑をおかけし、誠に申し訳ございません。 / この度は大変失礼いたしました。 |
| **Closing** | 何卒よろしくお願い申し上げます。 / 今後とも変わらぬご指導ご鞭撻のほど、よろしくお願い申し上げます。 |

## Phone Keigo (電話応対)

### Answering
- **「はい、株式会社〇〇でございます。」** (Company name + でございます)
- **「〇〇部の田中でございます。」** (Department + name + でございます)

### Asking for Someone
- **「〇〇様をお願いいたします。」** (Standard)
- **「〇〇様はいらっしゃいますでしょうか。」** (Polite)

### Putting on Hold
- **「少々お待ちくださいませ。」** (Standard)
- **「お待たせいたしました。」** (Returning)

### Taking Message
- **「承知いたしました。○○様からお電話があった旨、伝えておきます。」**
- **「ご伝言を承ります。」** (Formal)

### Not Available
- **「ただいま席を外しております。」** (Away from desk)
- **「本日は外出しております。」** (Out of office)
- **「担当の者が不在でございます。」** (Person in charge absent)

### Hanging Up
- **「失礼いたします。」** (Standard)
- **「では、失礼させていただきます。」** (More polite)

## Keigo for Specific Roles

### To Customers (お客様)
- **Full Sonkeigo + Kenjougo + Teineigo**
- **「お客様、ご注文を承ります。」**
- **「ご不明な点がございましたら、お申し付けください。」**

### To Superiors (上司・先輩)
- **Sonkeigo for their actions, Kenjougo for yours**
- **「部長、ご確認いただけますでしょうか。」**
- **「資料を作成いたしましたので、ご査収ください。」**

### To Colleagues (同僚)
- **Teineigo (です/ます) + Light Kenjougo**
- **「これ、見ていただけますか。」**
- **「確認しておきます。」**

### To Subordinates (部下・後輩)
- **Teineigo or Plain + Light Sonkeigo for their effort**
- **「よくやった。」/ **「ご苦労様。」**
- **「確認しておいて。」**

### To External Partners (取引先)
- **Full Keigo (like customers)**
- **「貴社のご発展をお祈り申し上げます。」**

## Common Keigo Mistakes (NG集)

| NG | OK | Reason |
|----|-----|--------|
| **「了解しました。」** (to superior) | **「承知いたしました。」** / **「かしこまりました。」** | 了解 = peer/equal |
| **「ご苦労様です。」** (to superior) | **「お疲れ様です。」** | ご苦労様 = superior→subordinate |
| **「お疲れ様でした。」** (leaving early) | **「お先に失礼します。」** | Context mismatch |
| **「失礼します。」** (entering) | **「お邪魔します。」** / **「失礼いたします。」** | 失礼します = leaving |
| **「お座りください。」** | **「おかけください。」** / **「どうぞおかけになってください。」** | お座り = child/dog |
| **「わかります。」** | **「承知しております。」** / **「存じております。」** | 分かる = casual |
| **「知りません。」** | **「存じ上げておりません。」** | 知らない = casual |
| **「行きます。」** | **「参ります。」** / **「伺います。」** | 行く = casual |
| **「来ます。」** | **「いらっしゃいます。」** / **「お見えになります。」** | 来る = casual |
| **「食べます。」** | **「召し上がります。」** / **「いただきます。」** | 食べる = casual |

## Practice: Keigo Transformation

**Base**: 部長が資料を確認して、私に返す。

1. **Sonkeigo (部長's action)**: 部長が資料を**ご確認になり**、私に**お返しになる**。
2. **Kenjougo (My action)**: 部長が資料を**ご確認になり**、私に**お返しいただく**。
3. **Full Business**: 部長が資料を**ご確認の上、ご返却いただけますでしょうか。**
4. **Email Request**: 資料を**ご確認いただき、ご返却いただけますと幸いです。**

---

*Keigo is not "polite language" - it's "relational grammar." Every verb choice maps your social coordinates. Memorize the 20 core verb triplets (する/なさる/いたす, 行く/いらっしゃる/参る, etc.). The rest are productive patterns (お/ご+stem+になる/する).*
