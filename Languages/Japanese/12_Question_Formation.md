# Question Formation - Complete Guide

## Core Principle: **Wh-words Stay In Place!**

Unlike English, Japanese question words **do not move** to the front. They remain in their grammatical position.

| English (Wh-fronting) | Japanese (In-situ) |
|----------------------|-------------------|
| **What** did you eat? | あなたは**何を**食べましたか？ |
| **Where** are you going? | **どこへ**行きますか？ |
| **Who** came? | **誰が**来ましたか？ |

---

## Yes/No Questions

### 1. Formal: か (ka)
- **学生ですか。** → **学生ですか？** (Are you a student?)
- **行きますか？** (Will you go?)

### 2. Casual: Rising Intonation ↗
- **学生？** (Student?)
- **行く？** (Going?)

### 3. Explanatory: の/ん (no/n) + か / Rising
- **学生なの？** (Is it that you're a student?)
- **行くんですか？** (Is it that you'll go?)

> **Usage**: Seeking explanation, confirming understanding, surprise

## Wh-Questions (疑問詞 - ぎもんし)

### Question Word Inventory

| Word | Reading | Function | Particle Notes |
|------|---------|----------|----------------|
| **何** | なに / なん | What | **何**を, **何**で, **何**に, **何**と |
| **誰** | だれ | Who | **誰**が, **誰**を, **誰**に, **誰**と |
| **どこ** | どこ | Where | **どこ**に, **どこ**へ, **どこ**で, **どこ**から |
| **いつ** | いつ | When | **いつ** (no に for relative time) |
| **なぜ / どうして** | なぜ / どうして | Why | Stands alone or + から/ので |
| **どう** | どう | How / What kind | **どう**でしたか, **どう**思う |
| **どれ** | どれ | Which one (3+) | **どれ**が, **どれ**を, **どれ**に |
| **どっち** | どっち | Which (2) | **どっち**が, **どっち**を |
| **どの** | どの | Which (modifies noun) | **どの**本, **どの**人 |
| **何時** | なんじ | What time | **何時**に |
| **幾つ / いくつ** | いくつ | How many (age, general) | **いくつ**ですか |
| **いくら** | いくら | How much (price) | **いくら**ですか |
| **どのくらい / どのぐらい** | どのくらい | How much/long/many | **どのくらい**かかりますか |

## Wh-Word + Particle Combinations

### 何 (What)
| Combo | Reading | Function | Example |
|-------|---------|----------|---------|
| **何** | なに | Direct object | **何**を食べますか？ |
| **何** | なん | Before counter/particle | **何**時ですか、**何**人ですか |
| **何で** | なんで / なにで | Why / By what means | **何で**来ましたか？ |
| **何に** | なにに | Target | **何に**興味がありますか？ |
| **何と** | なんと | With whom / Quotation | **何と**言いましたか？ |
| **何でも** | なんでも | Anything | **何でも**食べます。 |

### 誰 (Who)
| Combo | Function | Example |
|-------|----------|---------|
| **誰が** | Subject (focus) | **誰が**来ましたか？ |
| **誰を** | Object | **誰を**待ちますか？ |
| **誰に** | Recipient/Target | **誰に**あげますか？ |
| **誰と** | Accompaniment | **誰と**行きますか？ |
| **誰の** | Possession | **誰の**本ですか？ |

### どこ (Where)
| Combo | Function | Example |
|-------|----------|---------|
| **どこに** | Existence/Destination | **どこに**ありますか？ / **どこに**行きますか？ |
| **どこへ** | Direction | **どこへ**行きますか？ |
| **どこで** | Action location | **どこで**食べますか？ |
| **どこから** | Source | **どこから**来ましたか？ |
| **どこまで** | Limit | **どこまで**行きますか？ |

### いつ (When) - **NO に for Relative Time!**
| Correct | Incorrect | Reason |
|---------|-----------|--------|
| **いつ**行きますか？ | **いつに**行きますか？ | Relative time = no particle |
| **三時に**行きます。 | **三時**行きます。 | Absolute time = に |

## Embedded Questions (Indirect Questions)

### Structure: [Wh-clause] + か / かどうか / のか

| Type | Structure | Example |
|------|-----------|---------|
| **Yes/No** | [Sentence] + **かどうか** | **彼が来るかどうか**分かりません。 (Don't know **whether he'll come**.) |
| **Yes/No** | [Sentence] + **か** | **雨が降るか**分かりません。 |
| **Wh-question** | [Wh-clause] + **か** | **どこへ行くか**知っていますか？ (Know **where he's going**?) |
| **Wh-question** | [Wh-clause] + **のか** | **何が起きたのか**教えてください。 (Tell me **what happened**.) |

> **Tense in embedded clause**: Matches perspective time, not speech time
> - **どこへ行くか**知っていますか？ (Where does he go? / Where will he go?)
> - **どこへ行ったか**知っていますか？ (Where did he go?)

## Question Word + も / でも / か - Indefinite Pronouns

| Base | + も (w/ neg) | + でも | + か (in question) |
|------|---------------|--------|-------------------|
| **誰** | **誰も** (no one) | **誰でも** (anyone) | **誰か** (someone) |
| **何** | **何も** (nothing) | **何でも** (anything) | **何か** (something) |
| **どこ** | **どこも** (nowhere) | **どこでも** (anywhere) | **どこか** (somewhere) |
| **いつ** | **いつも** (always) | **いつでも** (anytime) | **いつか** (sometime) |
| **どれ** | — | **どれでも** (whichever) | **どれか** (one of them) |

### Usage Examples
- **誰も**来ませんでした。 (Nobody came.)
- **誰でも**できます。 (Anyone can do it.)
- **何か**食べたいですか？ (Want to eat something?)
- **どこか**行きたい。 (Want to go somewhere.)

## Rhetorical Questions

### 1. ことか / ものか - "No Way!" / "Absolutely Not!"
- **こんなこと、できるものか！** (Like I could do such a thing!)
- **彼が嘘をつくことか！** (He would never lie!)

### 2. か (Falling intonation) - "As if!"
- **私が負けるか！** (Me, lose? No way!)

### 3. わけがない / はずがない - "There's No Way"
- **彼が犯人なわけがない。** (There's no way he's the culprit.)

## Polite vs Casual Question Forms

| Type | Polite (です/ます) | Casual (Plain) |
|------|-------------------|----------------|
| **Yes/No** | 行きますか？ | 行く？ / 行くの？ |
| **Wh-Question** | 何**を**食べますか？ | 何**を**食べる？ / 何**を**食べるの？ |
| **Embedded** | どこへ行く**か**知っていますか？ | どこへ行く**か**知ってる？ |
| **Negative Q** | 行きませんか？ | 行かない？ / 行かないの？ |
| **Invitation** | 行きませんか？ | 行かない？ |

> **Negative question invitation**: 行きませんか？ = "Won't you go?" = "Let's go!"
> **Casual**: 行かない？ = "Wanna go?"

## Tag Questions / Confirmation Seeking

| Form | Structure | Nuance |
|------|-----------|--------|
| **ね** | [Statement] + ね | "Right?" (shared knowledge) |
| **よね** | [Statement] + よね | "Right?" (I think so, confirm) |
| **だろう/でしょう** | [Plain/Polite] + だろう/でしょう | "Probably," "Right?" (inference) |
| **じゃない/じゃありません** | [Noun/な-adj] + じゃない | "Isn't it?" |
| **ない/ありません** | [Verb/い-adj] + ない | "Isn't it?" / "Don't you?" |

### Examples
- **いい天気ですね。** (Nice weather, huh?)
- **学生**じゃ**ない？** (You're a student, right?)
- **来る**だろう？ (He'll come, right?)
- **高く**ない？ (Isn't it expensive?)

## Alternative Questions (A or B)

### Structure: A か B か
- **コーヒー**か**お茶**か、**どちら**がいいですか？ (Coffee or tea, which do you prefer?)
- **行く**か**行かない**か、決めてください。 (Decide whether to go or not.)

### Casual: A? B?
- **コーヒー？お茶？**

## Practice: Form Questions

**Base**: 田中さんは図書館で本を読みました。 (Tanaka-san read a book at the library.)

1. **Who** read? → **誰が**図書館で本を読みましたか？
2. **Where** did he read? → 田中さんは**どこで**本を読みましたか？
3. **What** did he read? → 田中さんは図書館で**何を**読みましたか？
4. **When** did he read? → 田中さんは**いつ**図書館で本を読みましたか？
5. **Did** he read? → 田中さんは図書館で本を読みました**か**？
6. **Did he read at the library?** → 田中さんは図書館**で**本を読みました**か**？
7. **Was it a book?** → 田中さんは図書館で**本を**読みました**か**？

## Question Intonation Patterns

| Pattern | Example | Meaning |
|---------|---------|---------|
| **Final rise** ↗ | 行きますか？ | Standard question |
| **Final fall** ↘ | 行きますか。 | Rhetorical / Angry / Confirmation |
| **Rise-fall** ↗↘ | **誰が**来ましたか？ | Wh-question (focus on wh-word) |
| **Flat** → | そうなんですか。 | Realization / Backchannel |
