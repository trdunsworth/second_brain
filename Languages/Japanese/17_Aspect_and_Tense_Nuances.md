# Aspect & Tense Nuances - Beyond Basic Conjugation

## Tense vs Aspect: The Critical Distinction

| Concept | Japanese Term | English Equivalent |
|---------|---------------|-------------------|
| **Tense** (時制 - じせい) | Past / Non-past | When action occurs |
| **Aspect** (相 - そう) | Perfective / Imperfective / Progressive / Stative | How action unfolds in time |

**Japanese has NO future tense!** Non-past = Present OR Future (context decides).

---

## Verb Aspects in Detail

### 1. Perfective (完了相) - Completed Action
**Forms**: た-form, ない-form + かった, etc.
- **Action viewed as complete whole**
- **私は本を読んだ。** (I read the book - done)

### 2. Imperfective (未完了相) - Ongoing/Habitual/Future
**Forms**: Dictionary form, ます-form, ない-form
- **Action viewed as incomplete, ongoing, or habitual**
- **私は本を読む。** (I read books / I will read the book)

### 3. Progressive (進行相) - In Progress RIGHT NOW
**Form**: て-form + いる
- **私は本を読んでいる。** (I am reading the book RIGHT NOW)

### 4. Resultative State (結果状態) - Result Persists
**Form**: て-form + いる (with change-of-state verbs)
- **ドアが開いている。** (The door IS OPEN - result of opening)
- **彼は死んでいる。** (He IS DEAD - result of dying)

### 5. Habitual (習慣相) - Regular Occurrence
**Form**: Dictionary/ます-form + ことが多い / いつも
- **私は毎日本を読む。** (I read books every day.)

### 6. Experiential (経験相) - Have Done Before
**Form**: た-form + ことがある
- **私は富士山に登ったことがある。** (I have climbed Mt. Fuji.)

## ている (te-iru) - The Shape-Shifter

### Three Distinct Meanings by Verb Type

| Verb Class (Vendler) | Examples | ている Meaning | Example |
|----------------------|----------|----------------|---------|
| **Activity** (継続動詞) | 走る, 泳ぐ, 書く, 食べる, 話す, 働く, 遊ぶ | **Progressive** (In progress) | **走っている** (Running now) |
| **Accomplishment** (完了動詞) | 本を読む, 手紙を書く, 家を建てる | **Progressive** (In progress) | **本を読んでいる** (Reading book) |
| **Achievement** (瞬間動詞) | 着く, 死ぬ, 割れる, 開く, 閉まる, 着く, 起きる, 知る | **Result State** (After completion) | **着いている** (Has arrived / Is here) |
| **State** (状態動詞) | 知る, 分かる, いる, ある, 好き, できる | **Continuous State** | **知っている** (Know - not "learning") |

### Achievement Verbs: Progressive vs Result

| Verb | ている = Progressive? | ている = Result State? |
|------|----------------------|----------------------|
| 着く (tsuku - arrive) | ✗ | **着いている** = Is here (arrived) |
| 死ぬ (shinu - die) | ✗ | **死んでいる** = Is dead |
| 知る (shiru - get to know) | ✗ | **知っている** = Know |
| 開く (aku - open) | ✗ | **開いている** = Is open |
| 結婚する (kekkon suru) | ✗ | **結婚している** = Is married |

> **To force progressive with achievement verbs**: Use **ているところだ** (in the process of)
> - **今、死んでいるところだ。** (In the process of dying right now.)

## てある (te-aru) vs ておく (te-oku) vs ている (te-iru)

### All THREE require TRANSITIVE verbs!

| Form | Structure | Focus | Agent | Example |
|------|-----------|-------|-------|---------|
| **ている** | Transitive + ている | Action in progress / State | Subject doing | **ドアを開けている** (Opening the door / Keep door open) |
| **てある** | Transitive + てある | **Result state** (intentional) | **Unstated/Implied** | **ドアが開けてある** (Door has been opened [by someone]) |
| **ておく** | Transitive + ておく | **Preparation** for future | **Subject** (doer) | **ドアを開けておく** (Will open door in advance) |

### Nuance Comparison

> **Situation**: You prepare documents for a meeting tomorrow.

| Sentence | Meaning |
|----------|---------|
| **書類を準備している。** | Currently preparing / Have prepared (focus on action/state) |
| **書類が準備してある。** | Documents are prepared (focus on result, ready state) |
| **書類を準備しておく。** | Will prepare documents (for future use) |
| **書類を準備しておいた。** | Prepared documents (in advance, done) |

## たり〜たり (Representative Actions)

**Structure**: [た-form + り] + [た-form + り] + する/した

| Meaning | Example |
|---------|---------|
| **Non-exhaustive listing** (did X, did Y, etc.) | **本を読んだり、音楽を聴いたりした。** (Read books, listened to music, etc.) |
| **Alternating states** | **雨が降ったり、やんだりする。** (Rain starts and stops.) |
| **Habitual variety** | **休みの日は、映画を見たり、買い物に行ったりする。** |

> **Implication**: "And other things too" - not exhaustive!

---

## ばかり (bakari) - Multiple Meanings

### 1. "Only / Nothing but" (with Nouns/Verbs)
> **甘いものばかり食べる。** (Eat nothing but sweets.)
> **文句ばかり言っている。** (Just keeps complaining.)

### 2. "Just did / Just finished" (に/は + ばかり)
> **食べたばかりだ。** (Just finished eating.)
> **来たばかりです。** (Just arrived.)

### 3. "About to" (ところ + ばかり - rare)
> **行くところばかりだ。** (Just about to go.)

### 4. "Approximately" (with Numbers - colloquial)
> **百人ばかり来た。** (About 100 people came.)

## Aspectual Auxiliaries (補助動詞 - ほじょどうし)

Attach to **Ren'youkei (Stem/て-form)** to add aspectual nuance.

### On て-form

| Auxiliary | Meaning | Example |
|-----------|---------|---------|
| **〜てみる** | Try doing | **食べてみる** (Try eating) |
| **〜てしまう** | Complete (regret/unintentional) | **ケーキを食べてしまった** (Ate all the cake - oops) |
| **〜ておく** | Do in advance | **予約しておく** (Reserve in advance) |
| **〜てある** | Result state (transitive) | **予約してある** (Reserved/ready) |
| **〜ていく** | Start & continue / Go doing | **歩いていく** (Walk on / Start walking) |
| **〜てくる** | Come doing / Have been doing | **雨が降ってきた** (Started raining) |
| **〜てみせる** | Show by doing | **やってみせる** (Do it to show) |
| **〜てやる** | Do for someone (downward) | **宿題をやってやる** (Do HW for him) |
| **〜てあげる** | Do for someone (equal/up) | **荷物を持ってあげる** (Carry luggage for you) |
| **〜てもらう** | Receive favor | **直してもらう** (Have it fixed) |

### On Stem (Ren'youkei)

| Auxiliary | Meaning | Example |
|-----------|---------|---------|
| **〜始める** | Start doing | **雨が降り始めた** (Started raining) |
| **〜終わる** | Finish doing | **読み終わった** (Finished reading) |
| **〜続ける** | Continue doing | **歩き続ける** (Keep walking) |
| **〜やめる** | Stop doing | **タバコをやめる** (Quit smoking) |
| **〜すぎる** | Do too much | **食べすぎた** (Ate too much) |
| **〜やすい** | Easy to do | **この本は読みやすい** (Easy to read) |
| **〜にくい** | Hard to do | **漢字は書きにくい** (Hard to write) |
| **〜がたい** | Hard to do (emotional/formal) | **信じがたい** (Hard to believe) |
| **〜そうだ** | Seems like | **雨が降りそうだ** (Looks like rain) |
| **〜そうもない** | Doesn't seem like | **勝てそうもない** (Doesn't seem winnable) |

## Tense in Subordinate Clauses (Relative Tense)

**Tense in subordinate clause is RELATIVE to main clause time, not speech time.**

### When Main Clause is PAST

| Subordinate Form | Meaning | Example |
|------------------|---------|---------|
| **Dictionary** (Non-past) | Same time or Future relative to past | **行く**と言った。 (Said [he] **will go**.) |
| **た-form** (Past) | Before main clause past | **行った**と言った。 (Said [he] **went**.) |
| **ていた-form** | Ongoing at that past time | **行っていた**と言った。 (Said [he] **was going**.) |

### Examples
> **彼が来る**と**思う**と思う。 (Think he **will come**.) - Present main
> **彼が来る**と**思った**思った。 (Thought he **would come**.) - Past main, same dict form!
> **彼が来た**と**思う**思う。 (Think he **came**.) - Past subordinate
> **彼が来た**と**思った**思った。 (Thought he **had come**.) - Both past

> **Rule**: In reported speech/thought, **tense doesn't backshift** like English!

## Future Expression Strategies (No Future Tense!)

| Strategy | Form | Example | Nuance |
|----------|------|---------|--------|
| **Non-past + Time** | 明日、行く | "Tomorrow I go" | Scheduled/Plan |
| **つもりだ** | 行くつもりだ | "Intend to go" | Intention |
| **予定だ** | 行く予定だ | "Plan to go" | Schedule |
| **だろう/でしょう** | 行くだろう | "Probably will go" | Conjecture |
| **はずだ** | 行くはずだ | "Supposed to go" | Expectation |
| **ことにする** | 行くことにする | "Decide to go" | Decision |
| **ことになる** | 行くことになった | "It's been decided" | External decision |
| **〜う/よう** (Volitional) | 行こう | "Let's go / I'll go" | Volition |

## Aspect Summary Table

| Aspect | Form | Verb Type | Meaning |
|--------|------|-----------|---------|
| **Perfective** | た-form | All | Completed |
| **Imperfective** | Dict/ます | All | Non-past (Pres/Fut/Habit) |
| **Progressive** | て-form + いる | Activity/Accomplishment | In progress |
| **Result State** | て-form + いる | Achievement | After completion |
| **Stative** | て-form + いる | State | Continuous state |
| **Experiential** | た-form + ことがある | All | Have done before |
| **Preparatory** | て-form + おく | Transitive | Do in advance |
| **Result (passive)** | て-form + ある | Transitive | Intentional result |
| **Inceptive** | Stem + 始める | All | Start doing |
| **Completive** | Stem + 終わる | All | Finish doing |
| **Continuative** | Stem + 続ける | All | Keep doing |
| **Excessive** | Stem + すぎる | All | Do too much |

## Practice: Identify Aspect

1. 今、本を読んでいる。 → **Progressive** (Activity)
2. 彼はもう着いている。 → **Result State** (Achievement: 着く)
3. 毎朝、走る。 → **Habitual** (Imperfective)
4. 富士山に登ったことがある。 → **Experiential**
5. 宿題をしておいた。 → **Preparatory** (ておく)
6. ドアが開けてある。 → **Result State** (てある - transitive)
7. 雨が降り始めた。 → **Inceptive** (始める)
8. ケーキを食べてしまった。 → **Completive + Regret** (てしまう)

---

*Aspect is how time flows inside the verb. Japanese cares more about aspect than tense. Master ている's three faces - it's the most used and most misunderstood form.*
