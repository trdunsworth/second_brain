# Japanese Dialects Overview (方言 - ほうげん)

## Overview
Standard Japanese (標準語 - 標準語) is based on **Tokyo dialect**. However, Japan has **rich dialectal diversity**. Understanding major dialects is crucial for:
- **Media comprehension** (anime, drama, variety shows)
- **Travel/Regional communication**
- **Cultural literacy**

---

## Major Dialect Groups

| Group | Regions | Major Cities | Mutual Intelligibility |
|-------|---------|--------------|----------------------|
| **Eastern (東日本)** | Kanto, Tohoku, Hokkaido | Tokyo, Sendai, Sapporo | High (Standard base) |
| **Western (西日本)** | Kansai, Chugoku, Shikoku, Kyushu | Osaka, Kyoto, Hiroshima, Fukuoka | Moderate |
| **Kyushu (九州)** | Kyushu island | Fukuoka, Kagoshima, Nagasaki | Low-Moderate |
| **Okinawan (琉球)** | Okinawa islands | Naha | **Very Low** (separate language family) |

## Kansai Dialect (関西弁) - Most Important for Learners

### Why Kansai?
- **2nd largest population** (Keihanshin: Osaka, Kyoto, Kobe)
- **Dominant in comedy/variety TV**
- **Distinct grammar** (not just accent)

### Key Features

#### 1. Copula
| Standard | Kansai | Example |
|----------|--------|---------|
| **だ** | **や** | 学生**や** / これ**や** |
| **です** | **です** / **やす** | 学生**です** / 学生**やす** (polite) |
| **ではない** | **やない** / **ちゃう** | 学生**やない** / 学生**ちゃう** |
| **だった** | **やった** | 学生**やった** |

#### 2. Negative Verbs
| Standard | Kansai | Example |
|----------|--------|---------|
| **〜ない** | **〜へん** / **〜ん** | 行か**へん** / 行か**ん** |
| **〜ません** | **〜まへん** | 行き**まへん** |
| **〜なかった** | **〜へんかった** / **〜なんだ** | 行か**へんかった** |

#### 3. Progressive (〜ている)
| Standard | Kansai | Example |
|----------|--------|---------|
| **〜ている** | **〜てる** / **〜とる** | 食べ**てる** / 食べ**とる** |

#### 4. Causative/Passive
| Standard | Kansai | Example |
|----------|--------|---------|
| **〜させる** | **〜さす** | 食べ**さす** |
| **〜られる** | **〜られる** (same) | 食べ**られる** |

#### 5. Particles
| Standard | Kansai | Nuance |
|----------|--------|--------|
| **よ** | **で** / **や** | 知ってる**で** / 知ってる**や** |
| **ね** | **な** / **やん** | いい**な** / いい**やん** |
| **から** | **さかい** / **け** | 雨**さかい** / 雨**け** |
| **ので** | **さかい** | 忙しい**さかい** |

#### 6. Vocabulary Differences
| Standard | Kansai | Meaning |
|----------|--------|---------|
| **ありがとう** | **おおきに** | Thank you |
| **だめ** | **あかん** | No good |
| **違う** | **ちゃう** | Wrong/different |
| **すごい** | **えらい** | Amazing / Terrible |
| **疲れた** | **しんどい** | Tired |
| **捨てる** | **ほる** | Throw away |
| **帰る** | **かえる** (same) | Return |
| **自分** | **わて** / **おい** | I/me (male) |
| **お前** | **おまはん** / **あんた** | You |
| **どこ** | **どこら** | Where |

#### 7. Sentence Endings
| Standard | Kansai | Example |
|----------|--------|---------|
| **〜よ** | **〜で** / **〜や** | 行くっ**で** / 行くっ**や** |
| **〜ね** | **〜な** / **〜やん** | ええ**な** / ええ**やん** |
| **〜かな** | **〜かいな** | 来る**かいな** |
| **〜かも** | **〜かもせん** | 来る**かもせん** |

### Osaka vs Kyoto vs Kobe
| Feature | Osaka | Kyoto | Kobe |
|---------|-------|-------|------|
| **Copula** | や | や / どす (polite) | や / やで |
| **Negative** | 〜へん | 〜へん / 〜ん | 〜へん |
| **Tone** | Direct, loud | Soft, feminine | Moderate |
| **Polite** | おおきに | おおきに / ありがとうございます | おおきに |

## Tohoku Dialect (東北弁) - Northern

### Features
- **Vowel raising**: い→え, う→お (e.g., 寒い→寒え)
- **Voicing**: か→が, た→だ (e.g., ありがとう→ありがでぇ)
- **Negative**: 〜ね / 〜ねー (行かねー)
- **Copula**: だ→だ / だべ
- **Particles**: が→け, に→に/さ

### Famous Phrases
- **「おら、わがね」** (俺、分かんない) - "I don't know"
- **「けっぱれ！」** (頑張れ！) - "Do your best!"
- **「なんもねぇ」** (何もない) - "Nothing"

## Kyushu Dialects (九州弁)

### Hakata (Fukuoka)
| Standard | Hakata | Example |
|----------|--------|---------|
| **だ** | **や** / **じゃ** | 学生**じゃ** |
| **です** | **です** / **じゃす** | 学生**じゃす** |
| **ではない** | **じゃない** / **じゃろか** | 学生**じゃない** |
| **〜ない** | **〜ん** / **〜やん** | 行か**ん** / 行か**やん** |
| **〜ている** | **〜とる** / **〜ちょる** | 食べ**とる** |
| **どうして** | **なんでん** / **どうやって** | **なんでん**来た？ |
| **とても** | **ばり** / **ばりく** | **ばり**寒い |

### Kagoshima (Satsugu)
- **Very distinct** - Low mutual intelligibility
- **Copula**: じゃ / じゃろ
- **Negative**: 〜ん / 〜ねえ
- **Vocabulary**: ありがとう→**おおきに** / **さんす**

## Tokyo Dialect Features (Standard Base)

### Yamanote vs Shitamachi
| Feature | Yamanote (Standard) | Shitamachi (Traditional) |
|---------|---------------------|--------------------------|
| **Pitch** | Standard | Distinct patterns |
| **Vocabulary** | Standard | **あたし** (I-fem), **てやんでえ** (rude) |
| **Particles** | Standard | **さ** (emphasis), **ぜ/ぞ** (male) |

## Pitch Accent Differences

### Standard (Tokyo) vs Kansai
| Word | Tokyo | Kansai | Type |
|------|-------|--------|------|
| **橋** (bridge) | **LH** (hashi) | **HL** (hashi) | Atamadaka vs Heiban |
| **箸** (chopsticks) | **HL** (hashi) | **LH** (hashi) | Heiban vs Atamadaka |
| **雨** (rain) | **HL** (ame) | **LH** (ame) | Heiban vs Atamadaka |
| **今** (now) | **LH** (ima) | **HL** (ima) | Atamadaka vs Heiban |
| **日本** (Japan) | **LHH** (nihon) | **HLL** (nihon) | Nakadaka vs Atamadaka |

> **Kansai tends to have more Heiban (flat) patterns.**

## Ryukyuan Languages (琉球語) - Okinawa

**NOT dialects of Japanese** - Separate Japonic languages.

| Feature | Okinawan (Uchinaaguchi) |
|---------|-------------------------|
| **Hello** | **はいさい** (Haisai - male) / **haitai** (female) |
| **Thank you** | **にふぇーでーびる** (Nifee-deebiru) |
| **Goodbye** | **ぐぶりーさびら** (Guburii-sabira) |
| **Good morning** | **うくみそーち** (Ukumisoochi) |
| **Yes** | **うー** (Uu) |
| **No** | **あか** (Aka) |

> **Mutual intelligibility with Japanese: ~0%**. Separate language.

## Media Dialect Guide

### Anime/Drama Stereotypes
| Character Type | Dialect | Purpose |
|----------------|---------|---------|
| **Osaka comedian** | Kansai (Osaka) | Funny, direct, loud |
| **Kyoto geisha/maid** | Kyoto | Refined, soft, feminine |
| **Country bumpkin** | Tohoku/Northern | Naive, warm, vowel-raised |
| **Yakuza/Thug** | Tokyo (rough) / Kansai | Intimidating |
| **Old person** | Tohoku/Kyushu | Traditional, respectful |
| **Idol/Kawaii** | Tokyo (cute) | Youthful, high-pitched |

### Variety Shows
- **Kansai comedians** dominate (Downtown, Ninety-nine, etc.)
- **Standard Japanese** = Host/Announcer
- **Dialect humor** = Pun on mutual unintelligibility

## Practical Tips for Learners

### 1. Passive Recognition First
- Watch **Kansai comedians** (Downtown, Kamaitachi, etc.)
- Listen for **や, へん, あかん, おおきに**

### 2. Don't Produce Until Advanced
- Speaking dialect as non-native = **weird/offensive** unless fluent
- Exception: **Set phrases** (おおきに, あかん) in appropriate context

### 3. Pitch Accent Awareness
- Kansai words often **opposite pitch** from Tokyo
- Learn **word-by-word** with pitch

### 4. Regional Vocabulary
- **Food names** vary wildly (e.g., しゃぶしゃぶ vs 土鍋)
- **Transport**: 地下鉄 (Tokyo) vs メトロ/地下鉄 (Osaka) vs 市営地下鉄 (others)
