# Essential Particles - Deep Dive & Nuances

## は (wa) vs が (ga) - The Eternal Battle

### Core Distinction

| Aspect | **は (Topic)** | **が (Subject/Focus)** |
|--------|----------------|------------------------|
| **Function** | "As for X..." - sets topic | "It is X that..." - identifies subject |
| **Information** | Known/old info | New/important info |
| **Question** | Answer to "What about X?" | Answer to "Who/What did X?" |
| **Contrast** | Implicit contrast | Exhaustive listing |

### Classic Examples

**1. Question determines particle:**
> Q: **誰が**来ましたか？ → A: **田中さんが**来ました。 (Focus: WHO)
> Q: **田中さんは**どうですか？ → A: **田中さんは**元気です。 (Topic: Tanaka-san)

**2. Double-subject (Topic + Subject):**
> **私は** **日本語が** 分かります。
> Topic: 私 (As for me) | Subject: 日本語 (Japanese is understandable)

> **象は** **鼻が** 長い。
> Topic: 象 | Subject: 鼻 (nose)

**3. Contrastive は:**
> **魚は**食べますが、**肉は**食べません。
> Fish I eat, but meat I don't. (Contrast)

**4. Phenomenon sentences (が for natural phenomena):**
> **雨が**降っています。 (Rain falls - not "as for rain")
> **地震が**ありました。 (Earthquake occurred)

**5. Stative predicates (adjectives, potential, desire) → が:**
> **猫が**好きです。 (Cats are likeable)
> **日本語が**できます。 (Japanese is doable)
> **水が**飲みたいです。 (Water is want-to-drink)

### Decision Tree
```
Is it the answer to a WH-question (who/what/which)?
  YES → が
  NO → Continue

Is it a stative predicate (like, can, want, understand)?
  YES → が
  NO → Continue

Is it contrastive ("X but not Y")?
  YES → は
  NO → Continue

Is it the main topic of conversation (known info)?
  YES → は
  NO → が (new information focus)
```

## に (ni) vs で (de) - Location Showdown

### Core Rule
| Particle | Function | Verbs |
|----------|----------|-------|
| **に** | **Existence location** / **Destination** / **Time point** | ある, いる, 住む, 勤める, 行く, 来る, 帰る, 着く |
| **で** | **Action location** / **Means** / **Cause** | Action verbs: 食べる, 勉強する, 働く, 遊ぶ, 作る |

### Existence vs Action
> **図書館に**本があります。 (Books **exist at** library - ある)
> **図書館で**勉強します。 (Study **at** library - action)

> **東京に**住んでいます。 (Live **in** Tokyo - 住む = existence)
> **東京で**働いています。 (Work **in** Tokyo - action)

### Motion Verbs: に vs へ vs で
| Particle | Nuance | Example |
|----------|--------|---------|
| **に** | Destination (arrival focus) | **東京に**着いた。 (Arrived **in** Tokyo) |
| **へ** | Direction (journey focus) | **東京へ**行く。 (Go **toward** Tokyo) |
| **で** | Means/Route (transport) | **電車で**東京へ行く。 (Go to Tokyo **by train**) |

### Time: に vs No Particle
| Use **に** | No Particle (Relative Time) |
|------------|----------------------------|
| Specific clock time: **三時に** | Today: **今日** (not 今日**に**) |
| Specific day: **月曜日に** | Tomorrow: **明日** |
| Specific date: **十月一日に** | Yesterday: **昨日** |
| Frequency: **週に**二回 | Every day: **毎日** |
| | Next week: **来週** |
| | This year: **今年** |

## を (o) - Beyond Direct Object

### 1. Direct Object (Transitive Verbs)
> **本を**読みます。 (Read **a book**)

### 2. Traversal (Motion "Through/Along")
> **公園を**走ります。 (Run **through** the park)
> **橋を**渡ります。 (Cross **the bridge**)
> **階段を**上ります。 (Go up **the stairs**)

### 3. Departure Point (Leave From)
> **家を**出ます。 (Leave **home**)
> **電車を**降ります。 (Get off **the train**)
> **会社を**辞めます。 (Quit **the company**)

### 4. Duration (Time Spent)
> **二時間を**勉強しました。 (Studied **for two hours**)
> **一生を**日本で過ごした。 (Spent **a lifetime** in Japan)

### 5. Causative Object
> **弟を**勉強させます。 (Make **brother** study)
> **子供を**寝かせます。 (Put **child** to sleep)

### を vs が with Potential
| Form | Particle | Example |
|------|----------|---------|
| **Dictionary potential** (神丹) | **が** | 日本語**が**話せます。 |
| **Short potential** (ら抜き) | **が** | 日本語**が**話せれます。 |
| **できる (suru potential)** | **が** | 日本語**が**できます。 |
| **Transitive + potential** | **を/が** both OK | 本**を/が**読めます。 |

> **Modern tendency**: を with potential is increasing, but が is standard.

## と (to) vs や (ya) vs とか (toka)

| Particle | Exhaustive? | Nuance | Example |
|----------|-------------|--------|---------|
| **と** | **YES** | Complete list | りんご**と**みかん (apples AND oranges - only these) |
| **や** | NO | Non-exhaustive, "etc. implied" | りんご**や**みかん (apples, oranges, **and such**) |
| **とか** | NO | Casual, examples | りんご**とか**みかん**とか** (apples, oranges, stuff like that) |

### と for Quotation
> **「行きます」と**言いました。 (Said "**I'll go**.")
> **「美味しい」と**思います。 (Think "**it's delicious**.")

### と for Natural Consequence (Conditional)
> **春と**桜が咲く。 (When spring comes, cherry blossoms bloom - **always**)
> **ボタンを押すと**電気がつく。 (Press button → light turns on)

### と for "With" (Accompaniment)
> **友達と**映画を見ました。 (Watched movie **with** friend)
> **父と**話しました。 (Spoke **with** father)

> **Note**: "With" for instruments → で (ペン**で**書く)

## の (no) - The Swiss Army Knife

### 1. Possession
> **私の**本 (My book)
> **田中さんの**車 (Tanaka-san's car)

### 2. Attribution (Noun modifies Noun)
> **日本の**車 (Japanese car / Car **of** Japan)
> **大学の**先生 (University professor)
> **木の**箱 (Wooden box / Box **of** wood)

### 3. Apposition (A = B)
> **東京の**都市 (The city **of** Tokyo = Tokyo city)
> **友達の**田中さん (Friend **Tanaka-san**)
> **学生の**私 (Me, **who is a student**)

### 4. Nominalization (Verb/Adj → Noun)
> **食べるの**が好きです。 (Like **eating**)
> **赤いの**をください。 (Give me **the red one**)
> **行けないの**は残念だ。 (**Not being able to go** is regrettable)

### 5. Subject in Relative Clause (の = が)
> **私が買った**本 (The book **I** bought)
> **猫が好きな**人 (Person **who likes cats**)

### 6. Explanatory の (んです / のだ)
> **忙しいんです。** (It's **that I'm busy** / The reason is I'm busy.)
> **雨なんですよ。** (It's raining, you see.)

### 7. Question Softener
> **何の**本ですか？ (What **kind of** book?)
> **どの**くらい**の**大きさ？ (About **what** size?)

## も (mo) - "Also" Replaces Particles

### Replaces: は, が, を
| Original | With も | Meaning |
|----------|---------|---------|
| 私は行く | **私も**行く | **I also** go |
| 猫が好き | 猫**も**好き | Like **cats too** |
| リンゴを食べた | リンゴ**も**食べた | Ate **apples too** |

### With Question Words = "Any/Every/No"
| Combo | Meaning | Example |
|-------|---------|---------|
| **誰も** | Everyone / No one (w/ neg) | **誰も**来なかった (Nobody came) |
| **何でも** | Anything / Everything | **何でも**食べます (Eat anything) |
| **どこも** | Everywhere / Nowhere (w/ neg) | **どこも**行かない (Go nowhere) |
| **いつも** | Always | **いつも**ここにいる |
| **いつでも** | Anytime | **いつでも**来ていい |
| **だれでも** | Anyone | **だれでも**できます |

### With Counters = "Even"
> **一分も**待ちません。 (Won't wait **even a minute**.)
> **一円も**ありません。 (Don't have **even one yen**.)

## から (kara) vs ために (tame ni) vs ので (node) - Reason/Cause

| Particle | Register | Structure | Nuance |
|----------|----------|-----------|--------|
| **から** | Casual/Neutral | [Sentence] + から | Subjective reason, "because" |
| **ので** | Polite | [Sentence] + ので | Objective reason, "since/as" |
| **ために** | Formal | [Noun/Verb-stem] + ために | Purpose / For the sake of |

### Examples
> **雨だから**行きません。 (Casual: Because it's raining)
> **雨なので**行きません。 (Polite: Since it's raining)
> **健康のために**運動します。 (For health's sake)
> **試験に合格するために**勉強します。 (In order to pass exam)

### だから / ですから (Sentence-start "Therefore")
> **雨です。だから**行きません。
> **雨です。ですから**行きません。

## まで (made) vs までに (made ni) - Time Limits

| Particle | Meaning | Example |
|----------|---------|---------|
| **まで** | **Until** (continuous) | **五時まで**働きます。 (Work **until** 5:00) |
| **までに** | **By** (deadline) | **五時までに**終わらせます。 (Finish **by** 5:00) |

### Spatial
> **駅まで**歩きます。 (Walk **to** the station - endpoint)
> **ここまで**来てください。 (Come **up to** here)

### Degree (Even)
> **子供まで**知っている。 (Even children know.)

## しか (shika) vs だけ (dake) vs ばかり (bakari) - "Only"

| Particle | Polarity | Nuance | Example |
|----------|----------|--------|---------|
| **しか** | **Negative only** | "Nothing but", limitation | お金**しか**ない (Have **only** money) |
| **だけ** | Positive/Negative | "Just/Only", neutral | これ**だけ**ください (Just this please) |
| **ばかり** | Positive | "Nothing but", "just did", emphasis | 甘いもの**ばかり**食べる (Eat nothing but sweets) |

### ばかり Special Uses
1. **Only/Excessive**: 毎日**ばかり**働いている (Work all day every day)
2. **Just finished**: 食べた**ばかり** (Just finished eating)
3. **About to**: 今**ばかり**行くところだ (Just about to go)

## より (yori) vs のほうが (no hou ga) - Comparison

### Structure: A より B のほうが [Adj]
> **夏より**冬のほうが**好きです。** (Like winter more than summer.)

### Shortened: A より B が [Adj] (B is subject)
> **夏より**冬**が**好きです。

### "More than expected": 思ったより / 予想より
> **思ったより**早い。 (Earlier than I thought.)

### "Less than": ほど...ない
> **彼ほど**背が高くない。 (Not as tall as him.)

---

## ほど (hodo) - Degree/Extent

### 1. "To the extent that..."
> **死ぬほど**痛い。 (Hurts **enough to die** / **so much that** I could die)
> **泣くほど**笑った。 (Laughed **so hard I cried**)

### 2. Comparison "As...as"
> **この本は**あの本**ほど**面白くない。 (This book isn't as interesting as that one.)

### 3. "About/Approximately" (with numbers)
> **十分ほど**待ちました。 (Waited **about 10 minutes**)

---

## ぐらい / くらい (gurai/kurai) - Approximation

| Use | Example |
|-----|---------|
| **Quantity** | **三十分ぐらい** (About 30 min) |
| **Degree** | **死ぬくらい**痛い (Hurts like dying) |
| **Minimum** | **これくらい**あればいい (This much is enough) |

> **ぐらい** = slightly more formal | **くらい** = more casual

---

## さえ (sae) vs すら (sura) - "Even" (Emphasis)

| Particle | Register | Example |
|----------|----------|---------|
| **さえ** | Standard | 子供**さえ**できる (Even a child can do it) |
| **すら** | Literary/Formal | 専門家**すら**知らない (Even experts don't know) |

### さえ + ば = "If only..."
> **お金さえあれば**買える。 (If only I had money, I could buy it.)

---

## こそ (koso) - "Precisely/For Sure" (Emphasis on Preceding)

| Use | Example |
|-----|---------|
| **Emphasis** | あなた**こそ**行くべきだ。 (**You** are the one who should go.) |
| **Reciprocity** | こちら**こそ**よろしく。 (**I** should be the one saying that.) |
| **Contrast** | 今**こそ**チャンスだ。 (**Now** is precisely the chance.) |

## Particle Combinations (Compound Particles)

| Combo | Components | Meaning | Example |
|-------|------------|---------|---------|
| **では** | で + は | In/at (topic/contrast) | **東京では**寒い |
| **へは** | へ + は | To (topic) | **学校へは**行かない |
| **には** | に + は | At/to (topic) | **ここには**ない |
| **では** | で + は | By means (topic) | **バスでは**行けない |
| **とは** | と + は | With/and (topic) | **彼とは**会った |
| **からは** | から + は | From (topic) | **ここからは**見えない |
| **までは** | まで + は | Until (topic) | **ここまでは**大丈夫 |
| **とも** | と + も | With (also) | **友達とも**行った |
| **にも** | に + も | At/to (also) | **ここにも**ある |
| **でも** | で + も | At/by (also) | **ここでも**売ってる |
| **からも** | から + も | From (also) | **東京からも**来た |
| **までに** | まで + に | By (deadline) | **五時までに** |

## Practice: Choose the Particle

1. 私は学生___です。 → は (topic)
2. 誰___来ましたか。 → が (focus)
3. リンゴ___食べます。 → を (object)
4. 図書館___勉強します。 → で (action location)
5. 東京___行きます。 → に/へ (destination)
6. 友達___行きます。 → と (with)
7. 私___本 → の (possession)
8. 私も行きます。 → も (replaces は)
9. 九時___始まります。 → から (time start)
10. 五時___働きます。 → まで (time end)
11. 魚___好きですが、肉___嫌いです。 → は、は (contrast)
12. 猫___好きです。 → が (stative)
13. お金___ありません。 → が/は (existence/contrast)
14. ペン___書きます。 → で (instrument)
15. これ___ください。 → を (object)
