# Basic Conjunctions & Connectors (接続詞 - せつぞくし)

## Overview
Conjunctions connect sentences, clauses, or phrases. Japanese conjunctions often appear at **sentence start** (unlike English where they're between clauses).

---

## Coordinate Conjunctions (並列・順接)

### Addition / Sequence

| Conjunction | Reading | Register | Function | Example |
|-------------|---------|----------|----------|---------|
| **そして** | そして | Neutral | And then, and | 起きて、顔を洗った。**そして**朝ごはんを食べた。 |
| **それから** | それから | Neutral | And then (time sequence) | 宿題をした。**それから**寝た。 |
| **それに** | それに | Neutral | Besides, moreover | 安い。**それに**美味しい。 |
| **さらに** | さらに | Formal | Furthermore, additionally | 速い。**さらに**安い。 |
| **しかも** | しかも | Formal | Moreover, on top of that | 嘘をついた。**しかも**隠した。 |
| **また** | また | Neutral | Also, again | **また**会いましょう。 |

### Contrast (逆接)

| Conjunction | Reading | Register | Function | Example |
|-------------|---------|----------|----------|---------|
| **しかし** | しかし | Formal | But, however | 行きたい。**しかし**お金がない。 |
| **でも** | でも | Casual | But | 行きたい。**でも**お金がない。 |
| **けれども / けれど** | けれども/けれど | Semi-formal | But, although | 高い**けれど**買う。 |
| **が** | が | Formal | But (mid-sentence) | 高い**が**買う。 |
| **にもかかわらず** | にもかかわらず | Formal | Despite | 雨**にもかかわらず**行った。 |
| **のに** | のに | Neutral | Despite (emotion) | 高い**のに**買った。 |

## Subordinate Conjunctions (従属接続)

### Cause / Reason (理由)

| Conjunction | Structure | Register | Example |
|-------------|-----------|----------|---------|
| **から** | [Sentence] + から | Casual/Neutral | 雨**だから**行かない。 |
| **ので** | [Sentence] + ので | Polite | 雨**なので**行きません。 |
| **ために** | [Noun/Verb-stem] + ために | Formal | 健康**のために**運動する。 |
| **せいで** | [Noun/Verb] + せいで | Negative cause | 彼の**せいで**遅れた。 (His fault) |
| **おかげで** | [Noun/Verb] + おかげで | Positive cause | 彼の**おかげで**助かった。 (Thanks to him) |

### Purpose (目的)

| Conjunction | Structure | Example |
|-------------|-----------|---------|
| **ために** | [Verb-stem] + ために | 合格する**ために**勉強する。 |
| **ように** | [Verb-dict/neg] + ように | 忘れない**ように**メモする。 |
| **ために** | [Noun] + のために | 平和**のために**働く。 |

### Condition (条件)

| Conjunction | Structure | Nuance | Example |
|-------------|-----------|--------|---------|
| **と** | [Verb-plain] + と | Natural law, always | ボタンを押す**と**光る。 |
| **ば** | [Verb-kateikei] + ば | General conditional | 時間があれば**行く**。 |
| **たら** | [Verb-ta] + ら | Completed action, specific | 雨が降ったら**やめる**。 |
| **なら** | [Noun/な-adj] + なら / [Verb] + なら | Topic-conditional | 学生**なら**安い。 / 行く**なら**連絡して。 |
| **もし** | もし + [Conditional] | "If by chance" | **もし**雨なら行かない。 |

### Time (時間)

| Conjunction | Structure | Example |
|-------------|-----------|---------|
| **とき / 時** | [Verb-plain] + とき | 来る**とき**連絡して。 |
| **前** | [Verb-dict] + 前に | 食べる**前に**手を洗う。 |
| **後** | [Verb-ta] + 後で | 食べた**後で**散歩する。 |
| **以来** | [Verb-ta] + 以来 | 会って**以来**連絡ない。 |
| **まで** | [Verb-dict] + まで | 戻る**まで**待つ。 |
| **あいだ** | [Verb-dict/ta] + あいだ | 寝て**いるあいだ**に雨が降った。 |

### Concession (譲歩)

| Conjunction | Structure | Example |
|-------------|-----------|---------|
| **のに** | [Sentence] + のに | 高い**のに**買った。 |
| **ても / でも** | [Verb-te] + も / [Adj-ku] + ても | 雨**でも**行く。 / 高く**ても**買う。 |
| **けれど** | [Sentence] + けれど | 高い**けれど**買う。 |
| **が** | [Sentence] + が | 高い**が**買う。 |

## Sentence-Level Connectors (Discourse Markers)

### Topic Shift / Introduction

| Marker | Function | Example |
|--------|----------|---------|
| **さて** | "Well then," "Now" | **さて**、始めましょう。 |
| **ところで** | "By the way" | **ところで**、聞いた？ |
| **そういえば** | "Come to think of it" | **そういえば**、約束してた。 |
| **ちなみに** | "Incidentally" | **ちなみに**、私は学生です。 |

### Conclusion / Summary

| Marker | Function | Example |
|--------|----------|---------|
| **つまり** | "In short," "That is to say" | **つまり**、行けないということだ。 |
| **要するに** | "In a word," "Basically" | **要するに**、ダメだ。 |
| **結論から言うと** | "To conclude" | **結論から言うと**、合格だ。 |
| **結局** | "After all," "In the end" | **結局**雨で中止になった。 |

### Emphasis / Clarification

| Marker | Function | Example |
|--------|----------|---------|
| **実は** | "Actually," "To tell the truth" | **実は**知らなかった。 |
| **確かに** | "Certainly," "Indeed" | **確かに**そう見える。 |
| **もちろん** | "Of course" | **もちろん**行きます。 |
| **絶対に** | "Absolutely" | **絶対に**負けない。 |

### Example / Listing

| Marker | Function | Example |
|--------|----------|---------|
| **例えば** | "For example" | **例えば**、東京や大阪。 |
| **とか / やら** | "Things like" | りんご**とか**みかん**やら**。 |
| **など** | "Etc." | 果物**など**。 |

## Conjunctive Particles (接続助詞) - Clause-Internal

These attach to **verb/adjective stems** to connect clauses WITHIN a sentence.

### て-form (Most Versatile)
| Use | Structure | Example |
|-----|-----------|---------|
| **Sequence** | [て-form] + [Verb] | 起き**て**、食べ**て**、行った。 |
| **Reason** | [て-form] + [Result] | 雨で濡れ**て**、風邪をひいた。 |
| **Means** | [て-form] + [Verb] | 走**って**逃げた。 |
| **State** | [て-form] + いる | 本を読**んでいる**。 |
| **Request** | [て-form] + ください | 待って**ください**。 |

### たり〜たり (Representative Actions)
> **本を読んだり、音楽を聴いたりした。** (Did things like reading books, listening to music.)

### ながら (Simultaneous Actions - Same Subject)
> **音楽を聴きながら勉強する。** (Study while listening to music.)

### つつ (Simultaneous - Formal/Written)
> **歩きつつ考える。** (Think while walking.)

### ばかり (Repetitive/Excessive)
> **文句を言ばかりいる。** (Just keeps complaining.)

## Compound Conjunctions (Multi-word)

| Expression | Components | Meaning |
|------------|------------|---------|
| **その上** | それ + の + 上 | Moreover, on top of that |
| **それどころか** | それ + どころ + ではない | Far from it, let alone |
| **それだけでなく** | それ + だけ + で + ない | Not only that |
| **それどころか** | それ + どころ + か | On the contrary |
| **その結果** | その + 結果 | As a result |
| **そのため** | その + ため | For that reason |
| **その上で** | それ + の + 上 + で | After that, on that basis |
| **その一方で** | それ + の + 一方 + で | On the other hand |

## Practice: Choose the Conjunction

1. 雨が降った。___、試合は中止になった。 → **そのため** / **なので** / **だから**
2. 高い。___、買う。 → **でも** / **けれど** / **が** / **のに**
3. 朝、起きる。___、顔を洗う。 → **そして** / **それから** / **て-form**
4. 学生___、安い。 → **なら** / **だと** / **は**
5. 勉強した___、試験に受かった。 → **から** / **ので** / **ため** / **おかげで**
6. 雨___、行く。 → **でも** / **ても** / **のに** / **が**
7. ここ___、静かだ。 → **は** / **では** / **なら**
8. 早く来い。___、間に合わない。 → **じゃないと** / **と** / **ば**

## Advanced: Logical Connectors in Writing (論理接続)

| Function | Formal Written | Example |
|----------|----------------|---------|
| **Definition** | 〜とは〜ことである / 〜とは〜を指す | **AIとは**、人工知能を指す。 |
| **Classification** | 〜には〜と〜がある / 〜は〜に分類される | **動詞には**、自動詞と他動詞がある。 |
| **Exemplification** | 例えば〜 / 〜の一例として | **例えば**、猫や犬は哺乳類だ。 |
| **Comparison** | 〜と同様に / 〜に対して / 〜と比較して | **従来の方法と比較して**、速い。 |
| **Contrast** | 一方 / 逆に / 対照的に | **一方**、リスクもある。 |
| **Cause-Effect** | 〜に起因する / 〜を契機として / 〜を受けて | **需要増を受けて**、生産を拡大。 |
| **Supplement** | 加えて / さらに / その上 | **加えて**、コストも下がる。 |
| **Concession** | 〜ながら / 〜つつある / 〜かといって | **困難ながら**、挑戦する。 |
| **Conclusion** | 以上のことから / 結論として / 要するに | **以上のことから**、提案する。 |

*Conjunctions are the skeleton of discourse. Start with て-form, から/ので, でも/が, そして/それから. Master these 80% use cases first.*
