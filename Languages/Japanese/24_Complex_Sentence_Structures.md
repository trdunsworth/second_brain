# Complex Sentence Structures

## Overview
Japanese complex sentences are built by **embedding clauses** before nouns (relative clauses) or connecting them with **conjunctions/particles**. The verb **always comes at the end** of the matrix clause.

---

## 1. Relative Clauses (連体修飾節) - The Foundation

### Structure: [Clause] + Noun
**No relative pronoun (who/which/that) needed!** The clause directly modifies the noun.

| English | Japanese | Analysis |
|---------|----------|----------|
| The book **that I read** | **私が読んだ**本 | Clause: 私が読んだ → Modifies: 本 |
| The person **who called** | **電話をかけた**人 | Clause: 電話をかけた → Modifies: 人 |
| The place **where I live** | **私が住んでいる**ところ | Clause: 私が住んでいる → Modifies: ところ |
| The time **when we met** | **会った**時 | Clause: 会った → Modifies: 時 |

### Subject in Relative Clause: が vs の
| Pattern | Example | Nuance |
|---------|---------|--------|
| **が** | **猫が**好きな人 | Standard for stative predicates (好き, 嫌い, 分かる, できる) |
| **の** | **私が**買った本 / **私の**買った本 | Standard for action verbs; の more natural in modern Japanese |

### Stacking Relative Clauses
> **私が昨日図書館で借りた** **赤い** **面白い** **本**
> [Clause] [Adj] [Adj] Noun
> Order: More permanent/defining closer to noun.

## 2. Quoted Speech (引用 - いんよう)

### Direct Quote (直接話法)
**Structure**: 「Quote」 + と + Verb of Speaking/Thinking
| Verb | Example |
|------|---------|
| 言う (iu) | **「行きます」と**言った。 |
| 思う (omou) | **「美味しい」と**思う。 |
| 聞く (kiku) | **「誰ですか」と**聞いた。 |
| 答える (kotaeru) | **「はい」と**答えた。 |
| 叫ぶ (sakebu) | **「助けて」と**叫んだ。 |

### Indirect Quote (間接話法)
**Structure**: [Clause] + と + Verb (or と思う/と考える)
- **彼は来る**と**言った。** (He said he would come.)
- **雨が降る**と**思う。** (I think it will rain.)
- **田中さんが社長だ**と**聞いた。** (Heard that Tanaka is president.)

> **Tense**: In indirect quotes, **tense doesn't backshift** like English!
> - "He said he **would** come" → 彼は来る**と**言った (not 来た**と**言った)

### Self-Talk / Internal Monologue
- **「よし、やるぞ」と**心に決めた。** (Decided in heart: "OK, I'll do it.")
- **「大丈夫だ」と**自分に言い聞かせた。** (Told self: "It's OK.")

## 3. Conditional Embedding

### Conditional as Noun Modifier
| Structure | Example |
|-----------|---------|
| **[Conditional] + とき/場合/なら** | **雨が降ったら**中止だ。 |
| **[ば/たら/なら] + ために/ように** | **失敗しないよう**に注意する。 |

### Conditional Chains
- **もし雨なら、かつ風が強ければ、中止だ。** (If rain AND strong wind → cancel)
- **行けば会えるし、会えば話せる。** (If go → meet; if meet → can talk.)

---

## 4. Causal/Reason Embedding

### ので / から as Clause Connectors
| Structure | Example |
|-----------|---------|
| **[Reason] ので [Result]** | **雨なので**行きません。 |
| **[Reason] から [Result]** | **雨だから**行かない。 |
| **Noun + のために** | **健康のために**運動する。 |

### Reason as Noun Phrase
- **遅れた理由は、バスが来なかった**からだ。 (Reason = clause)
- **彼が怒ったわけは、嘘をつかれた**からだ。

---

## 5. Purpose Embedding

### ために / ように + Verb
| Pattern | Subject | Example |
|---------|---------|---------|
| **Verb Dict + ために** | Same | **合格するために**勉強する。 |
| **Verb Dict/Neg + ように** | Same | **忘れないように**メモする。 |
| **Noun + のために** | — | **家族のために**働く。 |

### Purpose Clause as Modifier
- **合格するための**勉強 (Study **for passing**)
- **忘れないための**メモ (Memo **to not forget**)

---

## 6. Concessive Embedding (Contrast)

### のに / ても / けれど / が
| Structure | Example |
|-----------|---------|
| **[Concession] のに [Main]** | **高いのに**買った。 |
| **[て-form] も [Main]** | **高くても**買う。 |
| **[Clause] けれど [Main]** | **高いけれど**買う。 |
| **[Clause] が [Main]** | **高いが**買う。 |

### Concessive as Noun Modifier
- **高いのに買った**本 (The book I bought **despite being expensive**)

---

## 7. Temporal Embedding

### とき / 前 / 後 / 以来 / まで / あいだ
| Structure | Example |
|-----------|---------|
| **Verb Plain + とき** | **来るとき**連絡して。 |
| **Verb Dict + 前に** | **食べる前に**手を洗う。 |
| **Verb Ta-form + 後で** | **食べた後で**散歩する。 |
| **Verb Ta-form + 以来** | **会って以来**連絡ない。 |
| **Verb Dict + まで** | **戻るまで**待つ。 |
| **Verb ている + あいだ** | **寝ているあいだに**雨が降った。 |

### Temporal Clause as Modifier
- **来るときの**連絡 (Contact **when coming**)
- **食べた後の**散歩 (Walk **after eating**)

---

## 8. Comparative Embedding

### より / ほうが / ほど
| Structure | Example |
|-----------|---------|
| **A より B のほうが [Adj]** | **夏より冬のほうが**好き。 |
| **A ほど [Adj] ない** | **彼ほど**背が高くない。 |
| **〜ば〜ほど** | **早ければ早いほど**いい。 |

---

## 9. Complex Predicate Chains (Verb + Verb)

### V1 (Stem) + V2 (Aspectual)
| Pattern | Meaning | Example |
|---------|---------|---------|
| **〜始める** | Start | **雨が降り始めた** |
| **〜終わる** | Finish | **読み終わった** |
| **〜続ける** | Continue | **歩き続ける** |
| **〜やめる** | Stop | **タバコをやめた** |
| **〜すぎる** | Too much | **食べすぎた** |
| **〜やすい/にくい** | Easy/hard | **読みやすい/読みにくい** |
| **〜がたい** | Hard (formal) | **信じがたい** |

### V1 (て-form) + V2 (Auxiliary)
| Pattern | Meaning | Example |
|---------|---------|---------|
| **〜てみる** | Try | **食べてみる** |
| **〜てしまう** | Complete/Regret | **食べてしまった** |
| **〜ておく** | Prepare | **予約しておく** |
| **〜てある** | Result state | **予約してある** |
| **〜ていく** | Go doing | **歩いていく** |
| **〜てくる** | Come doing | **分かってきた** |
| **〜てあげる/くれる/もらう** | Give/Receive action | **教えてあげた** |

## 10. Nominalized Clauses as Arguments

### Subject Position
- **彼が来ないことは**分かっている。 (That he won't come is known.)
- **何が起きたのか**分からない。 (Don't know what happened.)

### Object Position
- **彼が来ることを**知っている。 (Know that he will come.)
- **どこへ行くか**教えて。 (Tell me where you're going.)

### Topic Position
- **彼が来るのは**明日だ。 (As for him coming, it's tomorrow.)

### Complement of Copula
- **私の夢は**医者**になること**だ。 (My dream is to become a doctor.)
- **問題は**お金が足りない**こと**だ。 (Problem is not enough money.)

---

## 11. Sentence-Final Predicate Complexes

### Modality Stacking
| Stack | Example | Meaning |
|-------|---------|---------|
| **Verb + たい + ようだ** | 行きたいようだ。 | Seems like wants to go. |
| **Verb + べき + だ** | 行くべきだ。 | Should go. |
| **Verb + こと + になっている** | 行くことになっている。 | It's decided/scheduled to go. |
| **Verb + ば + いい** | 行けばいい。 | Just go / All you have to do is go. |
| **Verb + だけ + だ** | 待つだけだ。 | Just have to wait. |

### Evidentiality Stacking
- **雨が降る**らしい**そうだ**。 (Heard it seems it will rain.)
- **彼は来る**ようだ**ね**。 (Seems he'll come, right?)

---

## 12. Ellipsis & Zero Pronouns (Null Arguments)

### Subject/Object Dropping
| Full | Elliptical | Context |
|------|------------|---------|
| **私が**本を**読みます**。 | 本を**読みます**。 | "I" clear from context |
| 田中さん**が**来ました。 | 来ました。 | Topic clear |
| **それを**ください。 | ください。 | Object clear |

### Verb Phrase Ellipsis
- A: **誰が行く？** B: **私が**。 (Not *私が行く*)
- A: **食べた？** B: **食べた**。 / **うん**。 (Not *食べました*)

## 13. Complex Sentence Templates (Memorize These)

### Template 1: Reason + Result
> **[Reason] ので / から、[Result]。**
> **雨が強いので、試合は中止になった。**

### Template 2: Condition + Consequence
> **もし [Condition] なら / たら / ば、[Consequence]。**
> **もし時間があれば、手伝います。**

### Template 3: Purpose + Action
> **[Purpose] ために / ように、[Action]。**
> **合格するために、毎日勉強する。**

### Template 4: Concession + Main
> **[Concession] のに / ても / が、[Main]。**
> **疲れているのに、働き続けた。**

### Template 5: Temporal Sequence
> **[Event 1] て / た後で / 前に、[Event 2]。**
> **宿題をして、寝た。** / **宿題をした後で、寝た。**

### Template 6: Quoted Speech/Thought
> **[Clause] と、[Verb: 言う/思う/聞く]。**
> **彼は来ないと言った。** / **雨だと思う。**

### Template 7: Nominalized Clause as Subject/Object
> **[Clause] こと/の が/は/を [Predicate]。**
> **彼が来ることが分かった。**

### Template 8: Comparative
> **A より B のほうが [Adj]。**
> **これよりあれのほうがいい。**

### Template 9: Change of State
> **[Verb Stem] ようになる / ことにする。**
> **日本語が話せるようになった。** / **毎日走ることにした。**

### Template 10: Relative Clause + Predicate
> **[Relative Clause] Noun は/が [Predicate]。**
> **私が買った本は面白い。**

## Practice: Build Complex Sentences

**Elements**: 田中さん, 来る, 雨, 降る, 中止, なる, 思う, 言う, 知る

1. "Tanaka said he'll come." → **田中さんが来ると言った。**
2. "I think it'll rain." → **雨が降ると思う。**
3. "If it rains, the game will be cancelled." → **雨が降ったら、試合が中止になる。**
4. "I know that Tanaka is coming." → **田中さんが来ることを知っている。**
5. "Because it rained, the game was cancelled." → **雨が降ったので、試合が中止になった。**
6. "The game that was cancelled was tomorrow's." → **中止になった試合は明日のだ。**
7. "Tanaka said the game was cancelled." → **田中さんが試合が中止になったと言った。**
8. "I think the game will be cancelled if it rains." → **雨が降れば試合が中止になると思う。**

---

*Complex sentences = simple clauses + embedding particles. The verb is always the anchor. Master the 10 templates above and you can express virtually any logical relationship.*
