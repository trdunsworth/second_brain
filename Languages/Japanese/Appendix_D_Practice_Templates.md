# Practice Templates (練習テンプレート) - Output Drills

## Philosophy: Structured Output
Output practice **consolidates** input. Templates provide **scaffolding** for production. Rotate skills: **Writing → Speaking → Shadowing → Translation**.

---

## 1. Writing Templates (ライティング)

### A. Daily Journal (日記) - 5 min/day
```
日付: ____年__月__日 (__曜日) 天気: ___ 気温: ___°C

1. 今日したこと (3-5文):
- 朝、_______________。
- 昼、_______________。
- 夜、_______________。

2. 感想・気づき (2-3文):
- _______________。
- _______________。

3. 明日の予定・目標 (1-2文):
- _______________。

新しい言葉: _______________ (例文: _______________)
```

### B. Structured Essay (小論文) - 30 min/week
**Template**: PREP法 (Point, Reason, Example, Point)

```
テーマ: _______________

P (結論): _______________と考える。

R (理由): なぜなら、_______________からだ。

E (具体例): 例えば、_______________。また、_______________。

P (再結論): 以上のことから、_______________と結論づけられる。
```

**Alternative**: SDS法 (Summary, Details, Summary)
```
概要: _______________について論じる。

詳細:
1. _______________
2. _______________
3. _______________

結論: したがって、_______________。
```

## 2. Speaking Templates (スピーキング)

### A. Self-Talk Narration (独り言) - 5 min/day
**Narrate your actions in real-time**
```
「今、_______________している。」
「次は、_______________しよう。」
「あ、_______________忘れた。」
「うーん、_______________かな。」
「よし、_______________終わった。」
```

### B. Shadowing Script (シャドーイング) - 10 min/day
**Source**: Native audio (podcast, news, drama) - 30-60 sec segments

**Procedure**:
1. Listen once (no text)
2. Listen + read transcript
3. **Shadow**: Speak **simultaneously** with audio (0.5 sec lag)
4. **Repeat** 3-5x until fluent
5. **Record** yourself → compare

**Shadowing Log**:
```
Date: ________
Source: _______________ (Episode/Time: ____)
Segment: _______________
Attempt 1: □  Attempt 2: □  Attempt 3: □  Attempt 4: □  Attempt 5: □
Issues: _______________ (pitch, speed, linking, vowels)
Next: _______________
```

### C. Role-Play Scenarios (ロールプレイ) - 15 min/week
**Solo**: Play both roles | **Partner**: Alternate roles

#### Scenario 1: Restaurant (飲食店)
```
Client: 「すみません、メニューをください。」
Server: 「はい、こちらです。お飲み物は？_______________」
Client: 「_______________をお願いします。」
Server: 「かしこまりました。お料理はお決まりですか？_______________」
Client: 「_______________にします。」
Server: 「少々お待ちください。_______________」
```

#### Scenario 2: Asking Directions (道案内)
```
You: 「すみません、_______________へ行きたいんですが、わかりますか？」
Local: 「ああ、_______________ですね。ここから_______________。」
You: 「徒歩でどのくらい？_______________」
Local: 「_______________分くらいですよ。_______________」
You: 「ありがとうございます。_______________」
```

#### Scenario 3: Business Meeting (会議)
```
Chair: 「では、_______________について議論を始めます。」
You: 「_______________という点で、_______________と考えます。」
Other: 「確かに_______________ですが、_______________という懸念も。」
You: 「それは_______________。では、_______________という案はどうでしょう。」
Chair: 「では、_______________で合意とし、次回までに_______________を進めましょう。」
```

### D. 1-Minute Speech (1分スピーチ) - Daily/Weekly
**Structure**: Hook → Point → Evidence → Conclusion

```
テーマ: _______________

Hook (10秒): 「_______________」という事実をご存知ですか？ / 最近、_______________というニュースが話題です。

Point (10秒): 私は、_______________と考えます。

Evidence (30秒): 理由は_______________です。実際、_______________というデータもあります。また、_______________という例もあります。

Conclusion (10秒): 以上のことから、_______________。皆さんも_______________してみてはいかがでしょうか。
```

### E. Picture Description (写真描写) - 5 min/day
**Source**: Random image (Unsplash, Pinterest, Instagram)

```
1. 全体: この写真には、_______________が写っています。
2. 詳細: 前景に_______________、背景に_______________があります。
3. 動作: _______________している人がいます。_______________しています。
4. 雰囲気: _______________な雰囲気です。_______________と感じます。
5. 推測: おそらく_______________だと思います。なぜなら_______________からです。
```

## 5. Listening Comprehension (リスニング)

### A. Dictation (ディクテーション) - 10 min
**Source**: Native audio (30-60 sec), **no transcript** first

```
Source: _______________ (Time: ___)
Segment: _______________

Attempt 1 (Listen only): _______________
Attempt 2 (Pause/Replay): _______________
Attempt 3 (Check transcript): _______________

Errors: _______________ (vocab, grammar, sound linking, pitch)
New Words: _______________
```

### B. Shadowing + Dictation Hybrid
```
1. Listen once (no text)
2. Shadow 3x (with transcript)
3. Hide transcript → Dictate from memory
4. Compare → Analyze errors
```
