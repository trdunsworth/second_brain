# Conditionals - Complete Guide (と・ば・たら・なら)

## The Four Main Conditionals

| Form | Structure | Name | Core Nuance |
|------|-----------|------|-------------|
| **と** (to) | [Verb Plain] + と | Natural Conditional | **Always happens** - natural law, inevitable result |
| **ば** (ba) | [Verb Kateikei] + ば | General Conditional | **If/When** - general condition, hypothetical |
| **たら** (tara) | [Verb Ta-form] + ら | Completed Conditional | **After/When** - specific completed action, one-time |
| **なら** (nara) | [Noun/な-adj] + なら / [Verb Plain] + なら | Contextual Conditional | **If so / In that case** - topic-conditional |

---

## 1. と (to) - Natural Consequence

### Structure
- **Verb Plain** + と
- **い-adj** + と
- **な-adj / Noun** + だ + と

### Core Meaning: **"Whenever X, Y happens" / "If X, then inevitably Y"**

| Use | Example | Translation |
|-----|---------|-------------|
| **Natural Law** | 春**になると**桜が咲く。 | When spring comes, cherry blossoms bloom. |
| **Machine/Rule** | ボタンを押す**と**電気がつく。 | Press button → light turns on. |
| **Habitual** | この道を曲がる**と**駅だ。 | Turn this road → it's the station. |
| **Discovery** | 開ける**と**空だった。 | Opened it → was empty. |

### Restrictions
- ❌ **Cannot use with volition** (commands, requests, intentions, suggestions)
- ❌ **Cannot use for future one-time events** with speaker's will
- ✅ OK: **明日、雨が降ると困る。** (If it rains tomorrow, I'll be troubled - involuntary reaction)

> **Wrong**: *行**と**見せましょう。* → Use **ば/たら/なら**

---

## 2. ば (ba) - General Conditional

### Structure
| Type | Rule | Example |
|------|------|---------|
| **Godan** | Kateikei (e) + ば | 書けば, 行けば, 買えば |
| **Ichidan** | Stem + れ + ば | 食べれば, 見れば |
| **Irregular** | すれば, 来れば | |
| **い-adj** | い → けれ + ば | 高ければ |
| **な-adj** | + なら / であれば | 静かなら / 静かであれば |
| **Noun** | + なら / であれば | 学生なら / 学生であれば |

### Core Meaning: **"If X (condition), then Y" - General, Hypothetical**

| Use | Example | Translation |
|-----|---------|-------------|
| **General Condition** | 時間があれば行きます。 | If I have time, I'll go. |
| **Hypothetical** | お金があれば買う。 | If I had money, I'd buy it. |
| **Advice** | 疲れていれば休めばいい。 | If tired, just rest. |
| **Polite Request** | よろしければ、どうぞ。 | If it's OK, please. |

### ば + ほしい / ほしくない (Desire Conditional)
- **早く来ればいいのに。**（If only [he] would come early...)

---

## 3. たら (tara) - Completed Action Conditional

### Structure
- **Verb Ta-form** + ら
- **い-adj** かった + ら
- **な-adj / Noun** だった + ら

### Core Meaning: **"After X happened / When X happens" - Specific, Realized**

| Use | Example | Translation |
|-----|---------|-------------|
| **One-time Future** | 明日、雨が降ったら中止だ。 | If it rains tomorrow, cancelled. |
| **Completed Action** | 宿題が終わったら遊ぶ。 | After HW finishes, play. |
| **Past Counterfactual** | 知っていたら行ったのに。 | If I'd known, I would've gone. |
| **Discovery** | 箱を開けたら、猫がいた。 | Opened box → cat was inside. |

### たら vs と: Discovery Context
| Sentence | Nuance |
|----------|--------|
| ドアを開け**ると**猫がいた。 | General fact: Whenever open door, cat there. |
| ドアを開け**たら**猫がいた。 | Specific event: I opened door, found cat. |

---

## 4. なら (nara) - Contextual / Topic Conditional

### Structure
- **Noun / な-adj** + なら
- **Verb / い-adj** (Plain) + なら
- Often: **Topic は** + なら

### Core Meaning: **"If we're talking about X / In the case of X / If so"**

| Use | Example | Translation |
|-----|---------|-------------|
| **Topic Conditional** | **東京なら**便利だ。 | **If it's Tokyo**, it's convenient. |
| **"If So" Response** | A: 行きます。 B: **行くなら**連絡して。 | A: I'll go. B: **If so**, contact me. |
| **Contrastive** | **肉なら**食べない。 | **Meat** I won't eat (but fish OK). |
| **Advice/Suggestion** | **学生なら**割引がある。 | **If you're a student**, there's a discount. |

### なら vs ば/たら: Speaker's Stance
- **なら** = "Given X as topic/context, Y" - Speaker has info about X
- **ば/たら** = "If X happens, Y" - Pure condition

|----------|----|----|------|------|
| **Natural Law** | ✅ Best | OK | OK | ❌ |
| **Machine/Rule** | ✅ Best | OK | OK | ❌ |
| **Habitual** | ✅ Best | OK | OK | ❌ |
| **General "If"** | ❌ | ✅ Best | OK | OK |
| **One-time Future** | ❌ | OK | ✅ Best | OK |
| **Past Counterfactual** | ❌ | OK | ✅ Best | OK |
| **Discovery (Specific)** | ❌ | OK | ✅ Best | ❌ |
| **Topic/Contrast** | ❌ | ❌ | ❌ | ✅ Best |
| **"If So" (Response)** | ❌ | ❌ | OK | ✅ Best |
| **Volition Allowed?** | ❌ | ✅ | ✅ | ✅ |

## Volition Compatibility

| Conditional | With Volition (Commands, Requests, Intentions) |
|-------------|------------------------------------------------|
| **と** | ❌ *行**と**ください ✗ |
| **ば** | ✅ 行**けば**ください ✓ (Polite request) |
| **たら** | ✅ 行**たら**ください ✓ (After you go...) |
| **なら** | ✅ 行**くなら**連絡して ✓ (If you're going...) |

> **Rule**: と expresses **objective inevitability** - cannot contain speaker's will.

---

## Negative Conditionals

| Form | Structure | Example |
|------|-----------|---------|
| **と** | ない-form + と | 行かな**いと**遅れる。 (If don't go, late.) |
| **ば** | ない-form (stem ない→なけれ) + ば | 行かな**ければ**遅れる。 |
| **たら** | ない-form (nakat) + たら | 行かな**かったら**遅れる。 |
| **なら** | ない-form / じゃない + なら | 行か**ないなら** / 行か**ないなら** |

---

## Compound Conditionals

### 1. ければ〜ほど (The More..., The More...)
- **早ければ早いほどいい。** (The earlier, the better.)
- **高ければ高いほど売れる。** (The more expensive, the better it sells.)

### 2. たら〜たら (Whether...or...)
- **雨が降ったら降ったで、行かない。** (If it rains, fine - won't go. / Rain or shine...)

### 3. なら〜なら (If X, then Y; If not X, then Z)
- **行くなら行くで、準備しろ。行かないなら行かないで、連絡しろ。**

### 4. ばこそ (Precisely Because) - Emphatic
- **君が行く**ばこそ**意味がある。** (It's meaningful precisely because YOU go.)

## Conditional-Like Expressions

| Expression | Structure | Meaning | Example |
|------------|-----------|---------|---------|
| **もし** (moshi) | もし + [Conditional] | "If by chance" (emphasizes hypothetical) | **もし**雨なら行かない。 |
| **万が一** (mangai) | 万が一 + [Conditional] | "In the unlikely event" | **万が一**失敗したらどうする？ |
| **〜場合** (baai) | [Verb Plain] + 場合 | "In case of" (noun phrase) | **雨の場合**は中止。 |
| **〜時** (toki) | [Verb Plain] + 時 | "When" (time focus) | **来る時**連絡して。 |
| **〜とすれば / となると** | [Plain] + とすれば/となると | "If that's the case / Assuming" | **そうとすれば**簡単だ。 |
| **〜限り** (kagiri) | [Plain] + 限り | "As long as" | **元気な限り**働く。 |

---

## Counterfactual Conditionals (Contrary to Fact)

### Structure: [Past/Counterfactual] + のに / ば / たら

| Form | Example | Meaning |
|------|---------|---------|
| **〜たら…のに** | 知っていたら行った**のに**。 | If I'd known, I would've gone (but didn't). |
| **〜ば…のに** | お金があれば買った**のに**。 | If I had money, I'd have bought it. |
| **〜たら…だろう** | 彼が来たら楽しかった**だろう**。 | If he came, it would've been fun. |

> **のに** adds regret/disappointment: "But in reality..."

## Practice: Choose the Best Conditional

1. Water boils at 100°C. → 水は100度で沸騰する**と**...
2. If you have time, please come. → 時間があれ**ば** / あ**たら**...
3. If it rains tomorrow, I won't go. → 明日雨が降**ったら**...
4. When I opened the box, there was a cat. → 箱を開け**たら**...
5. If you're a student, it's cheaper. → 学生**なら**...
6. "I'm going." "If so, call me." → 「行く。**行くなら**連絡して。」
7. The more you practice, the better. → 練習すればする**ほど**...
8. If I had known, I would have told you. → 知ってい**たら**教えたのに。
9. Press the button → light turns on. → ボタンを押す**と**...
10. As long as I'm healthy, I'll work. → 元気な**限り**...

## Advanced: Conditional in Complex Sentences

### Embedded Conditionals
- **彼が来るなら、私も行くつもりだ。** (If he's going, I intend to go too.)
- **雨が降ったら中止だと連絡があった。** (Got notice that if it rains, it's cancelled.)

### Conditional + Volitional
- **行けば会えるだろう。**（If go, can probably meet.）
- **行ったら電話する。**（When/If go, will call.）
- **行くなら待ってる。**（If you're going, I'll wait.）

### Conditional in Relative Clauses
- **行くなら早いほうがいい。** (If going, earlier is better.)
- **買うなら今だ。** (If buying, now's the time.)

---

*Conditionals are not interchangeable. Each encodes a different temporal/logical relationship. Master the "Volition Test" for と, and the "Topic vs Condition" distinction for なら. These two are the most common errors.*
