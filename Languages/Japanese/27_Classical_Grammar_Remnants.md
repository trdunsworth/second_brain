# Classical Grammar Remnants in Modern Japanese (文語の残影)

## Overview
Modern Japanese (口語 - こうご) retains many **Classical Japanese (文語 - ぶんご)** forms in **fixed expressions, idioms, literature, formal writing, and set phrases**. Recognizing these unlocks higher-level reading.

---

## Classical Auxiliary Verbs (助動詞 - じょどうし) - Surviving Forms

### 1. ぬ (nu) - Perfective / Negative (Classical) → Modern: ない
**Classical**: 完了 (completion) / 否定 (negation)
**Modern Survival**: Fixed phrases, negation in set expressions

| Classical | Modern Equivalent | Surviving Usage |
|-----------|-------------------|-----------------|
| **死ぬ** (shinu) | 死ぬ | **Only verb retaining ぬ as dictionary form!** |
| **去ぬ** (さる) | 去る | **去り際** (saraigiwa - moment of leaving) |
| **〜ず** (zu) | 〜ない | **知らず** (shirazu - unknowingly), **言わずもがな** (iwazu mo gana - goes without saying) |
| **〜ぬ** (nu) | 〜ない | **成せば成る、成さねば成らぬ** (Naseba naru, nasaneba naranu) |

### 2. つ (tsu) - Perfective (Completion) → Modern: た
**Classical**: 完了
**Modern Survival**: Fossilized in set phrases

| Classical Form | Modern | Surviving Usage |
|----------------|--------|-----------------|
| **尽きつ** (tsukitsu) | 尽きた | **尽きることなく** (tsukiru koto naku) |
| **なりつ** (naritsu) | なった | **成りつつある** (naritsutsu aru - in process of becoming) |
| **〜つ〜つ** | 〜たり〜たり | **思い出しつ、忘れつ** (omoidashitsu, wasuretsu) |

### 3. たり (tari) - Perfective / Progressive → Modern: て/た
**Classical**: 完了・進行・反復
**Modern Survival**: **〜たり〜たり** (representative actions)

| Classical | Modern | Example |
|-----------|--------|---------|
| **書きたり** | 書いた / 書いて | **読みたり、書きたり** (yomitari, kakitari) |
| **ありたり** | あった / あって | **ありたり** (aritari - commonplace) |

### 4. けり (keri) - Past / Exclamatory → Modern: た / よ
**Classical**: 過去・感動
**Modern Survival**: Fossilized in proverbs, poetry

| Classical | Modern | Surviving Usage |
|-----------|--------|-----------------|
| **行きけり** (yukikeri) | 行ったよ | **古池や蛙飛び込む水の音** (furuike ya kawazu tobikomu mizu no oto - no keri but famous haiku) |
| **〜けり** | 〜たよ | **行きけり** → **行ったことよ** (poetic) |

### 5. き (ki) - Past (Direct Experience) → Modern: た
**Classical**: 過去（直感）
**Modern Survival**: Almost none in speech, some in literature

| Classical | Modern | Note |
|-----------|--------|------|
| **来き** (koki) | 来た | **来き** only in classical texts |

### 6. なむ (namu) - Emphatic / Wish → Modern: よ / ね
**Classical**: 強意・願望
**Modern Survival**: **なむ** → **な** (emphatic) in some dialects/set phrases

## Classical Adjectives (形容詞 - けいようし) - Surviving Stems

### ク活用 → Modern い-adjectives
| Classical Stem | Modern | Surviving Forms |
|----------------|--------|-----------------|
| **なし** (nashi) | ない | **なし** (without), **なからずも** (nakarazu mo - not without) |
| **よし** (yoshi) | いい/よい | **よし** (OK/good), **よしあし** (good and bad) |
| **あし** (ashi) | 悪い | **あし** (bad - literary), **あしき** (ashiki - bad, literary) |

### シク活用 → Modern い-adjectives
| Classical Stem | Modern | Surviving Forms |
|----------------|--------|-----------------|
| **かなし** (kanashi) | 悲しい | **かなし** (sad - literary), **かなしみ** (sadness) |
| **うれし** (ureshi) | 嬉しい | **うれし** (happy - literary), **うれし涙** (ureshi namida) |

## Classical Verb Forms in Modern Usage

### 1. Imperfective (未然形) + ば → ば conditional
| Classical | Modern | Example |
|-----------|--------|---------|
| **書かば** (kakaba) | 書けば | **書かば** (if write - literary) |
| **行かば** (ykaba) | 行けば | **行かば** (if go - literary) |

### 2. Continuative (連用形) + て → て-form
| Classical | Modern | Example |
|-----------|--------|---------|
| **書きて** (kaite) | 書いて | **書きて** (writing - literary/poetic) |
| **思い出で** (omoide) | 思い出して | **思い出で** (omoide - memory/noun) |

### 3. Terminal (終止形) + ども → ども (concessive)
| Classical | Modern | Example |
|-----------|--------|---------|
| **れども** (redomo) | けども | **しかしども** (shikashi domo - however) |
| **いども** (idomo) | いえども | **言いども** (iidomo - even if say) |

### 4. Attributive (連体形) + もの → ものか (rhetorical)
| Classical | Modern | Example |
|-----------|--------|---------|
| **行くものか** (yuku mono ka) | 行くものか | **行くものか！** (Like I'd go!) |

## Fossilized Classical Expressions (Daily Use)

### 1. ず (zu) - Negative Continuative (〜ないで / 〜なくて)
**Modern Usage**: Very common in written, formal, and set phrases.

| Expression | Reading | Meaning | Origin |
|------------|---------|---------|--------|
| **知らず** | しらず | Unknowingly | 知る + ず |
| **言わずもがな** | いわずもがな | Goes without saying | 言わず + もがな |
| **敢えて〜ず** | あえて〜ず | Deliberately not... | 敢えて + ず |
| **〜ずにはいられない** | 〜ずにはいられない | Can't help but... | ず + には + いられない |
| **〜ずにおく** | 〜ずにおく | Leave undone | ず + に + おく |
| **〜ずじまい** | 〜ずじまい | End up not doing | ず + 仕舞い |
| **何食わぬ顔** | なにくわぬかお | Poker face | 何 + 食わ (imperfective) + ぬ + 顔 |

### 2. ぬ (nu) - Negative Terminal/Attributive
| Expression | Reading | Meaning |
|------------|---------|---------|
| **成せば成る、成さねば成らぬ** | なせばなる、なさねばならぬ | Where there's a will, there's a way |
| **為せば成る** | なせばなる | If you do it, it will be done |
| **なきにしもあらず** | なきにしもあらず | Not entirely without / Possible |
| **ぬかりない** | ぬかりない | Thorough, no oversight |

### 3. たり (tari) - Representative Actions
| Modern | Classical Origin | Meaning |
|--------|------------------|---------|
| **〜たり〜たり** | 連用形 + たり | Do X, do Y, etc. |
| **ありたり** | あり + たり | Commonplace, ordinary |
| **たちまち** | たちまち (立 + まち) | Immediately (not tari but similar) |

### 3. けり (keri) → Exclamatory Past
| Modern | Classical | Usage |
|--------|-----------|-------|
| **〜たことよ** | 〜けり | Poetic narrative past |

## Classical Particles in Modern Usage

### 1. や (ya) - Non-exhaustive "And" (Classical: や)
**Modern**: や (same) / など (etc.)
- **花や鳥** (Flowers, birds, etc.)

### 2. か (ka) - Question / Uncertainty (Classical: か)
**Modern**: か (question), か (or - in 嵌めか)

### 3. な (na) - Emphatic / Prohibition (Classical: な)
**Modern**: な (prohibition: 行くな), な (emotion: 美しいな), な (tag question: 行くな)

### 3. ぞ (zo) - Emphasis (Classical: ぞ)
**Modern**: ぞ (masculine emphasis: 行くぞ)

### 4. なむ (namu) → な (Emphasis)
**Modern**: な (emphasis: 行くな - "Do go!")

## Classical Sentence Patterns in Modern Writing

### 1. 文語調 (Bungochō) - Literary Style
**Features**: だ/です → である/であります, ず, つ, たり, けり, なり, たり

| Spoken (口語) | Written/Literary (文語) |
|---------------|-------------------------|
| **学生だ** | **学生である** |
| **行かない** | **行かず** / **行かぬ** |
| **書いて** | **書きて** / **書き** |
| **読んだり** | **読みたり** |
| **来たよ** | **来たり** / **来たれり** |
| **美しい** | **美し** (terminal) / **美しき** (attributive) |
| **静かだ** | **静かなり** / **静かなる** |

### 2. である Style (De Aru Style) - Academic/Formal
**Standard for**: Papers, reports, news, Wikipedia, contracts

| Plain | である Style |
|-------|--------------|
| 学生だ | 学生である |
| 行かない | 行かない / 行かず |
| 書いている | 書いている / 書きつつある |
| だった | であった |
| ではない | ではない / でない |

> **である** = Formal written copula. **であります** = Formal polite.

### 3. Stem-Linking (連用形接続) - Formal Written
**Instead of て-form**: Use **連用形 (stem)** to connect clauses.

| て-form (Spoken) | Stem-linking (Written) |
|------------------|------------------------|
| **読んで、書く** | **読み、書く** |
| **行って、見る** | **行き、見る** |
| **高くて、大きい** | **高く、大きい** (adj: く-form) |
| **静かで、広い** | **静かで、広い** (な-adj: で remains) |

> **Rule**: Verbs → Stem (ren'youkei) | い-adj → く | な-adj → で

## Reading Classical Japanese (Basic Toolkit)

### Verb Identification
| Classical Form | Modern Equivalent | Identification |
|----------------|-------------------|----------------|
| **〜ず** | 〜ない | Negative continuative |
| **〜ぬ** | 〜ない / 〜た | Negative terminal/attributive OR perfective |
| **〜つ** | 〜た | Perfective |
| **〜たり** | 〜た / 〜て | Perfective/progressive |
| **〜けり** | 〜たよ | Exclamatory past |
| **〜き** | 〜た | Direct experience past |
| **〜けむ** | 〜ただろう | Conjectural past |
| **〜まし** | 〜ただろう | Counterfactual |

### Adjective Identification
| Classical Terminal | Classical Attributive | Modern |
|--------------------|----------------------|--------|
| **〜し** (shi) | **〜き** (ki) | い-adj (ク活用) |
| **〜じ** (ji) | **〜き** (ki) | い-adj (シク活用) |
| **〜なり** (nari) | **〜なる** (naru) | な-adj (ナリ活用) |
| **〜たり** (tari) | **〜たる** (taru) | な-adj (タリ活用) |

### Copula
| Form | Classical | Modern |
|------|-----------|--------|
| Terminal | **なり** (nari) | だ / である |
| Attributive | **なる** (naru) | な / の |
| Continuative | **に** (ni) | で / に |

## Practice: Identify Classical Remnants

1. **知らず知らずのうちに** → ず (negative continuative) × 2
2. **成せば成る、成さねば成らぬ** → ぬ (negative attributive/terminal)
3. **言わずもがな** → ず + もがな
4. **ありふれた** (commonplace) → あり (verb) + ふれ (passive) + た → not classical but **ありたり** origin
5. **いとおかし** → いと (very) + おかし (charming - classical adj)
6. **書きて** (in haiku/literature) → 連用形 + て
7. **美しき** (attributive classical) → シク活用 attributive
8. **静かなり** (copula) → ナリ活用 terminal
9. **行かば** (conditional) → 未然形 + ば
10. **言いども** (concessive) → 終止形 + ども

---

*Classical remnants are the "DNA" of modern Japanese. You don't need to master classical grammar, but recognizing these 20-30 fossilized forms dramatically improves reading of literature, formal writing, and even daily set phrases.*
