# Keigo (敬語) - Honorifics Fundamentals

## Three Categories

| Category | Japanese | Purpose | Direction |
|----------|----------|---------|-----------|
| **尊敬語** (Sonkeigo) | Honorific | **Elevate** the **listener/third party** | Their actions → High |
| **謙譲語** (Kenjougo) | Humble | **Lower** the **speaker** | My actions → Low |
| **丁寧語** (Teineigo) | Polite | **Polite** form for **general use** | Neutral → Polite |

> **Core Principle**: Keigo is **relational**. You choose based on **who does the action** and **who receives it**.

---

## 丁寧語 (Teineigo) - Baseline Polite

| Plain | Polite (Teineigo) |
|-------|-------------------|
| だ / である | です / であります |
| Verb Dictionary | Verb ます-form |
| い-adj + だ | い-adj + です |
| な-adj + だ | な-adj + です |

> **Use**: Default with strangers, seniors, formal situations. **Not keigo per se** - just polite register.

## 尊敬語 (Sonkeigo) - Elevating Others' Actions

### 1. Special Honorific Verbs (完全尊敬語)

| Plain Verb | Sonkeigo | Example |
|------------|----------|---------|
| **いる / 行く / 来る** | **いらっしゃる** | 先生が**いらっしゃる**。 |
| **言う** | **おっしゃる** | 部長が**おっしゃった**。 |
| **見る** | **ご覧になる** (ごらんになる) | 社長が**ご覧になった**。 |
| **食べる / 飲む** | **召し上がる** (めしあがる) | お客様が**召し上がった**。 |
| **する** | **なさる** | 先生が**なさる**。 |
| **知る** | **ご存知だ** (ごぞんじだ) | **ご存知ですか？** |
| **寝る** | **お休みになる** | **お休みになりましたか？** |
| **くれる** | **くださる** | 先生が**くださった**。 |
| **会う** | **お会いになる** | **お会いになりましたか？** |

### 2. お/ご + Stem + になる (General Pattern)
**Structure**: **お/ご** + **Verb Stem** + **になる**

| Verb | Sonkeigo | Example |
|------|----------|---------|
| 読む | **お読みになる** | **お読みになりますか？** |
| 書く | **お書きになる** | **お書きになりました。** |
| 待つ | **お待ちになる** | **お待ちになっています。** |
| 帰る | **お帰りになる** | **お帰りになりました。** |
| 使う | **お使いになる** | **お使いになりますか？** |

> **Rule**: **お** for native verbs (和語), **ご** for Sino-Japanese (漢語)
> - **お**: 読む, 書く, 待つ, 帰る, 使う, 話す, 聞く...
> - **ご**: 連絡する, 報告する, 説明する, 理解する, 判断する, 出発する...

### 3. Passive Form as Sonkeigo (受身尊敬)
**Structure**: Verb Passive Form
- **先生が本を書かれた。** (Teacher wrote book - honorific)
- **部長がもうお帰りになった。** → **部長がもうお帰りになられた。**

> **Less formal** than special verbs or お〜になる. Common in business.

## 謙譲語 (Kenjougo) - Humbling Own Actions

### 1. Special Humble Verbs (完全謙譲語)

| Plain Verb | Kenjougo | Example |
|------------|----------|---------|
| **行く / 来る / いる** | **参る** (まいる) | **私が参ります。** |
| **言う** | **申す** (もうす) | **田中と申します。** |
| **見る** | **拝見する** (はいけんする) | **資料を拝見しました。** |
| **食べる / 飲む** | **いただく** | **コーヒーをいただきます。** |
| **する** | **いたす** | **私がいたします。** |
| **知る** | **存じる** (ぞんじる) | **存じております。** |
| **思う** | **存じる** | **そう存じます。** |
| **会う** | **お目にかかる** (おめにかかる) | **お目にかかれて光栄です。** |
| **もらう** | **いただく** | **資料をいただきました。** |
| **あげる** | **差し上げる** (さしあげる) | **先生に差し上げました。** |

### 2. お/ご + Stem + する (General Pattern)
**Structure**: **お/ご** + **Verb Stem** + **する** (→ いたす for extra humility)

| Verb | Kenjougo | Example |
|------|----------|---------|
| 待つ | **お待ちする** / **お待ちいたす** | **お待ちしております。** |
| 連絡する | **ご連絡する** / **ご連絡いたす** | **ご連絡いたします。** |
| 報告する | **ご報告する** / **ご報告いたす** | **ご報告いたしました。** |
| 説明する | **ご説明する** / **ご説明いたす** | **ご説明いたしましょう。** |
| 了解する | **ご了解する** → **承知する** (better) | **承知いたしました。** |
| 送る | **お送りする** / **お送りいたす** | **お送りいたします。** |

> **Same お/ご rule**: Native = お, Sino = ご

### 3. 二重敬語 (Double Keigo) - **AVOID!**
| Wrong | Correct | Reason |
|-------|---------|--------|
| **お読みになられる** | お読みになる / 読まれる | Double honorific |
| **拝見させていただく** | 拝見する / 見せていただく | Double humble |
| **おっしゃられる** | おっしゃる | Double honorific |
| **いただかれる** | いただく / くださる | Double |

## 尊敬語 vs 謙譲語 - Quick Decision

```
WHO performs the action?
├── Listener / Superior / Customer / Third Party (Respected)
│   └── Use **尊敬語** (Sonkeigo)
│       ├── Special verbs: いらっしゃる, おっしゃる, 召し上がる...
│       ├── お/ご〜になる: お読みになる, ご連絡になる...
│       └── Passive: 書かれる, 行かれる...
│
└── Me / My In-group (Family, Company colleagues to outsider)
    └── Use **謙譲語** (Kenjougo)
        ├── Special verbs: 参る, 申す, 拝見する, いただく...
        ├── お/ご〜する/いたす: お待ちする, ご連絡いたす...
        └── (Never use passive for own actions!)
```

## Common Set Phrases (Business Essentials)

### Greetings
| Situation | Phrase |
|-----------|--------|
| **Good morning** | **おはようございます** / **お早うございます** |
| **Thank you** | **ありがとうございます** / **感謝いたします** / **恐縮です** |
| **Sorry** | **申し訳ありません** / **申し訳ございません** / **恐れ入ります** |
| **Excuse me** | **失礼します** / **失礼いたします** |
| **Goodbye (leaving)** | **失礼します** / **お先に失礼します** |
| **Goodbye (staying)** | **お疲れ様でした** / **ご苦労様でした** (to subordinates) |

### Requests
| Plain | Polite (Teineigo) | Honorific (Sonkeigo) | Humble (Kenjougo) |
|-------|-------------------|---------------------|-------------------|
| して | してください | **していただけますか** / **なさってください** | **させていただきます** |
| ください | ください | **くださる** | **いただく** |
| 見て | 見てください | **ご覧ください** | **拝見させていただく** |
| 来て | 来てください | **いらしてください** | **参らせていただく** |

### Phone Etiquette
| Situation | Phrase |
|-----------|--------|
| **Answering** | **はい、株式会社○○でございます。** |
| **Asking for someone** | **○○様をお願いいたします。** / **○○様はいらっしゃいますか。** |
| **Putting on hold** | **少々お待ちください。** / **お待たせいたしました。** |
| **Taking message** | **承知いたしました。** / **お伝えいたします。** |
| **Hanging up** | **失礼いたします。** |

### Email Openings/Closings
| Position | Phrase |
|----------|--------|
| **Opening** | **いつもお世話になっております。** / **平素より格別のご高配を賜り、厚く御礼申し上げます。** |
| **Closing** | **よろしくお願いいたします。** / **何卒よろしくお願い申し上げます。** |
| **Apology** | **ご迷惑をおかけし、誠に申し訳ございません。** |

## Bikago (美化語) - Beautification Language
Adding **お/ご** to nouns for politeness (not keigo per se, but expected).

| Plain | Bikago |
|-------|--------|
| 水 | **お水** |
| 茶 | **お茶** |
| 金 | **お金** |
| 箸 | **お箸** |
| 傘 | **お傘** |
| トイレ | **お手洗い** |
| 名前 | **お名前** |
| 住所 | **ご住所** |
| 連絡 | **ご連絡** |
| 質問 | **ご質問** |

> **Don't overdo**: Your own things usually don't get お/ご (my water = 水, not お水)

## Keigo Quick Reference Card

| Function | Sonkeigo (Others) | Kenjougo (Self) | Teineigo (Neutral) |
|----------|-------------------|-----------------|-------------------|
| **Be/Exist** | いらっしゃる | おる / 参る | います |
| **Go/Come** | いらっしゃる / お見えになる | 参る / 伺う (うかがう) | 行きます / 来ます |
| **Say** | おっしゃる | 申す / 申し上げる | 言います |
| **See** | ご覧になる | 拝見する | 見ます |
| **Eat/Drink** | 召し上がる | いただく | 食べます / 飲みます |
| **Do** | なさる | いたす | します |
| **Know** | ご存知だ | 存じる | 知っています |
| **Think** | お思いになる | 存じる | 思います |
| **Meet** | お会いになる | お目にかかる | 会います |
| **Give (Me→Other)** | — | 差し上げる | あげます |
| **Give (Other→Me)** | くださる | いただく | くれます |
| **Receive** | お受けになる | いただく | もらいます |

## Practice: Choose Keigo

1. "The president will come tomorrow." → **社長が明日いらっしゃいます。**
2. "I will go to the meeting." → **会議に参ります。/ 伺います。**
3. "Please look at this document." → **この資料をご覧ください。**
4. "I read the document." → **資料を拝見しました。**
5. "The manager said so." → **部長がおっしゃいました。**
6. "I think so too." → **私もそう存じます。**
6. "Please eat." → **召し上がってください。**
7. "I'll have some." → **いただきます。**
8. "Please wait." → **お待ちください。**
9. "I'll wait." → **お待ちしております。**
10. "Thank you for giving me this." → **いただきまして、ありがとうございます。**

---

*Keigo is not "polite language" - it's "relational language." Every verb choice positions you in the social hierarchy. Start with the 10 special verb pairs (Sonkeigo/Kenjougo). The rest are productive patterns.*
