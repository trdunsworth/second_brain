# Classical Japanese Basics (古文 - こぶん)

## Why Learn Classical Japanese?
- **Literature**: Read pre-1946 novels, poetry, essays
- **Modern remnants**: 20% of written Japanese uses classical grammar/forms
- **Idioms/Proverbs**: Most originate from classical texts
- **Formal writing**: Legal, academic, ceremonial language

## Classical Verb Conjugation (古文動詞活用)

| Class | Classical Name | Example | Modern Equivalent |
|-------|----------------|---------|-------------------|
| **四段** (Yodan) | 四段活用 | **書く** (kaku) | Godan |
| **上一段** (Kami-ichidan) | 上一段活用 | **見る** (miru) | Ichidan |
| **下一段** (Shimo-ichidan) | 下一段活用 | **受く** (ukuku) | Ichidan |
| **上二段** (Kami-nidan) | 上二段活用 | **落ちる** (ochiru) | Ichidan |
| **下二段** (Shimo-nidan) | 下二段活用 | **受く** (ukuku) | Ichidan |
| **カ行変格** (Ka-gyou henkaku) | カ行変格活用 | **来** (ku) | 来る (kuru) |
| **サ行変格** (Sa-gyou henkaku) | サ行変格活用 | **す** (su) | する (suru) |
| **ナ行変格** (Na-gyou henkaku) | ナ行変格活用 | **死ぬ** (shinu) | 死ぬ (shinu) - Godan |

### Key: Classical → Modern Mapping
| Classical Form | Modern Form | Notes |
|----------------|-------------|-------|
| **四段 (Yodan)** | **五段 (Godan)** | Same verbs, renamed |

| **カ変/サ変/ナ変/ラ変** | **Irregular** | Same |

## Reading Classical Texts - Practical Approach

### 1. Identify Verb Forms
- **〜ず** → Negative
- **〜つ/〜ぬ/〜たり/〜けり** → Past/Perfective
- **〜む/〜ん/〜まし/〜べし** → Modality

### 2. Identify Auxiliary Chains
- **書きつけり** = 書き (ren'you) + つ (perfective) + けり (exclamatory past)
- **見えぬなり** = 見え (ren'you) + ぬ (negative) + なり (copula)

### 3. Historical Kana → Modern
- **いはひ** → いはひ (祝い)
- **をかし** → おかし (可愛い/面白い)
- **あはれ** → あわれ (哀れ)
- **をかし** → おかし (interesting/charming)

### 4. Vocabulary Shifts
| Classical | Modern | Meaning |
|-----------|--------|---------|
| **をかし** (okashi) | おかしい / 可愛い | Charming/amusing |
| **あはれ** (aware) | 哀れ | Pathos/pity |
| **いと** (ito) | 非常に | Very |
| **かなし** (kanashi) | 悲しい / 愛しい | Sad/dear |
| **おかし** (okashi) | おかしい | Funny/strange |
| **もののあはれ** | 物の哀れ | Pathos of things |

## Essential Classical Texts for Practice

### 1. **伊勢物語** (Ise Monogatari) - 10th c.
- **Opening**: 「むかし、をとこありけり。」
- **Grammar**: ありけり (ari + keri = exclamatory past)

### 2. **土佐日記** (Tosa Nikki) - 10th c.
- **Written in kana** (pretending to be woman)
- **Grammar**: 見えぬ (mienu = negative), 思ひ出でられぬ (omoidasarenu)

### 3. **枕草子** (Makura no Sōshi) - 11th c.
- **Sei Shōnagon** - Essays/lists
- **Style**: Elegant, witty, observational
- **Famous**: 「春はあけぼの。」（Spring is dawn.）

### 4. **方丈記** (Hōjōki) - 13th c.
- **Kamo no Chōmei** - Buddhist impermanence
- **Opening**: 「ゆく河の流れは絶えずして、しかももとの水にあらず。」
- **Grammar**: 絶えず (taezu = negative continuative), あらず (arazu = negative)

### 5. **徒然草** (Tsurezuregusa) - 14th c.
- **Yoshida Kenkō** - Essays
- **Style**: Reflective, miscellaneous
- **Opening**: 「つれづれなるままに、日暮らし、硯に向かひて、心に移りゆくよしなしごとをそこはかとなく書きつくれば、あやしうこそものぐるほしけれ。」

### 6. **奥の細道** (Oku no Hosomichi) - 17th c.
- **Bashō** - Haibun (prose + haiku)
- **Mix of classical & vernacular**

## Practice: Classical → Modern

1. **「花は散りぬ、風のいたずらに」** → 花は散った、風のいたずらに。
2. **「月見れば千々に物こそ悲しけれ」** → 月を見ると、いろいろなことが悲しい。
3. **「をとこ、心に思ふことありて、女のもとへ通ひけり」** → 男が、心に思うことがあって、女のもとへ通った。
4. **「春はあけぼの。やうやう白くなりゆく山ぎは、少し明かりて、紫だちたる雲の細くたなびきたる。」** → 春は暁。だんだん白くなりゆく山際、少し明るく、紫色に立った雲が細くたなびいている。
5. **「ゆく河の流れは絶えずして、しかももとの水にあらず。」** → 流れ行く川の流れは絶えることなく、しかも元の水ではない。

## Study Path for Classical Japanese

1. **Historical kana** (1 week)
2. **Verb conjugation table** (2 weeks) - Focus on 4 main classes
3. **Top 20 auxiliaries** (2 weeks) - ぬ, つ, たり, けり, む, べし, まし, ず, じ, ごとし
4. **Adjective conjugation** (1 week) - ク, シク, ナリ, タリ
5. **Particles** (1 week)
6. **Read annotated texts** (ongoing) - Start with **伊勢物語**, **土佐日記**, **枕草子**
7. **Dictionary**: **古語辞典** (Kogo jiten) - Essential tool

---

*Classical Japanese is not "old Japanese" - it's the **literary register** used for 1000+ years. You don't need fluency. Recognizing the 20 core auxiliaries + historical kana unlocks pre-war literature, legal texts, and the roots of modern grammar.*
