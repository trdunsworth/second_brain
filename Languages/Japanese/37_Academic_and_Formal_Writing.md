# Academic & Formal Writing (学術・公用文・論理的文章)

## Overview
Japanese academic/formal writing follows **strict conventions** distinct from both speech and literature. Master the **である style**, logical connectors, and citation norms.

---

## 論文スタイル (Ronbun Style) - Academic Paper Conventions

### 1. Copula: である / であります
| Register | Plain | Polite |
|----------|-------|--------|
| **Standard Academic** | **である** | **であります** |
| **Thesis/Dissertation** | **である** | — |
| **Journal Article** | **である** | — |
| **Grant Proposal** | **である** | **であります** |
| **Business Report** | **である** | **であります** |

> **Never use** です/ます in academic papers (except quotes). **Never use** だ.

### 2. Sentence Structure Principles

#### A. One Idea Per Sentence
> **Bad**: データを収集し、分析し、結果をまとめ、考察した。
> **Good**: データを収集した。これを分析した。結果をまとめた。考察を加えた。

#### B. Subject Clarity
> **Bad**: 実験を行った結果、有意差が認められた。
> **Good**: **本実験の結果**、有意差が認められた。

#### C. Logical Flow Markers
| Position | Function | Expressions |
|----------|----------|-------------|
| **Paragraph Start** | Topic | **本稿では、〜について論じる。** |
| **Section Start** | Transition | **まず、〜を概観する。** / **次に、〜を検討する。** |
| **Argument** | Claim | **〜と考えられる。** / **〜と推測される。** |
| **Evidence** | Support | **これは、〜による。** / **〜ことが示唆される。** |
| **Counter** | Concession | **一方、〜という指摘もある。** |
| **Rebuttal** | Response | **しかし、〜という点で異なる。** |
| **Conclusion** | Summary | **以上のことから、〜と結論づけられる。** |

## Logical Connectors (論理接続表現) - Formal Written

### Addition / Elaboration
| Connector | Function | Example |
|-----------|----------|---------|
| **さらに** | Furthermore | **さらに、この結果は〜を示唆する。** |
| **また** | Also | **また、先行研究においても同様の傾向が報告されている。** |
| **加えて** | In addition | **加えて、新たな知見が得られた。** |
| **ならびに** | And (formal) | **実験ならびにシミュレーションを行った。** |
| **のみならず** | Not only... but also | **専門家のみならず、一般市民にも影響する。** |

### Contrast / Concession
| Connector | Function | Example |
|-----------|----------|---------|
| **しかし** | However | **しかし、この手法には限界がある。** |
| **一方** | On the other hand | **一方、コストの面では優位である。** |
| **逆に** | Conversely | **逆に、温度が低い場合は反応が遅い。** |
| **それに対して** | In contrast | **それに対して、本手法は高速である。** |
| **〜が** | But (clause-internal) | **コストは高い**が**、精度は向上する。** |
| **〜ものの** | Although | **高価**ものの**、**需要は高い。** |

### Cause / Reason
| Connector | Function | Example |
|-----------|----------|---------|
| **したがって** | Therefore | **データに誤差が含まれる。したがって、再実験が必要である。** |
| **それゆえに** | For that reason | **サンプル数が少ない。それゆえに、統計的有意性は低い。** |
| **このため** | For this reason | **このため、新たな指標を導入した。** |
| **〜ため** | Because | **予算不足**ため**、**計画を縮小した。** |
| **〜ことを受けて** | In response to | **審査結果**を受けて**、計画を見直した。** |

### Condition
| Connector | Function | Example |
|-----------|----------|---------|
| **もし〜ならば** | If | **もし仮説が正しければ、現象が説明できる。** |
| **〜場合** | In case | **エラーが発生した場合、システムは停止する。** |
| **〜とき** | When | **データが欠損しているときは、補完処理を行う。** |

### Purpose
| Connector | Function | Example |
|-----------|----------|---------|
| **〜ために** | In order to | **精度向上**のために**、モデルを改良した。** |
| **〜ように** | So that | **エラーが出ないよう**、検証を重ねた。** |
| **〜ことを目的として** | For the purpose of | **原因究明**を目的として**、調査を行った。** |

### Exemplification
| Connector | Function | Example |
|-----------|----------|---------|
| **例えば** | For example | **例えば、画像認識タスクにおいて顕著である。** |
| **具体的には** | Specifically | **具体的には、パラメータを調整した。** |
| **一例として** | As an example | **一例として、A社の事例を挙げる。** |

### Summary / Conclusion
| Connector | Function | Example |
|-----------|----------|---------|
| **以上のことから** | From the above | **以上のことから、本手法は有効であると結論づけられる。** |
| **要するに** | In short | **要するに、コストと精度のトレードオフである。** |
| **すなわち** | That is | **すなわち、最適解は存在しない。** |
| **結論として** | As a conclusion | **結論として、さらなる検証が必要である。** |

## Hedging (学術的控え表現) - Epistemic Modality

### Certainty Levels
| Level | Expression | Example | Use Case |
|-------|------------|---------|----------|
| **High** | **〜はずだ / にちがいない** | **正しいはずだ。** | Strong evidence |
| **Standard** | **〜と考えられる / と推測される** | **効果があると考えられる。** | Standard claim |
| **Moderate** | **〜可能性がある / 〜傾向がある** | **改善の可能性がある。** | Preliminary |
| **Weak** | **〜かもしれない / 〜と思われる** | **関係しているかもしれない。** | Speculative |
| **Negative** | **〜とは限らない / 〜わけではない** | **必ずしも正しいとは限らない。** | Caution |

### Passive for Objectivity
| Active (Speech) | Passive (Writing) |
|-----------------|-------------------|
| **私は実験した。** | **実験が行われた。** |
| **筆者は分析した。** | **分析がなされた。** |
| **我々は観察した。** | **観察がなされた。** |

## Citation & Reference Conventions

### In-Text Citation (本文中引用)

#### Author-Year (Author-Date)
> **田中 (2020) は、〜と報告している。**
> **〜とされる (田中, 2020)。**
> **複数の研究 (佐藤, 2019; 鈴木, 2021) で確認されている。**

#### Numbered [1]
> **先行研究 [1] によれば、〜である。**
> **複数の報告 [1-3] が存在する。**

### Direct Quote (直接引用)
> **「この現象は未解明である」 (田中, 2020, p. 45)。**

### Indirect Quote (間接引用)
> **田中 (2020) は、この現象が未解明であると指摘している。**

### Reference List (参考文献リスト) Format

#### Journal Article
> **著者名. (年). タイトル. 雑誌名, 巻(号), ページ範囲. DOI**
> **田中太郎. (2020). 新手法の提案. 日本学術雑誌, 50(3), 123-135. https://doi.org/xxx**

#### Book
> **著者名. (年). 書名. 出版社.**
> **佐藤花子. (2019). 統計解析入門. 東京大学出版会.**

#### Chapter in Edited Book
> **著者名. (年). 章タイトル. 編者名 (編), 書名 (pp. ページ). 出版社.**

#### Conference Proceedings
> **著者名. (年). タイトル. 会議名, 開催地, ページ.**

#### Web Source
> **著者名. (年). タイトル. URL (参照 年-月-日).**

### Japanese Citation Styles
- **日本心理学会式** (Japanese Psychological Association) - APA-based
- **日本医学会式** (Japanese Medical Society) - Vancouver-based
- **日本機械学会式** (JSME) - Numbered
- **情報処理学会式** (IPSJ) - Numbered

> **Use your target journal's style guide.**

## Structural Templates

### Abstract (要旨 / アブストラクト) - 200-400 chars
> **背景:** 〜という課題がある。
> **目的:** 本研究では、〜を目的とする。
> **方法:** 〜という手法を用いた。
> **結果:** 〜という結果が得られた。
> **結論:** 〜ことが示された。今後は〜が課題である。

### Introduction (序論 / 緒論)
> **1. 研究背景:** 社会的/学術的意義
> **2. 先行研究の概観:** 何が分かっているか、何が分かっていないか
> **3. 問題提起:** ギャップの明示
> **4. 研究目的・問い:** 本研究の目的
> **5. 研究の構成:** 本稿の構成

### Methods (方法 / 手法)
> **対象/材料:** サンプル、機器、試薬
> **手順:** 実験手順、解析方法
> **倫理:** 倫理委員会承認番号

### Results (結果)
> **事実のみ** - 統計値、図表参照
> **統計的有意性**: p値、効果量、信頼区間
> **主観なし** - 考察は次のセクション

### Discussion (考察)
> **1. 主要な発見の要約**
> **2. 解釈・メカニズムの議論**
> **3. 先行研究との比較・整合性**
> **4. 限界・制約**
> **5. 今後の展望・応用**

### Conclusion (結論)
> **1. 主要結論の再確認**
> **2. 学術的・実践的意義**
> **3. 今後の課題**

## 公用文 (Kōyobun) - Government/Business Official Documents

### Structure
> **1. 件名** (Subject)
> **2. 宛名** (Addressee)
> **3. 差出人** (Sender)
> **4. 日付** (Date)
> **5. 本文** (Body) - **である** style
> **6. 末尾** (Closing) - **以上**

### Common Patterns
| Purpose | Opening | Closing |
|---------|---------|---------|
| **通知** (Notification) | **〜について、下記のとおり通知する。** | **以上** |
| **依頼** (Request) | **〜について、ご協力をお願いする。** | **よろしくお願いする。** |
| **回答** (Response) | **〜について、下記のとおり回答する。** | **以上** |
| **報告** (Report) | **〜について、下記のとおり報告する。** | **以上** |
| **申請** (Application) | **〜について、申請する。** | **よろしく審査のほどお願いする。** |

### 公用文 Vocabulary
| 公用文 | Standard | Meaning |
|--------|----------|---------|
| **下記のとおり** | 次の通り | As follows |
| **ご査収ください** | 受け取ってください | Please review/accept |
| **ご高配** | ご配慮 | Kind consideration |
| **ご清栄** | お元気で | Good health/prosperity |
| **ご多忙の折** | お忙しいところ | In your busy schedule |
| **恐縮ですが** | 申し訳ありませんが | I'm sorry but |
| **何卒** | どうぞ | Please (earnest) |
| **早急に** | すぐに | Urgently |
| **適宜** | 適切に | As appropriate |
| **速やかに** | 早く | Promptly |

## Business Email (ビジネスメール) - Formal

### Structure
```
件名：【御礼】〇〇の件について（株式会社〇〇　田中太郎）

株式会社〇〇
山田様

いつも大変お世話になっております。
株式会社〇〇の田中でございます。

先日は、貴重なお時間をいただき、誠にありがとうございました。
ご説明いただいた内容について、社内で検討させていただきたく存じます。

つきましては、来週の月曜日までにご連絡を差し上げたく存じますが、
ご都合のよいお時間帯などございましたら、ご教示いただけますと幸いです。

お忙しいところ恐縮ですが、何卒よろしくお願い申し上げます。

--------------------------------------------------
株式会社〇〇
営業部　田中太郎
TEL: 03-xxxx-xxxx
Email: tanaka@xxx.co.jp
```

### Email Templates by Purpose

#### Request (依頼)
> **ご検討いただけますと幸いです。**
> **ご確認いただけますでしょうか。**
> **ご対応のほど、何卒よろしくお願い申し上げます。**

#### Apology (謝罪)
> **ご迷惑をおかけし、誠に申し訳ございません。**
> **深くお詫び申し上げます。**
> **再発防止に努めてまいる所存でございます。**

#### Scheduling (日程調整)
> **ご都合のよい日程をご教示いただけますでしょうか。**
> **ご調整いただけますと幸いです。**
> **候補日をご提示いたします。**

#### Sending Documents (送付)
> **資料をお送りいたします。**
> **別途メールにて送付させていただきます。**
> **ご査収のほど、よろしくお願い申し上げます。**

## Writing Checklist (推敲チェックリスト)

### Structure
- [ ] 論理の流れは明確か（導入→方法→結果→考察→結論）
- [ ] 段落ごとにトピックセンテンスがあるか
- [ ] 接続詞で論理関係が明示されているか

### Style
- [ ] **である** 統一されているか（です/ます混在なし）
- [ ] 文末が **た/だ/である** で統一されているか
- [ ] 受動態・無人称で客観性を保っているか
- [ ] 控え表現（〜と考えられる等）を適切に使っているか

### Clarity
- [ ] 一文一義（一つの文に一つの主張）
- [ ] 主語・述語の対応が明確か
- [ ] 専門用語は初出で定義されているか
- [ ] 略語は初出で正式名称を併記しているか

### Mechanics
- [ ] 誤字脱字なし
- [ ] 数値・単位・記号が正しいか
- [ ] 図表番号・引用が正しいか
- [ ] 参考文献形式が統一されているか

---

*Academic Japanese = logical architecture. The grammar is simple (である + passive + connectors). The discipline is in the thinking. Write the outline first. Then fill each section with evidence. The language follows the logic.*
